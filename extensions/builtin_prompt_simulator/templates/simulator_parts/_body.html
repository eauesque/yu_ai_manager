sed Reference

      
    

    

      

        
          
SyntaxDescriptionExample

        
        
          
s/old/new/flagsReplace — all liness/cat/dog/g

          
/pat/s/old/new/flagsReplace — matching lines only/^cat/s/,/|/g

          
/pat/dDelete matching lines/^#/d

          
/pat/!dKeep only matching lines (grep)/blue/!d

          
y/src/dst/Transliterate chars (like tr)y/ABC/abc/

          
/pat/a\textInsert text after matching lines/header/a\---

          
/pat/i\textInsert text before matching lines/footer/i\---

        
      

      
Flags (s command)

      

        
          
gReplace all occurrences in each line

          
iCase-insensitive matching

        
      

      
Regex (JavaScript RegExp)

      

        
          
.Any character

          
^ $Start / end of line

          
* + ?Quantifiers (0+, 1+, 0-1)

          
\d \w \sDigit, word char, whitespace

          
[abc] [^abc]Character set / negated set

          
(foo|bar)Alternation & grouping

          
\bWord boundary

          
(?=pat) (?!pat)Lookahead / negative lookahead

          
$1 $2Back-reference in replacement

        
      

      
Delimiter

      
The character after s or y is the delimiter. Use \/ to include a literal delimiter.
