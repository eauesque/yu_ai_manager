# LLM Router

> Целевая версия: v4.55.0 или выше

## Что такое LLM Router

LLM Router — это **совместимый с OpenAI прокси-сервер LLM**, встроенный в yu_ai_manager.  
Он объединяет несколько локальных бэкендов LLM, таких как Ollama, LM Studio и llama.cpp,  
и предоставляет их как **единую конечную точку** клиентам, таким как Claude Code, Continue и Open WebUI.

```
Клиент (Claude Code / Continue и т. д.)
          │  (API совместимый с OpenAI)
          ▼
    yu_ai_manager
    ┌─────────────────────────────────────────┐
    │           LLM Router                   │
    │                                         │
    │  alias: "claude-opus-4-7" ──► large    │
    │  alias: "local-coder" ──► ollama-mac/…│
    │                                         │
    │  [BackendCatalog]                       │
    │   ollama-mac  ─── 192.168.1.10:11434   │
    │   ollama-pi5  ─── 192.168.1.20:11434   │
    │   mdns-win01  ─── Автоматически обнаруженные бэкенды mDNS (alias: "mdns-<prefix>") │
    └─────────────────────────────────────────┘
```

### Возможности

| Функция | Функция |
|---|---|
| **Объединение нескольких бэкендов** | Регистрируйте любое количество экземпляров Ollama в локальной сети |
| **Абстракция с псевдонимами** | Скройте реальные названия моделей с помощью `"model": "fast"` |
| **Автоматическое обнаружение mDNS** | Автоматически регистрируйте узлы yu_ai_manager в одной локальной сети без конфигурации |
| **Интеграция Claude Code** | Реализуйте совместимый с Anthropic `/v1/messages`. Дополнительный прокси не требуется |
| **Динамическое отключение/включение** | Переключайте бэкенды мгновенно из веб-интерфейса. Перезагрузка не требуется |
| **Маршрутизация на основе категорий** | Автоматически выбирайте оптимальные модели через виртуальные бэкенды `large` / `fast` / `vision` |

## Архитектура

```
Клиент (Claude Code / Continue и т. д.)
    │
    │ POST /v1/chat/completions
    │ POST /v1/messages          ← Anthropic compatible
    │ GET  /v1/models
    ▼
BackendCatalog  ─── Разрешение псевдонима ──► Бэкенд + имя модели
    │
    ├─ Вручную зарегистрированные бэкенды (написанные в config.json)
    └─ Автоматически обнаруженные бэкенды mDNS (alias: "mdns-<prefix>")
```

**Поток запроса:**

1. Клиент отправляет запрос с `"model": "claude-opus-4-7"`
2. Router разрешает `"claude-opus-4-7"` → `"large"` в таблице `aliases`
3. Выберите действительный бэкенд из категории `large`
4. {trans["flow_step_4"]}
5. {trans["flow_step_5"]}

## Gateway Различие с Gateway

| | LLM Router | Gateway |
|---|---|---|
| **Область** | Только LLM (Ollama и т. д.) | SD WebUI, ComfyUI, Ollama вместе |
| **Граница аутентификации** | Локальные можно обойти. api_key требуется вне локальной сети | Аутентификация Bearer на основе области для всех бэкендов |
| **Конечные точки** | `/v1/*` (совместимо с OpenAI/Anthropic) | `/v1/*`, `/sd/*`, `/comfy/*` |
| **Основной случай использования** | Бэкенд для инструментов кодирования ИИ | Безопасно предоставляйте инструменты генерации внешним клиентам |

Обе функции работают независимо. Если вы используете только LLM, LLM Router достаточно.

---

## Связь с LAN Cowork

Когда включен [LAN Cowork](../lan-cowork/README.md),  
одноранговые узлы в одной локальной сети автоматически обнаруживаются через mDNS и автоматически регистрируются  
в LLM Router с псевдонимами вроде `mdns-<node_id[:8]>`.  
Мультиузловая среда LLM настраивается без конфигурации.
