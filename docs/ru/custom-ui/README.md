## Обзор

YU AI Manager имеет полностью отделённое от фронтенда бэкэнд-API, поэтому вы можете свободно менять пользовательский интерфейс.
Пользовательский интерфейс активируется просто размещением в директории `ui/<name>/`.

### Что можно делать в этой системе

- **Полная замена интерфейса**: замена всех страниц (поиск, статистика, настройки и т.д.) на собственный дизайн
- **Кастомизация тем**: изменение цветовой схемы путём перезаписи переменных CSS
- **Частичная замена**: кастомизация только нужных страниц, остальные используют интерфейс по умолчанию
- **Генерация интерфейса AI**: передача документации API Claude или ChatGPT для автоматической генерации интерфейса

### Архитектура

```

│   ├── default/              # Справочный UI (встроенный)
│   │   ├── manifest.json     # Метаданные UI (обязательно)
│   │   ├── templates/        # Шаблоны Jinja2 HTML
│   │   │   ├── index.html    # Главная страница поиска
│   │   │   ├── stats.html    # Панель статистики
│   │   │   ├── tools.html    # Страница инструментов
│   │   │   ├── settings.html # Страница настроек
│   │   │   ├── story.html    # Страница "Your Story"
│   │   │   ├── inspect.html  # Инспектор метаданных
│   │   │   └── _nav.html     # Общая панель навигации (include)
│   │   └── static/           # CSS, JS, изображения
│   │       ├── css/          # Таблицы стилей
│   │       ├── dist/         # Выходные данные сборки TypeScript
│   │       └── favicon.svg   # Значок сайта
│   ├── custom/               # Пользовательский интерфейс (gitignored, автоопределение)
│   │   ├── manifest.json
│   │   ├── templates/

```

### Порядок разрешения интерфейса

При запуске сервера выбор используемого интерфейса осуществляется в следующем порядке приоритета:

| Приоритет | Условие | Действие |
|-----------|---------|---------|
| 1 | Установлено `"ui": "my-theme"` в `config.json` | Используется указанный `ui/my-theme/` |
| 2 | В `ui/custom/` присутствует валидный `manifest.json` | Используется `ui/custom/` с автоопределением |
| 3 | Ни одно из вышеперечисленных не применяется | Используется `ui/default/` по умолчанию |

### manifest.json

Все пользовательские интерфейсы должны содержать обязательный `manifest.json`:

```json
{
  "name": "my-custom-ui",
  "version": "1.0.0",
  "description": "My custom UI for YU AI Manager",
  "author": "Your Name",
  "api_version": "1"
}
```

| Поле | Обязательно | Описание |
|-----|-----------|---------|
| `name` | Да | Идентификатор интерфейса (рекомендуется совпадать с именем директории) |
| `version` | Да | Семантическое версионирование |
| `description` | Нет | Описание интерфейса |
| `author` | Нет | Имя автора |
| `api_version` | Нет | Поддерживаемая версия API (`"1"`) |
| `type` | Нет | `"full"` (по умолчанию) или `"theme"` |

### Распределение статических файлов

Директория `static/` пользовательского интерфейса сопоставляется URL `/static/` Flask:

```
ui/custom/static/style.css  →  /static/style.css
ui/custom/static/js/app.js  →  /static/js/app.js
ui/custom/static/img/logo.png  →  /static/img/logo.png
```

Ссылки из HTML:
```html
<link rel="stylesheet" href="/static/style.css">
<script src="/static/js/app.js"></script>
<img src="/static/img/logo.png">
```

### API управления интерфейсом

Управление интерфейсом доступно с вкладки "UI" на странице Settings или через API:

| Метод | Путь | Описание |
|-------|------|---------|
| GET | `/api/ui/list` | Список установленных интерфейсов |
| POST | `/api/ui/switch` | Переключение активного интерфейса (требует перезагрузки) |
| POST | `/api/ui/install` | Установка интерфейса из URL (только localhost) |
| DELETE | `/api/ui/<name>/uninstall` | Удаление интерфейса (только localhost) |

### MCP инструменты

Управление интерфейсом также доступно через MCP (Model Context Protocol):

- `list_uis()` — список установленных интерфейсов
- `switch_ui(name)` — переключение активного интерфейса
- `install_ui(url)` — установка интерфейса из URL
- `uninstall_ui(name)` — удаление интерфейса
