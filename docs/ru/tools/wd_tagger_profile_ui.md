# Руководство по UI профилей WD-Tagger

Этот документ описывает **интерфейс управления профилями** WD-Tagger (добавлен в v4.197.0+).

## 1. Обзор

- **Профиль** объединяет настройки WD-Tagger: файлы модели, определения тегов, пороги и предобработку.
- Открыть: страница Tools → раздел **WD-Tagger** → `Управление профилями...`.
- В модальном окне можно переключаться между **Списком (List)** и **Формой (Form)**.

## 2. Экран списка (List)

### 2.1 Метки (Builtin / User)

- `builtin`: встроенные профили (только чтение)
- `user`: пользовательские профили (можно создавать/редактировать/удалять)
- `↻`: профиль **перезаписывает встроенный** профиль с тем же `id`

### 2.2 Фильтр (All / User / Builtin)

Кнопки фильтра:

- `Все`
- `Пользовательские`
- `Встроенные`

### 2.3 Кнопки (действия)

Действия в строке:

- `Дублировать`: копирует профиль и открывает форму (чтобы изменить встроенный профиль)
- `Редактировать`: редактировать пользовательский профиль (встроенные нельзя)
- `Удалить`: удалить пользовательский профиль (встроенные нельзя)
- `Экспорт`: скачать профиль как `.json`
- `Тест (пробная загрузка)`: **без реальной загрузки** проверить, можно ли получить файлы с HuggingFace

Справа сверху:

- `+ Новый`: создать пустой профиль
- `Импорт`: создать профиль из JSON (загрузка / вставка)

## 3. Экран формы (Form)

Форма состоит из 5 секций-аккордеонов.

### 3.1 Metadata

- `id`: идентификатор профиля (нельзя изменить позже)
- `Отображаемое имя`: имя в списке
- `profile_version`: версия схемы (обычно не нужно менять)

### 3.2 Model & Files

- `model_id`: id модели в HuggingFace (например: `SmilingWolf/wd-swinv2-tagger-v3`)
- `adapter_family`, `backend`, `hf_subdir`: только при необходимости
- `Файлы`:
  - `name`: имя файла (например: `model.onnx`)
  - `Обязательно`: будет считаться обязательным в тесте
  - `size_hint_mb`: опционально
  - `+ Добавить файл` / `Удалить`: добавить/убрать строки

### 3.3 Tag source

Откуда берутся определения тегов.

- `csv`: файл(file), разделитель(delimiter), колонка имени(name_col), колонка категории(category_col), карта(category_map)
- `json_list`: файл(file), схема(schema)
- `json_dict`: файл(file), сопоставление(mapping)
- `composite`: комбинирование источников(sources)

### 3.4 Threshold source

Откуда берутся пороги.

- `global_per_category`: задавать пороги по категориям в UI
- `per_tag`: файл + fallback
  - файл(file)
  - режим fallback(fallback.mode): `global` / `category_default`
  - значение fallback(fallback.value)

### 3.5 Preprocess & Categories

- Предобработка(`preprocess_spec`): `input_size`, `dtype`, `layout`, `channel_order`, `resize_strategy` (`letterbox` / `longest_side_pad` / `stretch`), `scale`, `mean`, `std`
- Категории:
  - `Поддерживаемые категории`
  - `categories_mode`: `from_tag_source` / `all_general`

## 4. Импорт / Экспорт

### 4.1 Импорт

`Импорт` открывает два таба:

- Загрузить JSON: загрузить `.json` файл
- Вставить JSON: вставить JSON в текстовое поле

После импорта открывается форма. Проверьте/измените и нажмите `Сохранить`.

### 4.2 Экспорт

В списке нажмите `Экспорт`, чтобы скачать профиль в формате JSON.

## 5. Тест (пробная загрузка)

- Проверяет, можно ли получить файлы из `files` с **HuggingFace**.
- При успехе может появиться `Загрузка OK: {n} файлов ({total} MB)`.
- При ошибке показывается причина (следующий раздел).

## 6. Частые ошибки (кратко)

- `id_conflict`: пользовательский профиль с таким `id` уже существует
- `id_immutable`: `id` нельзя менять (переименование через Дублировать → Удалить)
- `in_use`: нельзя удалить, потому что профиль активен
- `validation_failed`: ошибка проверки (`{detail}` содержит детали)
- `profile_too_large`: импортированный JSON больше 1MB
- `ssrf_blocked`: перенаправление вне HuggingFace заблокировано (SSRF защита)
- `hf_unavailable`: HuggingFace недоступен / неправильный ответ
- `timeout`: таймаут (60s)
- `required_missing`: отсутствует обязательный файл

## 7. Ограничения (важно)

- Встроенные (`builtin`) профили нельзя редактировать/удалять. Используйте `Дублировать`.
- `id` неизменяем. Для переименования: `Дублировать` → `Удалить` старый.
- Лимит импорта: **1MB**.
- `Тест` разрешает только домены HuggingFace (SSRF allowlist):
  - `huggingface.co`
  - `hf.co`
