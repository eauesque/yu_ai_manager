# SNS и внешние интеграции

YU AI Manager может интегрироваться с внешними сервисами, такими как Bluesky и GitHub.
Управление через MCP-инструменты.

## Интеграция с Bluesky

Публикация изображений в Bluesky через привязанный аккаунт.

### Настройка

1. Установить хэндл Bluesky и пароль приложения на вкладке Settings > SNS
2. Пароль приложения создаётся по адресу https://bsky.app/settings/app-passwords

### Основные MCP-инструменты

| Инструмент | Описание |
|-----------|---------|
| `bsky_post_image` | Опубликовать изображение в Bluesky |
| `bsky_get_profile` | Получить информацию профиля |

## Интеграция с GitHub

Управление файлами и Issue в репозиториях GitHub.

### Настройка

Установить GitHub Personal Access Token на вкладке Settings > API Keys.

### Основные MCP-инструменты

| Инструмент | Описание |
|-----------|---------|
| `github_list_repos` | Список репозиториев |
| `github_create_issue` | Создать Issue |
| `github_list_issues` | Список Issue |
