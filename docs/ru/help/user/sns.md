# SNS Share и Bluesky Monitor

## Обзор

SNS Share — расширение для прямой публикации AI-генерированных изображений из YU AI Manager в Bluesky и X (Twitter).
Текст поста автоматически генерируется из настраиваемых шаблонов с переменными метаданных изображения.
Bluesky Monitor добавляет функцию мониторинга уведомлений с AI-триажем и автоответами.

## Настройка

### Получение App Password для Bluesky

1. Войти на [bsky.app](https://bsky.app) и открыть **Настройки > App Passwords**
2. Нажать **Добавить App Password**
3. Ввести имя (например, «YU AI Manager») и нажать **Создать App Password**
4. Скопировать отображённый пароль

> **Важно**: App Password отображается только на этом экране. Скопируйте до закрытия диалога. Никогда не используйте основной пароль Bluesky.

### Настройка в YU AI Manager

1. Открыть **Settings** в меню навигации
2. Перейти на вкладку **SNS**
3. Ввести:
   - **Хэндл Bluesky**: (например, `yourname.bsky.social`)
   - **App Password**: Полученный выше пароль
   - **Шаблон поста**: Шаблон текста поста (см. [Переменные шаблона](#переменные-шаблона))
4. Нажать **Сохранить**

## Функции

### Публикация в Bluesky

1. Открыть модальное окно деталей изображения
2. Нажать кнопку **SNS**
3. Проверить и при необходимости отредактировать текст поста
4. Нажать **Опубликовать в Bluesky**

- Посты ограничены **300 grapheme** (избыток обрезается автоматически)
- Изображения автоматически сжимаются до лимита 1 МБ Bluesky

### Bluesky Monitor

Bluesky Monitor опрашивает уведомления Bluesky, складывает их в локальную очередь и выполняет триаж.

#### Типы уведомлений

- **Упоминание**: Вас упомянули в посте
- **Ответ**: Ответили на ваш пост
- **Цитата**: Процитировали ваш пост
- **Подписка**: Кто-то подписался на вас
- **Лайк / Репост**: Лайкнули или репостнули ваш пост

#### Система очереди

Каждое уведомление входит в очередь со статусом **pending** (ожидает).
Затем может перейти в состояния:
- **notified** — уведомлено MCP-клиенту (Claude Desktop)
- **dismissed** — отклонено как не требующее действий

#### Триаж AI

Классификация уведомлений на требующие и не требующие ответа:
- **valid** — требует действий (вопрос, баг-репорт, предложение о сотрудничестве)
- **invalid** — можно игнорировать (общие похвалы, спам, боты)

#### Автоответы

На valid упоминания, ответы и цитаты можно настроить автоматические ответы на основе шаблонов.

## Переменные шаблона

| Переменная | Описание |
|-----------|---------|
| `{positive_short}` | Позитивный промпт (первые 100 символов) |
| `{positive}` | Полный позитивный промпт |
| `{model}` | Имя модели |
| `{seed}` | Значение seed |
| `{steps}` | Количество шагов сэмплирования |
| `{cfg}` | CFG Scale |
| `{sampler}` | Имя сэмплера |
| `{size}` | Размер изображения |
| `{tags}` | Топ-5 тегов |
| `{filename}` | Имя файла |

Шаблон по умолчанию: `{positive_short}`

## MCP-интеграция

**Публикация (6 инструментов)**:
- `share_to_bluesky`, `get_x_share_url`, `get_sns_preview`, `test_bluesky_connection`
- `get_sns_config` / `save_sns_config`

**Очередь уведомлений (5 инструментов)**:
- `bsky_get_pending_notifications`, `bsky_get_notification_queue`
- `bsky_triage_notification`, `bsky_send_auto_response`, `bsky_poll_notifications`

**Настройки Monitor (4 инструмента)**:
- `bsky_get_monitor_config` / `bsky_save_monitor_config`
- `bsky_get_triage_prompts` / `bsky_save_triage_prompts`
