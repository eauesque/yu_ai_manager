# Самодиагностика и отчетность при ошибках

Если YU AI Manager не работает или ведет себя неправильно, выполните следующие действия для сбора информации об ошибке и отправки отчета разработчикам. Вам не нужны знания команд или Git.

## 1. Сначала нажмите «Отправить отчет о проблеме»

1. Откройте приложение в браузере и выберите **Diagnostics** из меню в верхнем правом углу экрана.
2. Нажмите кнопку **«Отправить отчет о проблеме»**.
3. После небольшого ожидания будет создана папка `repair/2026XXXX-HHMMSS/`. Содержимое включает следующий автоматический набор отчетов:
   - Информацию об окружении, последние логи, параметры (личная информация, токены и API-ключи замаскированы)
   - Шаблоны промптов для ремонта AI

Нажмите **«Открыть папку»**, чтобы открыть папку в Проводнике. Нажмите **«Создать ZIP»**, чтобы объединить все в один zip-файл.

> О маскировании: имена пользователей, email, строки похожие на API-ключи, IP-адреса автоматически заменяются на `<REDACTED>`. Это не совершенно, поэтому перед совместным использованием один раз проверьте содержимое.

## 2. Поделитесь отчетом

Отправьте ZIP-файл разработчикам, в канал поддержки или в Discord. Кнопка **«Скопировать сообщение для Discord»** создает краткий текст для вставки.

## 3. Попробуйте временные решения самостоятельно

### 3-A. Проверка окружения (doctor)

Нажмите кнопку **«Диагностика окружения»** на экране диагностики, чтобы увидеть состояние Python, GPU, БД и т.д. в формате markdown. Попробуйте последовательно следовать указаниям `fix_hint` (подсказки по исправлению) из элементов красного цвета (ERROR) или желтого цвета (WARN).

### 3-B. Перезагрузитесь в Safe Mode

Если обычный запуск невозможен, приложение падает или бесконечно загружается, вы можете запустить приложение в **Safe Mode**.

- Windows: дважды щелкните `start.bat --safe-mode` (или добавьте ` --safe-mode` в конец ярлыка)
- macOS / Linux: запустите `./start.sh --safe-mode` из терминала

В Safe Mode вы можете:

- Проверить параметры
- Использовать «Отправить отчет о проблеме» и «Диагностика окружения»
- Применить **безопасный пакет обновления (update.zip)**, полученный от разработчика (только замена файлов, автоматические скрипты восстановления отключены)

Safe Mode остается активным до следующего обычного запуска. Просто перезагрузитесь нормально, чтобы вернуться в обычный режим.

### 3-C. Применить пакет обновления (update.zip)

Если вы получили `update.zip` от разработчика:

1. Перейдите на экран диагностики → раздел **«Применить обновление»**
2. Выберите файл и убедитесь, что **Verify** становится зеленым
3. Нажмите **Применить** в диалоговом окне подтверждения
4. Следуйте отображаемым инструкциям для перезагрузки

> Никогда не применяйте zip-файл, если проверка красная. Это может означать повреждение или пакет для другого приложения.

Если что-то пошло не так, вы можете использовать **«Отменить предыдущее обновление (Rollback)»**, чтобы вернуться в предыдущее состояние.

## 4. Что не следует делать

- Не публикуйте сырые логи без маскирования в социальные сети или открытые форумы
- Не применяйте `update.zip` из неизвестных источников
- Не редактируйте вручную папку `data/` или файл `tags.db`

## Если у вас все еще есть проблемы

Если проблема не решена, отправьте ZIP с описанием операции, которая привела к проблеме. На стороне AI будут прочитаны файлы `prompt_for_codex.md` / `prompt_for_claude.md`, и будет предложен патч для исправления.
