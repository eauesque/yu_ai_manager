# Поиск

## Базовый поиск

Введите теги через запятую в строку поиска:

```
1girl, blue_eyes, school_uniform
```

## Фильтры поиска

| Фильтр | Описание |
|--------|---------|
| Диапазон дат | Фильтр по начальной и конечной дате |
| Формат файла | PNG / WebP / JPG / GIF |
| Рейтинг | Фильтр по звёздам 1–5 |
| Избранное | Только добавленные в избранное |
| Коллекция | Только в конкретной коллекции |

## Поиск по промпту

Поле `in_prompt` позволяет выполнять полнотекстовый поиск по тексту промпта изображения.
При включённом FTS (Full-Text Search) поиск выполняется быстро.

## Порядок сортировки

| Сортировка | Описание |
|-----------|---------|
| date | По дате регистрации (новые первые) |
| date_old | По дате регистрации (старые первые) |
| folder | По папке |
| path | По пути |
| random | Случайный порядок |
| rating_desc | По рейтингу (высокий первый) |
| rating_asc | По рейтингу (низкий первый) |

## Семантический поиск

При настроенной модели Hailo-10H или ONNX CLIP доступен поиск на естественном языке.
Используйте кнопку семантического поиска справа от строки поиска.

### Ускорение через FAISS (рекомендуется)

По умолчанию используется перебор через NumPy, но **установка FAISS значительно ускоряет поиск**.

| Размер библиотеки | NumPy (по умолч.) | FAISS (рекоменд.) |
|------------------|-------------------|-------------------|
| До 10 тыс. | Десятки мс | Единицы мс |
| 100 тыс. | 1–3 сек | Десятки мс |
| Более 1 млн | Более 10 сек | Менее 100 мс |

#### Установка

```bash
# Активировать venv
source venv/bin/activate

# x86_64 (Intel/AMD)
uv pip install faiss-cpu

# Raspberry Pi 5 (aarch64) — если pip не работает:
# Через conda: conda install -c conda-forge faiss-cpu
```

После установки перезапустить сервер — обнаружится автоматически.
При успешной активации в логе будет:

```
FAISS x.x.x detected — using accelerated vector search
```
