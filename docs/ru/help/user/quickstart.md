# YU AI Manager за 5 минут

## Что такое YU AI Manager

YU AI Manager — WebUI-приложение для централизованного управления метаданными AI-генерированных изображений
(Stable Diffusion / NovelAI / ComfyUI и т.д.). Автоматически извлекает промпты и информацию о моделях
из изображений, упрощая поиск, просмотр и организацию тегов.

---

## Требования

| Параметр | Требование |
|----------|-----------|
| Python | 3.11 или выше |
| Node.js | 18 или выше (для сборки фронтенда) |
| ОС | Windows 10/11, macOS, Linux |
| Браузер | Chrome / Firefox / Edge (рекомендуется последняя версия) |

---

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/your-repo/yu_ai_manager.git
cd yu_ai_manager
```

### 2. Создать виртуальное окружение Python

**macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows (Git Bash):**
```bash
python -m venv venv
source venv/Scripts/activate
```

### 3. Установить Python-зависимости

```bash
uv pip install -r requirements.txt
```

> Если `uv` не установлен: `pip install uv`

### 4. Собрать фронтенд

```bash
pnpm install
pnpm run build
```

> Если `pnpm` не установлен: `npm install -g pnpm`

## Первый запуск

### 1. Запустить сервер

```bash
python web_ui.py
```

### 2. Открыть в браузере

```
http://localhost:5000
```

## Первые шаги

### Шаг 1: Зарегистрировать папки для сканирования

1. Открыть **Settings** через гамбургер-меню в правом верхнем углу
2. Выбрать вкладку **Scan**
3. Добавить путь к папке с AI-изображениями
4. После добавления папки сканирование запустится автоматически

Во время сканирования вверху отображается прогресс-бар.
При большом количестве изображений может занять несколько минут, но поиск/просмотр доступен.

### Шаг 2: Просмотр сетки миниатюр

После завершения сканирования на главной странице появится сетка миниатюр.

- **Прокрутка**: Виртуальный скролл для плавного отображения большого числа изображений
- **Сортировка**: Переключение в верхнем меню (по дате, рейтингу и т.д.)
- **Правый клик**: Добавить в избранное или коллекцию через контекстное меню

### Шаг 3: Поиск по тегам

Введите теги через запятую в строке поиска:

```
1girl, blue_eyes, school_uniform
```

- **Автодополнение**: Подсказки при вводе
- **Фильтры**: Диапазон дат, формат файла, звёздный рейтинг
- **Полнотекстовый поиск**: Поиск по тексту промпта

### Шаг 4: Просмотр подробностей

Клик по миниатюре открывает модальное окно с деталями.

- **Вкладка Info**: Промпт, негативный промпт, имя модели, параметры генерации
- **Звёздный рейтинг**: 1–5 звёзд
- **Избранное**: Кнопка сердечка
- **Редактирование тегов**: Добавление/удаление пользовательских тегов
- **Клавиши**: Стрелки для перехода к предыдущему/следующему изображению

## Сводка частых операций

| Действие | Способ |
|---------|--------|
| Найти изображение | Ввести теги в строку поиска |
| Просмотреть детали | Кликнуть по миниатюре |
| Добавить в избранное | Кнопка сердечка или правый клик |
| Поставить звёздный рейтинг | Звёздочки в модальном окне деталей |
| Добавить в коллекцию | Правый клик > Добавить в коллекцию |
| Выбрать несколько | Ctrl+клик или Shift+клик |
| Сканировать новую папку | Settings > вкладка Scan |

## Следующие шаги

### Bridge (интеграция с генераторами)

SD WebUI / ComfyUI / NovelAI API для отправки/получения промптов.
Подробности в [руководстве по Bridge](bridges.md).

### Extensions

WD-Tagger (автотегирование), библиотека промптов, вьювер чат-логов и многое другое.
Управление на вкладке Settings > Extensions.

### Семантический поиск

После настройки CLIP-модели (ONNX или Hailo-10H) доступен поиск на естественном языке.

## Устранение неполадок

- **Команда `uv` не найдена**: `pip install uv`
- **Команда `pnpm` не найдена**: `npm install -g pnpm`
- **Порт 5000 занят**: `python web_ui.py --port 5100`
- **Изображения не отображаются**: Проверить правильность пути к папке сканирования
