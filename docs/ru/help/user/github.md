# GitHub Integration

## Обзор

GitHub Integration — расширение для централизованного управления репозиториями,
Issue, Pull Request, Discussion и релизами GitHub прямо из YU AI Manager.
Поддерживает несколько GitHub-аккаунтов, токены хранятся зашифровано.
Дашборд для быстрого просмотра уведомлений и статистики репозиториев,
а также функция AI-триажа Issue.

## Настройка

### Получение GitHub Personal Access Token (PAT)

1. Войти в GitHub: **Settings > Developer settings > Personal access tokens > Tokens (classic)**
2. Нажать **Generate new token (classic)**
3. Ввести имя, установить срок действия
4. Поставить галочку на **`repo`** в области видимости
5. Нажать **Generate token** и скопировать отображённый токен

> **Важно**: Токен отображается только на этом экране. Скопируйте до закрытия.

### Добавление аккаунта

1. Открыть карточку **GitHub** в лаунчере Extensions или напрямую перейти `/ext/github`
2. Открыть вкладку **Settings**
3. Нажать **Добавить аккаунт**
4. Ввести:
   - **Метка**: Отображаемое имя аккаунта (например, «Личный», «Рабочий»)
   - **Токен**: Полученный PAT
   - **Репозитории**: Для мониторинга в формате `owner/repo` (можно несколько)
5. После сохранения выбрать аккаунт в выпадающем списке

## Функции

### Дашборд

- **Уведомления**: Список непрочитанных уведомлений GitHub
- **Статистика репозиториев**: Звёзды, форки, открытые Issue в виде карточек

### Issue

- Фильтрация по репозиторию и состоянию (open/closed)
- Просмотр деталей (тело, комментарии, метки)
- Создание новых Issue
- **Триаж**: AI-классификация Issue
  - `valid_bug` — Достоверный баг-репорт
  - `needs_info` — Нужна дополнительная информация
  - `skip` — Не требует действий
- **Очередь Issue**: Автоматический опрос новых Issue и добавление в локальную очередь

### Pull Requests

- Список и фильтрация PR
- Просмотр изменений по файлам

### Releases

- Список последних релизов отслеживаемых репозиториев
- Просмотр примечаний к релизу

## MCP-интеграция

GitHub Integration предоставляет 12 MCP-инструментов:

- Получение и просмотр Issue
- Получение и просмотр PR
- Управление очередью Issue (список ожидающих, триаж, отклонение, опрос)

## Советы

- **Несколько аккаунтов**: Разделите личный и рабочий для удобства
- **Использование триажа**: При большом потоке Issue автоматическая классификация повышает эффективность
- **Безопасность токенов**: Токены хранятся в зашифрованном виде на сервере
