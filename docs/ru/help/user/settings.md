# Настройки

## Настройки сервера

| Параметр | Описание |
|----------|---------|
| Host | Адрес байндинга (127.0.0.1 при выключенном LAN) |
| Port | Номер порта веб-сервера |
| LAN Access | ON — доступ с других устройств в LAN |
| PIN Auth | Требование ввода PIN при доступе |
| Boss Mode | Экран входа с PIN в стиле газеты |

## Настройки сканирования

Добавление, удаление, изменение порядка и включение/отключение зарегистрированных папок.

## Настройки парсера

| Параметр | Описание |
|----------|---------|
| Extract A1111 | Извлечение метаданных формата Stable Diffusion WebUI |
| Extract ComfyUI | Извлечение метаданных воркфлоу ComfyUI |
| Normalize tags | Приведение тегов к нижнему регистру |
| Compute hash | Вычисление хэша файлов (для обнаружения дубликатов) |
| FTS | Включение индекса полнотекстового поиска |

## API-ключи

Управление API-ключами для внешних инструментов (MCP-сервер, скрипты, агенты).
Используется с Bearer-аутентификацией.

## Внешний вид

Настройка темы, цвета акцента, фонового изображения, звуковых эффектов и т.д.

## Зашифрованное хранилище секретов

Конфиденциальные значения (PIN, пароль Bluesky, секреты Webhook и т.д.) защищены шифрованием Fernet из пакета `cryptography`.

- **Формат шифрования**: Строки с префиксом `enc:`
- **Совместимость**: Существующие открытые значения работают как есть (шифрование только при новом сохранении)
- **Установка**: `uv pip install cryptography` (при отсутствии функция шифрования недоступна)

### Бэкенд ключей

Ключ шифрования получается в следующем приоритете:

1. **Парольная фраза** — При установке переменной `YU_SECRET_PASSPHRASE` ключ выводится через PBKDF2-HMAC-SHA256 (600 000 итераций). Соль автоматически сохраняется в `data/secret.salt`
2. **Системный keychain** — При наличии пакета `keyring` ключ хранится в Windows Credential Manager / macOS Keychain / Linux Secret Service
3. **Файл** — `data/secret.key` (обратная совместимость, автосоздание при первом запуске)

### Экспорт/Импорт ключей

Ключ шифрования можно экспортировать/импортировать в формате JSON с защитой паролем для миграции между машинами или резервного копирования.

## Интеграция с 1Password CLI

В окружениях с установленным `op` CLI можно динамически получать секреты из 1Password Vault.

### Настройка

1. Установить [1Password CLI](https://developer.1password.com/docs/cli/)
2. Войти командой `op signin`
3. Добавить маппинг `op_secrets` в `config.json`:

```json
{
  "op_secrets": {
    "server.pin": "op://Private/YuManager/pin",
    "sns.bluesky.app_password": "op://Private/Bluesky/app_password"
  }
}
```

## MCP-инструменты для настроек

| Инструмент | Описание |
|-----------|---------|
| `settings_get_schema` | Получить схему всех настроек (тип, описание, категория) |
| `settings_get_all` | Получить все настройки (секреты замаскированы) |
| `settings_get` | Получить одно значение настройки |
| `settings_set` | Обновить значение настройки (секреты шифруются автоматически) |
| `secrets_status` | Получить состояние бэкенда ключа шифрования |
| `secrets_export` | Экспортировать ключ в JSON с защитой паролем |
| `secrets_import` | Импортировать ключ из экспортированных данных |
