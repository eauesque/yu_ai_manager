# Примеры использования

Коллекция распространенных сценариев, показывающих, как максимально использовать yu_ai_manager.

---

## 1. Организация большой коллекции изображений AI

У вас есть тысячи изображений, созданных с помощью NovelAI или Stable Diffusion, разбросанные по папкам, и их поиск стал трудоемким.

### Шаги

1. Перейдите на вкладку **Параметры > Сканирование** и зарегистрируйте папки с изображениями (поддерживается несколько папок)
2. Сканирование начинается автоматически после добавления папки. Архивы ZIP/7z также сканируются
3. По завершении сканирования используйте поиск по тегам (например, `1girl, blue_eyes`) или сортировку на главной странице для поиска изображений
4. Выберите свои избранные, затем щелкните правой кнопкой мыши > **Добавить в коллекцию**, чтобы организовать их в группы
5. Доступ к коллекциям в любое время из боковой панели коллекций

### Советы

- Вы можете искать и просматривать во время выполнения сканирования (подключения к БД только для чтения предотвращают конфликты блокировки)
- Включите расширение Auto Scan Watcher для автоматического обнаружения вновь добавленных файлов
- Библиотеки с более чем 1 миллионом файлов остаются быстрыми благодаря постраничной навигации по набору ключей

## 2. Поиск изображений по содержимому подсказки

Вы не совсем помните подсказку, которую использовали для того идеального композиции.

### Шаги

1. Переключите цель поиска на **in_prompt** в строке поиска
2. Введите любые ключевые слова, которые помните (например, `cherry blossom`)
3. Используйте регулярные выражения для более точного совпадения (например, `masterpiece.*cherry`)

### Советы

- Когда включен FTS (полнотекстовый поиск), даже массивные библиотеки подсказок ищут быстро
- Комбинируйте с фильтрами диапазона дат или формата файла для получения лучших результатов
- Установите порядок сортировки на `random` для переоткрытия забытых жемчужин

---

## 3. Поиск визуально похожих изображений

У вас есть изображение и вы хотите найти другие с похожим внешним видом или ощущением.

### Подход A: Поиск сходства pHash (композиция и цвет)

1. Откройте изображение в модальном окне деталей
2. Нажмите кнопку **Найти похожие изображения**
3. Изображения с похожими композициями отображаются в боковой панели, отсортированные по сходству pHash (перцептивный хеш)

### Подход B: Семантический поиск CLIP (значение и концепция)

1. Нажмите кнопку **Семантический поиск** рядом со строкой поиска
2. Введите описание на естественном языке (например, "девушка, стоящая у моря" или "закат городского пейзажа")
3. CLIP понимает содержание изображения и возвращает результаты, отсортированные по семантическому сходству

### Советы

- Семантический поиск требует предварительно настроенной модели CLIP (ONNX или Hailo-10H)
- Для больших библиотек (100K+ изображений) установка `faiss-cpu` резко улучшает скорость поиска
- pHash превосходен в совпадении композиций, а CLIP совпадает по значению — попробуйте оба для лучших результатов

## 4. Управление избранными изображениями

Вы хотите быстро пересмотреть свои лучшие работы из большой библиотеки.

### Шаги

1. Нажмите **кнопку сердца** на карточке изображения или в модальном окне деталей, чтобы отметить как избранное
2. Установите **рейтинг звезд** (1–5) в модальном окне деталей для оценки качества
3. Добавьте **аннотации** с примечаниями в свободной форме (например, "кандидат для переработки" или "опубликовано в SNS")
4. Используйте фильтры поиска для отображения только избранного или изображений с рейтингом 4 звезды и выше

### Советы

- Отсортируйте по рейтингу (`rating_desc`), чтобы просмотреть лучшие изображения вместе
- Избранным и рейтингами можно также управлять из контекстного меню (щелкните правой кнопкой мыши)

## 5. Отправка подсказок в другой инструмент генерации

Вы хотите повторно использовать подсказку из прошлого изображения для создания вариаций в другом инструменте.

### Шаги

1. Откройте модальное окно деталей и просмотрите информацию о подсказке
2. Нажмите **Отправить в SD WebUI** / **Отправить в ComfyUI** / **Отправить в NAI**
3. Открывается страница Bridge с предварительно заполненной подсказкой
4. При необходимости отредактируйте подсказку и запустите генерацию в целевом инструменте

### Советы

- Синтаксис веса (`()` vs `{}`) автоматически преобразуется между форматами SD и NAI
- Используйте кнопку **QP** в панели инструментов Bridge для вставки предустановок качества одним щелчком
- Подсказки также можно отправлять из любого Bridge из преобразователя подсказок или симулятора подсказок

## 6. Просмотр изображений внутри архивов ZIP/7z

Вы загрузили наборы изображений, упакованные как ZIP файлы, и хотите их просмотреть без извлечения.

### Шаги

1. В параметрах > сканирование зарегистрируйте папку, содержащую ваши ZIP/7z файлы
2. Включите опцию **Сканирование ZIP/7z** в параметрах сканирования
3. После сканирования архивные изображения отображаются на главной странице, как обычные изображения
4. Модальное окно деталей показывает имя архива и путь в архиве

### Советы

- Видео внутри архивов извлекаются в временный кеш (LRU, 2 ГБ) для плавного повторного воспроизведения
- Поддерживаются вложенные архивы (ZIP-в-ZIP)
- Используйте функцию пакетной загрузки для переупаковки архивных изображений в новый ZIP

## 7. Обмен изображениями с командой или семьей

Вы хотите, чтобы другие устройства в одной сети Wi-Fi (телефоны, планшеты и т.д.) просматривали вашу библиотеку.

### Шаги

1. На вкладке **Параметры > Сервер** включите "LAN Access"
2. Установите **PIN-код** (требуется для доступа в LAN)
3. Перезагрузите сервер
4. Доступ `http://<server-IP>:5000` с другого устройства в LAN
5. Введите PIN для входа

### Советы

- Выдайте **LAN Share token** (путь `/s/`) для создания ссылки для гостевого доступа, которая не требует PIN
- QR-код отображается на экране сервера — просто отсканируйте его камерой телефона для подключения
- Также поддерживается аутентификация доверенного прокси-сервера через обратный прокси

## 8. Автоматическое тегирование изображений с помощью AI

Ручное тегирование утомительно, и вы предпочли бы, чтобы AI анализировал и автоматически разметал ваши изображения.

### Подход A: WD-Tagger (быстро, ориентирован на теги)

1. Загрузите модель WD-Tagger ONNX из **Параметры**
2. Нажмите **Запустить WD-Tagger** на странице "Tools" или в модальном окне деталей
3. Теги в стиле Danbooru автоматически назначаются

### Подход B: Анализ AI (естественный язык, высокая точность)

1. Добавьте сервер Ollama или OpenAI-совместимый в **Параметры > AI Analysis**
2. Запустите анализ из вкладки **AI Analysis** в модальном окне деталей
3. Создается естественное описание языка изображения

### Советы

- WD-Tagger также поддерживает композитный режим с двигателями VLM (совместимыми с OpenAI API)
- Пост-обработка, такая как фильтрация NSFW и нормализация тегов, применяется автоматически
- Теги можно записать в метаданные XMP для легкой совместимости с другими инструментами

## 9. Просмотр статистики и отчетов

Вы хотите понять тенденции и рост вашей библиотеки изображений.

### Шаги

1. Откройте страницу **Статистика** из навигационной панели, чтобы увидеть общую статистику
2. Посетите страницу **Ежемесячный отчет** для подробных ежемесячных разбивок:
   - Ежемесячное количество файлов и изменение месяц к месяцу, топ 20 тегов, новые теги, распределение источников, ежедневные количества
3. Проверьте раздел **Трофеи** для значков достижений

### Советы

- Трофеи охватывают 6 категорий (веха / полоса / разнообразие / источник / скрытая) и 4 уровня (бронза до платины), разблокировка по прогрессу
- Установите правильный часовой пояс в параметрах > внешнем виде, чтобы обеспечить точную ежедневную статистику

## 10. Интеграция с AI Агентами через MCP

Вы хотите взаимодействовать с вашей библиотекой изображений из Claude Desktop или других совместимых с MCP инструментов AI.

### Шаги

1. Зарегистрируйте MCP сервер yu_ai_manager в вашем MCP клиенте (например, Claude Desktop):
   ```json
   {
     "command": "python",
     "args": ["-m", "mcp_server"],
     "env": { "YU_DB": "./tags.db" }
   }
   ```
2. Дайте естественные инструкции AI, такие как "поиск изображений" или "добавить это в избранное"
3. Доступно более 60 инструментов, включая `search_images`, `add_favorite` и `trigger_scan`

### Советы

- Расширение MCP Client также может подключаться к внешним MCP серверам (stdio / SSE / Streamable HTTP)
- С настроенной аутентификацией API Key внешние инструменты могут вызывать REST API напрямую без заголовков CSRF
- Расширение Hailo GenAI позволяет интеграцию через конечную точку, совместимую с OpenAI SDK

## 11. Использование Hailo-10H как OpenAI-совместимого сервера

Если у вас есть Hailo-10H NPU, вы можете использовать его как локальный AI сервер с полной совместимостью OpenAI SDK. Внешние инструменты, такие как Open WebUI, Continue.dev и пользовательские скрипты, могут напрямую получить доступ к LLM Hailo, VLM, речь-в-текст и встраиванию CLIP.

### Поддерживаемые конечные точки

| Конечная точка | Функция | Эквивалент OpenAI API |
|---|---|---|
| `GET /ext/hailo-genai/v1/models` | Список загруженных моделей | List Models |
| `POST /ext/hailo-genai/v1/chat/completions` | Создание текста и понимание изображения (VLM) | Chat Completions |
| `POST /ext/hailo-genai/v1/audio/transcriptions` | Речь-в-текст | Audio Transcriptions |
| `POST /ext/hailo-genai/v1/embeddings` | Текст-в-вектор (CLIP) | Embeddings |

### Шаги

1. Подтвердите, что расширение Hailo GenAI включено в **Extensions > GenAI**
2. Загрузите необходимые модели (LLM: `qwen2.5-1.5b-chat`, VLM: `llava-v1.6-vicuna-7b`, и т.д.)
3. Установите **Base URL** в параметрах подключения внешнего инструмента:
   ```
   http://localhost:5000/ext/hailo-genai/v1
   ```
   (Отрегулируйте номер порта в соответствии с конфигурацией yu_ai_manager)
4. API ключ не требуется для локального доступа. Если инструмент требует его, введите фиктивное значение (например, `dummy`)

### Подключение внешних инструментов

#### Open WebUI

В параметрах > подключения > OpenAI API добавьте:
- **URL**: `http://localhost:5000/ext/hailo-genai/v1`
- **API Key**: `dummy`

#### Continue.dev (VS Code AI Assistant)

Добавьте в `~/.continue/config.json`:
```json
{
  "models": [{
    "title": "Hailo Qwen2.5",
    "provider": "openai",
    "model": "qwen2.5-1.5b-chat",
    "apiBase": "http://localhost:5000/ext/hailo-genai/v1",
    "apiKey": "dummy"
  }]
}
```

#### Python (OpenAI SDK)

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:5000/ext/hailo-genai/v1",
    api_key="dummy",
)

# Создание текста
res = client.chat.completions.create(
    model="qwen2.5-1.5b-chat",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(res.choices[0].message.content)

# Понимание изображения (VLM) — присоедините изображение в base64
import base64
with open("image.png", "rb") as f:
    b64 = base64.b64encode(f.read()).decode()

res = client.chat.completions.create(
    model="llava-v1.6-vicuna-7b",
    messages=[{
        "role": "user",
        "content": [
            {"type": "text", "text": "Describe this image."},
            {"type": "image_url", "image_url": {"url": f"data:image/png;base64,{b64}"}},
        ],
    }],
)

# Речь-в-текст
res = client.audio.transcriptions.create(
    model="whisper-1",
    file=open("audio.wav", "rb"),
)

# Встравивание текста (CLIP)
res = client.embeddings.create(
    model="clip",
    input="a girl standing by the sea",
)
print(len(res.data[0].embedding))  # 512
```

### Поддерживаемые параметры

- **Chat Completions**: `model`, `messages`, `stream`, `temperature` (0–2), `max_tokens` (64–2048)
- **Audio Transcriptions**: `model`, `file`, `language`, `response_format` (json / text / verbose_json)
- **Embeddings**: `model`, `input` (string или массив строк)
- **Синонимы модели**: `whisper-1` → whisper-base, `clip` / `text-embedding-clip` → clip-vit-b-16

### Важные примечания

- **Эксклюзивность устройства**: Hailo-10H может загружать только одну модель GenAI (LLM, VLM или S2T) одновременно. Переключайте режимы со страницы GenAI
- **Ограничение URL изображения**: Для безопасности URL изображений `http://` блокируются. Используйте формат `data:image/...;base64,...` или расширение yu_ai_manager `file_id:` вместо
- **Встраивание CLIP**: Поддерживается только текст-в-вектор. Для векторизации изображения используйте конечную точку `/api/semantic/`
- **Форматы аудио**: Форматы, отличные от WAV (MP3, M4A, OGG, и т.д.), требуют установки ffmpeg
- **Поле `usage`**: Количество токенов всегда возвращает 0 (ограничение Hailo NPU)
