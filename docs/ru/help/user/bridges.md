# Bridge-интеграции

Функция Bridge позволяет отправлять промпты из YU AI Manager напрямую в различные инструменты AI-генерации изображений.

## Поддерживаемые Bridge

### SD WebUI Bridge
Интеграция с Stable Diffusion WebUI (Automatic1111 / Forge).
- Отправка и получение промптов
- Передача параметров генерации

### NAI Bridge
Интеграция с NovelAI.
- Автоматическая конвертация синтаксиса промптов (SD ↔ NAI)
- Автоматическая вставка тегов качества

#### Vibe Transfer (зелье NovelAI) и кеш encode-vibe

Модели NAI V4+ требуют предварительного кодирования референсных изображений через `/ai/encode-vibe`
(**2 Anlas за вызов**) перед использованием в запросах генерации.

Чтобы избежать лишних расходов Anlas при повторной генерации с одним и тем же изображением,
результаты кодирования сохраняются в локальном кеше:

```
data/nai_vibe_cache/<sha256>__<model>__<info_extracted>.bin
```

- **Ключ**: SHA256 исходного изображения + имя модели + степень извлечения информации (шаг 0,01)
- **Максимальный размер**: 500 МБ по умолчанию. Меняется в Settings > NAI Bridge > «Vibe encode cache (MB)» (0 = отключено)
- **LRU-вытеснение**: самые старые файлы удаляются в фоновом потоке при превышении лимита

### ComfyUI Bridge
Интеграция с ComfyUI.
- Вставка промптов в воркфлоу
- Настройка формата вывода

## Пакетная генерация

Все три Bridge поддерживают пакетную генерацию в основном пути генерации (семантика, совместимая с A1111).

### Batch count / Batch size

- **Batch count** — Количество последовательных запусков генерации (временная ось). Клиент вызывает API по одному разу за итерацию.
- **Batch size** — Количество изображений, генерируемых параллельно за один вызов API (ось VRAM). Не отображается в NAI Bridge.
- Итого изображений = Batch count × Batch size

При фиксированном Seed значение seed увеличивается в виде `base + i` на каждой итерации цикла (то же поведение, что и в A1111). При `-1` (случайном) каждый раз используется новый случайный seed.

### Кнопки остановки

| Bridge | Одиночный запуск (count=1) | Loop (count>1) |
|---|---|---|
| NAI | Кнопки остановки нет | Только «Остановить после текущего» |
| SD WebUI | «Остановить» (API отмены сервера) | «Остановить после текущего» + «Остановить» |
| ComfyUI | «Остановить» (API отмены сервера) | «Остановить после текущего» + «Остановить» |

- **Остановить (немедленно)** — Прерывает текущий вызов API и останавливает цикл. Для SD WebUI / ComfyUI также вызывается API отмены на сервере.
- **Остановить после текущего** — Позволяет текущему изображению завершить генерацию, после чего следующая итерация не запускается.

NAI Bridge не показывает кнопку остановки для одиночной генерации, потому что API NAI списывает Anlas (кредиты) в момент принятия запроса fetch. Разрыв HTTP-соединения не останавливает генерацию на стороне сервера и не возвращает средства — кнопка остановки только вводила бы пользователей в заблуждение.

### Замечание о VRAM

Увеличение Batch size пропорционально увеличивает потребление VRAM GPU сервера. При SDXL с Batch size 4 и выше возможны ошибки OOM — начните с 1 и увеличивайте постепенно.

## Пресеты качества

Кнопка «QP» на панели инструментов каждого Bridge позволяет одним кликом вставить теги улучшения качества.

Встроенные пресеты:
- SD High Quality
- SD Realistic
- NAI Quality
- NAI Artistic
- Minimal

Можно создавать собственные пресеты.

## Пресеты разрешения

Над полями Width/Height в SD WebUI Bridge и ComfyUI Bridge есть выпадающий список «Resolution Preset» и кнопка ⇄ Swap. Позволяет выбрать популярные разрешения одним кликом.

- **SD 1.5** — 5 вариантов на базе 512 для моделей SD1.5
- **SDXL Trained** — 9 официальных обучающих бакетов SDXL (приоритет качества)
- **SDXL Cheat Sheet** — 12 вариантов с соотношениями сторон кино/фото, округлёнными до кратных 8 (приоритет композиции, источник [Civitai](https://civitai.com/articles/2246/sdxl-image-size-cheat-sheet))

При выборе `Custom` сохраняются текущие значения W/H. Кнопка ⇄ меняет Width и Height местами.

Разрешения из Cheat Sheet выходят за пределы официальных бакетов, поэтому у некоторых моделей возможно незначительное нарушение композиции.

> В ComfyUI Bridge применяется только в режиме Simple. Не влияет на значения узлов в режиме Raw JSON Workflow.

## Передача между Bridge

Промпты можно передавать напрямую между Bridge. При передаче SD ↔ NAI синтаксис конвертируется автоматически.
