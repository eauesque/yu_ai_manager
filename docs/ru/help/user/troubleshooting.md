# Устранение неполадок

## Распространённые проблемы

### Сервер не запускается

- Убедиться, что виртуальное окружение активировано: `source venv/bin/activate`
- Убедиться, что зависимости установлены: `uv pip install -r requirements.txt`
- Убедиться, что порт не занят: `ss -tlnp | grep 5000`

### Изображения не отображаются

- API миниатюр требует физического наличия файлов изображений
- Проверить, что пути в таблице `files` совпадают с реальными путями к файлам
- Проверить правильность пути к корневой директории сканирования

### Нет доступа из LAN

- Убедиться, что «LAN Access» включён в Settings > Server
- Убедиться, что PIN-аутентификация настроена (обязательна при публикации в LAN)
- Убедиться, что порт открыт в брандмауэре
- Проверить правильность IP-адреса сервера

### Ошибка подключения MCP

- Проверить корректность `YU_BASE_URL`
- Убедиться, что сервер запущен
- Проверить действительность API-ключа
- При LAN-подключении — убедиться, что HTTP/SSE эндпоинт (`/mcp`) доступен

### Медленное сканирование

- Отключение `compute_hash` ускоряет процесс
- При удалённых путях — скорректировать настройки таймаута Remote FS
- При большом количестве файлов первое сканирование требует времени

### Медленная генерация миниатюр

- Во время сканирования I/O диска насыщен, генерация миниатюр замедляется. После завершения сканирования выполняется автопрогрев
- **pyvips (опционально)**: При большом количестве крупных JPEG-изображений ускорение через shrink-on-load libvips
  - Linux: `sudo apt install libvips-dev && uv pip install pyvips`
  - macOS: `brew install vips && uv pip install pyvips`
- **Pillow-SIMD (опционально)**: Ускорение масштабирования в 2–4 раза через ARM NEON / x86 AVX2
  - `uv pip install pillow-simd`

## Отладка

- Просмотр серверных логов на вкладке Settings > Logs
- Режим отладки MCP: `YU_DEBUG_MODE=1` добавляет дополнительные инструменты
- Проверка целостности DB: `python db_health.py`
