# Модель безопасности Extension

Это программное обеспечение позиционируется как система, где «каждый может создать Extension с помощью AI».
При этом в него встроены механизмы защиты системы от вредоносных Extension.

На этой странице объясняются эти механизмы.
Описание доступно для понимания не только разработчикам.

---

## Основная концепция

Extension работают в **защищённой среде**.

Внутри этой защищённой среды Extension могут действовать относительно свободно.
Добавлять страницы, отображать данные, обрабатывать изображения — это работа Extension.

Однако то, что находится **вне** защищённой среды — ядро системы (core), другие Extension,
все файлы на вашем PC — им недоступно.
Это не «запрещено правилами», а **физически недостижимо** по своей архитектуре.

---

## Механизм разрешений

Для любого действия Extension необходимо **разрешение**.

Разрешения спроектированы по той же модели, что и разрешения приложений смартфона.

- Камере нормально запрашивать доступ к камере
- Странно, когда камера запрашивает доступ к контактам

Extension — то же самое. Если Extension для нанесения водяных знаков запрашивает сетевой доступ,
это должно вызывать подозрение.

### Процесс утверждения

1. Установить Extension (или попросить AI создать)
2. YU AI Manager автоматически сканирует код и проверяет, что он пытается делать
3. Отображается список запрашиваемых разрешений
4. **Extension не запускается, пока вы не утвердите**

Внимательно читайте информацию на экране утверждения.
Особо обращайте внимание на разрешения, выделенные красным.

### После утверждения разрешений

Extension работает в пределах утверждённых разрешений.
Неутверждённые разрешения Extension не может использовать, как бы ни старался.
Не «попытка отклонена» — а «вообще не видно».

---

## Три независимых уровня мониторинга

Extension мониторируется тремя независимыми механизмами.
Они независимы друг от друга — если один обманули, остальные два продолжают работать.

### 1. Сканирование кода

Автоматический анализ кода Extension для выявления опасных паттернов.
Выполнение внешних программ, прямые операции с базой данных, динамическое выполнение кода —
всё это обнаруживается немедленно.

### 2. Контроль разрешений

При обращении Extension к API проверяется наличие действующего «разрешительного токена».
Токен выдаётся только при утверждении вами разрешения.
Extension не может подделать токен самостоятельно.

### 3. Журнал аудита

Все операции Extension записываются.
Эти записи хранятся в независимом месте, недоступном для изменения самим Extension.

При обнаружении аномалии — например, попытке выполнить необъявленное действие —
автоматически поступает уведомление, и при необходимости токен Extension аннулируется.

## Создание Extension с помощью AI

При создании Extension через Claude Desktop, созданный Extension автоматически
регистрируется с **самым ограничительным уровнем**.

Это как не давать новому сотруднику ключи от сейфа с первого дня.
Сначала запускаем с ограниченными правами, убеждаемся в отсутствии проблем,
затем при необходимости добавляем разрешения.

### Что может Extension, созданный AI

**Без утверждения**:
- Отображение и чтение данных
- Добавление страниц в UI
- Добавление экранов настроек

**Требует утверждения**:
- Обмен данными с внешними сервисами
- Запись в базу данных
- Чтение файлов

**Невозможно при любых условиях**:
- Чтение или изменение ядра системы (core)
- Чтение или изменение других Extension
- Запуск внешних программ
- Подделка токенов

---

## Периодические проверки

Утверждение Extension — это не одноразовое событие.

Если код изменяется и объём изменений превышает определённый порог, требуется **повторное утверждение**.
Это защита от приёма «постепенно меняй, и незаметно превратится в нечто совершенно другое».

Также автоматически выполняются периодические повторные проверки кода.
Даже если при утверждении проблем не было, новые правила проверки могут обнаружить их позже.

---

## Что вы должны делать

1. **Внимательно читайте экран утверждения разрешений** — понимайте, что запрашивается, прежде чем утверждать
2. **Отклоняйте необычные запросы разрешений** — обработке изображений сеть не нужна
3. **Не игнорируйте уведомления** — при обнаружении аномалии проверьте
4. **Не устанавливайте Extension из ненадёжных источников** — это само собой разумеется

В обратную сторону — если вы делаете только это, всё безопасно.
Остальное защитит механизм.
