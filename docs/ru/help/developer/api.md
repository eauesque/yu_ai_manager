# Обзор API

YU AI Manager предоставляет REST API, позволяющий программно выполнять все операции WebUI.
Более 320 эндпоинтов охватывают широкий спектр операций — от управления изображениями до AI-анализа.

> **Подсказка**: Детальные общие соглашения (аутентификация, CSRF, ограничение скорости, формат ответов) — в разделе «Справочник API».

## Аутентификация

Поддерживаются 4 способа аутентификации.

| Способ | Назначение | Заголовок/параметр |
|--------|-----------|-------------------|
| PIN-аутентификация | Сессии браузера | Вход через `/_pin` → сессионный cookie |
| API Key | Взаимодействие между сервисами / MCP | `Authorization: Bearer sk_xxxx` |
| Trusted Proxy | Обратный прокси | Заголовок `X-Remote-User` |
| LAN Share токен | Гостевой доступ | Путь `/s/<token>` |

### Примеры тестирования через curl

```bash
# Аутентификация по API Key (заголовок CSRF не нужен)
curl -H "Authorization: Bearer sk_your_key" \
     http://localhost:5000/api/search?tags=1girl

# В среде с PIN-аутентификацией нужны 2 шага
# 1. Получить CSRF-токен
curl -c cookies.txt http://localhost:5000/_pin
# 2. Отправить PIN
curl -b cookies.txt -X POST \
     -H "X-Requested-With: XMLHttpRequest" \
     -d "pin=1234" http://localhost:5000/_pin_check
```

### Защита CSRF

Для всех POST/PUT/DELETE эндпоинтов `/api/` обязателен заголовок `X-Requested-With`.
Для запросов с Bearer API Key не требуется.

## Основные эндпоинты

### Поиск и просмотр изображений

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/search` | Поиск с фильтрами по тегам, дате, рейтингу и т.д. |
| GET | `/api/search-grouped` | Поиск с группировкой по папкам/ZIP |
| GET | `/api/file/<id>` | Детальные метаданные изображения |
| GET | `/api/thumbnail/<id>` | Миниатюра (WebP, кэш ETag) |
| GET | `/api/original/<id>` | Оригинальное изображение (поддержка Range) |
| GET | `/api/suggest` | Кандидаты для автодополнения тегов |

### Рейтинги, теги и аннотации

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/api/ratings/batch-set` | Массовая установка рейтингов |
| POST | `/api/tags/batch-set` | Массовое редактирование тегов |
| POST | `/api/annotations/batch-set` | Массовая установка аннотаций |
| GET | `/api/annotations/<id>` | Получить аннотации |
| GET | `/api/annotations/search` | Поиск аннотаций |

### Коллекции

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/collections` | Список коллекций |
| POST | `/api/collections` | Создать коллекцию |
| PUT | `/api/collections/<id>` | Переименовать коллекцию |
| DELETE | `/api/collections/<id>` | Удалить коллекцию |
| POST | `/api/collections/<id>/batch-add` | Массовое добавление файлов |
| POST | `/api/collections/<id>/batch-remove` | Массовое удаление файлов |

### Сканирование

| Метод | Путь | Описание |

### AI-анализ

## Формат ответов

Все API отвечают в унифицированном формате JSON.

```json
{
  "ok": true,
  "data": { ... },
  "error": null
}
```

При ошибке:

```json
{
  "ok": false,
  "data": null,
  "error": "Сообщение об ошибке"
}
```

## Ограничение скорости

Трёхуровневая схема token bucket.

| Уровень | Область | Лимит | Burst |
|---------|---------|-------|-------|
| READ | Все GET-запросы | Без ограничений | — |
| WRITE | POST/PUT/DELETE | ~120 req/min | 30 |
| HEAVY | Семантический поиск, AI-анализ, сканирование | ~20 req/min | 5 |
| DESTRUCTIVE | purge, hard-delete, запись конфигурации | ~12 req/min | 3 |

При превышении возвращается HTTP 429. Время ожидания указано в заголовке `Retry-After`.

## SSE (Server-Sent Events)

События в реальном времени доставляются через SSE по адресу `/api/events/stream`.
Подробности в разделе «SSE-события».

> **Примечание**: Максимум 10 одновременных подключений с одного IP. Лимит загрузки — 100 МБ.
