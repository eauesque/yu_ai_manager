# Модальная панель инструментов

Единая панель инструментов в нижней части модального окна деталей обеспечивает доступ ко всем основным элементам управления при просмотре изображений/видео.

## Структура

### Основная панель (всегда видима)

**Режим неподвижного изображения:**
- ☆ Избранное
- ⓘ Переключить информационную панель
- ‹ › Предыдущее / Следующее
- Масштаб (− / 100% / +)
- Режим подгонки (fit / fit-w / fit-h / fit-custom + высота / original)
- Spread 2P / направление ↔ (если применимо)
- ⛶ Иммерсивный / ⤢ Полный экран
- 📁 Коллекция
- Bridge Отправить (Отправить подсказку ▾ / Отправить изображение ▾)

**Режим видео/аудио (двухуровневая раскладка):**
- Верхняя: отображение времени + полоса поиска (макс. ширина 720px)
- Нижняя: ☆ Избранное / ⓘ Информация / ‹ › / ▶ Воспроизведение ⏪ ⏩ / ♪ Без звука + громкость / ⛶ ⤢ / 📁

### Меню переполнения (кнопка …)

Объединяет редко используемые операции в вертикальный список:
- Автоматическое воспроизведение + интервал
- Повтор / скорость / возобновление (для видео)
- FPB / сетка символов (для неподвижных изображений)
- ZIP / просмотр контейнера
- Справка по клавиатуре ?
- Свернуть панель инструментов «

## Сочетания клавиш

| Клавиша | Действие |
|---|---|
| `T` | Переключить видимость панели инструментов |
| `V` | Иммерсивный режим |
| `F` | Полный экран |
| `I` | Информационная панель |
| `H` | Справка по клавиатуре |
| `P` | Автоматическое воспроизведение |
| `Space` / `K` | Воспроизведение / пауза (видео) |
| `J` / `0` | Перемотка назад (видео) |
| `L` | Ускоренное воспроизведение (видео) |
| `M` | Без звука (видео) |
| `R` | Повтор (видео) |
| `←` / `→` | Предыдущее / следующее изображение |
| `ESC` | Закрыть меню переполнения → модальное окно по порядку |

## Свертывание и восстановление

Способы свертывания панели инструментов:
- В меню переполнения (…) выберите "Свернуть панель инструментов"
- Нажмите клавишу `T`

Способы восстановления:
- Нажмите на рукоятку края в центре нижней части экрана
- Нажмите клавишу `T` еще раз

Положение рукоятки края автоматически регулируется в зависимости от наличия киноленты в свернутом состоянии.

## Доступность

- Вся панель инструментов имеет `role="toolbar"`
- Кнопка переполнения использует `aria-haspopup="menu"` / `aria-expanded` обновляется динамически
- Пункты меню переполнения имеют `role="menuitem"`
- Рукоятка края является стандартной `<button>` управляемой с помощью Enter / Пробел
- Чтобы соответствовать WCAG 2.5.5 (Размер цели), визуально 8px рукоятка имеет невидимую область попадания 24px в высоту, расширенную через `::before`
