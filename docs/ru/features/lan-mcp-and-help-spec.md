# Спецификация доступа LAN MCP и конечной точки справки

**Версия реализации**: 3.1.0
**Связанная документация**: `docs/en/features/mcp-integration-guide.md`
**Связанные файлы**: `routes/mcp_endpoint.py`, `routes/help.py`, `mcp_server/help_tools.py`

---

## Обзор

1. **Доступ LAN MCP** — разрешить MCP клиентам на LAN подключаться к конечной точке MCP по IP адресу когда включён режим совместного использования LAN
2. **Конечная точка `/help`** — обеспечить встроенное веб-руководство для приложения (также опубликовано как MCP ресурс)

---

## 1. Доступ LAN MCP

### 1-1. Архитектура

Через LAN MCP клиенты подключаются непосредственно к конечной точке YU AI Manager `/mcp` используя HTTP/SSE транспорт.

### 1-2. Конечная точка MCP SSE

| Элемент | Детали |
|------|------|
| Конечная точка | `/mcp` (SSE + постинг сообщений) |
| Транспорт | HTTP + Server-Sent Events (SSE) |
| Аутентификация | Не требуется с localhost. API ключ требуется с IP адресов LAN |

### 1-3. Аутентификация API ключа

Существующий механизм управления API ключами (`/api/keys`) переиспользуется.

### 1-4. UI параметров

Фрагмент конфигурации подключения LAN MCP (версия HTTP) добавляется на вкладку Settings > API Keys.

---

## 2. Конечная точка `/help`

### 2-1. Принципы проектирования

- Полностью автономный
- Двойное назначение как MCP ресурс
- Аутентификация не требуется

### 2-2. Конечные точки

| Конечная точка | Содержание |
|----------------|------|
| `GET /help` | Главная страница руководства |
| `GET /help/<section>` | Страница, специфичная для раздела |
| `GET /api/help/toc` | Таблица содержания JSON |
| `GET /api/help/content/<section>` | Тело раздела JSON |

### 2-3. MCP инструменты

- `help_search`: Поиск по ключевому слову
- `help_get_section`: Получение раздела
