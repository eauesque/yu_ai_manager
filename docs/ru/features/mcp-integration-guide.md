# Руководство по интеграции MCP — управление YU AI Manager с LLM

YU AI Manager имеет встроенный **MCP (Model Context Protocol)** сервер, который позволяет LLM приложениям управлять библиотекой изображений, используя естественный язык.

Встроенный в это приложение интерфейс чата отсутствует.
Чтобы взаимодействовать с ним, используя естественный язык, подключитесь из вашего предпочтительного MCP-совместимого клиента.

---

## Что такое MCP?

MCP (Model Context Protocol) — это стандартный протокол, который позволяет LLM приложениям получать доступ к внешним инструментам и источникам данных.
YU AI Manager действует как MCP сервер, и LLM клиенты (такие как Claude Desktop) подключаются к нему, переводя инструкции на естественном языке в операции API.

```
┌─────────────────┐      MCP (stdio)       ┌─────────────────────┐
│  LLM Client     │ <--------------------> │  YU AI Manager      │
│  (Claude Desktop │                        │  MCP Server         │
│   / Open WebUI   │                        │  (python -m         │
│   / Cline и т.д.)  │                        │   mcp_server)       │
└─────────────────┘                        └────────┬────────────┘
                                                     │ HTTP API
                                                     v
                                           ┌─────────────────────┐
                                           │  YU AI Manager      │
                                           │  Web Server          │
                                           │  (localhost:5000)    │
                                           └─────────────────────┘
```

## Поддерживаемые MCP клиенты

Ниже представлены репрезентативные MCP-совместимые клиенты. Шаги конфигурации похожи для всех них.

| Клиент | Провайдер | Функции |
|---|---|---|
| **Claude Desktop** | Anthropic | Прямой доступ Claude. Встроенная поддержка MCP |
| **Claude Code** | Anthropic | Клиент на основе терминала для разработчиков |
| **Cline** | VS Code Extension | Интеграция редактора. Поддержка нескольких LLM |
| **Open WebUI** | Open Source | Самостоятельно размещённый. Может быть объединён с локальными LLM, такими как Ollama |

Примечание: Количество MCP-совместимых клиентов быстро растёт.
Любой клиент, поддерживающий stdio транспорт, должен быть в состоянии подключиться.

## Установка

### 1. Запустите YU AI Manager

MCP сервер работает через Web сервера API, поэтому YU AI Manager должен работать сначала.

```bash
python web_ui.py --db ./tags.db --port 5000
```

### 2. Выпустить API ключ (рекомендуется)

Выпуск API ключа позволяет MCP серверу обойти аутентификацию PIN при использовании совместного использования LAN или аутентификации PIN.

API ключи могут быть выпущены из Settings -> API Keys.

API ключ не требуется при запуске без PIN (`config_test.json`).

### 3. Добавить параметры подключения в ваш MCP клиент

#### Claude Desktop

Отредактируйте `claude_desktop_config.json`:

**Windows**: `%APPDATA%\Claude\claude_desktop_config.json`
**macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`

```json
{
  "mcpServers": {
    "yu-ai-manager": {
      "command": "python",
      "args": ["-m", "mcp_server"],
      "cwd": "C:/path/to/yu_ai_manager",
      "env": {
        "YU_BASE_URL": "http://127.0.0.1:5000",
        "YU_API_KEY": "sk_your_api_key_here"
      }
    }
  }
}
```

#### Claude Code

Добавьте параметры в `.mcp.json` в корне проекта, или используйте команду `claude mcp add`:

```json
{
  "mcpServers": {
    "yu-ai-manager": {
      "command": "python",
      "args": ["-m", "mcp_server"],
      "cwd": "/path/to/yu_ai_manager",
      "env": {
        "YU_BASE_URL": "http://127.0.0.1:5000",
        "YU_API_KEY": "sk_your_api_key_here"
      }
    }
  }
}
```

#### Cline (VS Code)

Введите ту же информацию через параметры MCP Cline.

#### Переменные окружения

| Переменная | Требуется | По умолчанию | Описание |
|---|---|---|---|
| `YU_BASE_URL` | - | `http://localhost:5000` | URL веб-сервера |
| `YU_API_KEY` | - | Нет | API ключ (требуется в окружениях PIN) |
| `YU_DEBUG_MODE` | - | `0` | Установить на `1` для добавления инструментов отладки |

## Примеры использования

После подключения вы можете управлять библиотекой изображений, давая LLM инструкции на естественном языке.

### Поиск и просмотр

```
"Show me the 20 most recent images of girls with blue eyes"
"Filter to only images generated with NovelAI"
"Show me statistics for images scanned last week"
```

### Организация и классификация

```
"Give these 10 images a 5-star rating"
"Add images tagged 'landscape' to the 'Scenery Collection'"
"List all images with a rating of 3 or below"
```

### Анализ и аннотирование

```
"Score the quality of recently added images and save to annotations"
"Show me all annotations for image ID 12345"
"Search for annotations with source agent:claude"
```

### Операции сканирования

```
"Scan for new images"
"Check the scan progress"
"Show me any scan errors"
```

## Доступные инструменты

MCP сервер предоставляет следующие инструменты LLM:

### Поиск и просмотр (4 инструмента)

| Имя инструмента | Описание |
|---|---|
| `search_images` | Поиск изображений по тегам, дате, формату, рейтингу и т.д. |
| `get_image_detail` | Получить все метаданные для изображения |
| `get_library_stats` | Статистика библиотеки (количество файлов, количество тегов, распределение источников и т.д.) |
| `find_similar` | Поиск похожих изображений, используя перцептивный хеш |

### Коллекции (4 инструмента)

| Имя инструмента | Описание |
|---|---|
| `list_collections` | Список коллекций |
| `create_collection` | Создать коллекцию |
| `delete_collection` | Удалить коллекцию |
| `add_to_collection` / `remove_from_collection` | Добавить/удалить изображения |

### Теги и рейтинги (2 инструмента)

| Имя инструмента | Описание |
|---|---|
| `rate_images` | Установить рейтинги звёзд для нескольких изображений одновременно |
| `set_tags` | Добавить/удалить теги для нескольких изображений одновременно |

### Аннотации (4 инструмента)

| Имя инструмента | Описание |
|---|---|
| `set_annotations` | Сохранить результаты анализа AI как аннотации |
| `get_annotations` | Получить аннотации для изображения |
| `search_annotations` | Поиск аннотаций по источнику, ключу и уверенности |
| `delete_annotations` | Удалить аннотации |

### Сканирование (3 инструмента)

| Имя инструмента | Описание |
|---|---|
| `trigger_scan` | Запустить сканирование |
| `get_scan_status` | Проверить прогресс сканирования |
| `get_scan_errors` | Список ошибок сканирования |

### Другие

Инструменты для библиотеки приглашений, резервного копирования и управления клиентом MCP также включены.

## Часто задаваемые вопросы

### В: Нет ли в приложении функции чата?

О: Нет. YU AI Manager специализируется на управлении метаданными изображений, а интерфейс диалога с AI делегируется MCP-совместимым клиентам. Вы можете выполнять все операции с использованием естественного языка, запустив Claude Desktop или аналогичный клиент рядом.

### В: Какой LLM я должен использовать?

О: Будет работать любой LLM, если MCP клиент его поддерживает.
Для надёжной обработки аргументов инструмента большие модели, такие как Claude или GPT-4 класс, как правило, работают наиболее последовательно.

### В: Могу ли я использовать локальный LLM?

О: Да, локальные LLM работают с комбинациями, такими как Open WebUI + Ollama, при условии, что они поддерживают MCP. Однако точность вызова инструмента зависит от возможностей модели.

### В: YU AI Manager также имеет функцию MCP клиента?

О: Расширение `MCP Client` (на странице Tools) подключает YU AI Manager к **другим MCP серверам**. Это руководство описывает противоположное направление: внешний LLM -> YU AI Manager.
