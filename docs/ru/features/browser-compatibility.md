# Отчёт о совместимости браузеров

**Дата исследования:** 2026-02-23

## Поддерживаемые браузеры (рекомендуется)

| Браузер  | Минимальная версия | Полная функциональность |
|----------|----------------|---------------------|
| Chrome   | 80+            | 94+                 |
| Firefox  | 74+            | 101+                |
| Safari   | 13.1+          | 16+                 |
| Edge     | 80+            | 94+                 |

IE11 и более старые версии не поддерживаются.

## Совместимость API

| Функция | Chrome | Firefox | Safari | Edge | Примечания |
|---------|--------|---------|--------|------|-------|
| Fetch API / async/await | 55+ | 52+ | 11+ | 15+ | Все браузеры поддерживают |
| AbortController | 66+ | 57+ | 11.1+ | 16+ | Все браузеры поддерживают |
| IntersectionObserver | 51+ | 55+ | 12.1+ | 16+ | Используется для бесконечной прокрутки |
| Optional chaining `?.` | 80+ | 74+ | 13.1+ | 80+ | Широко используется в коде |
| scroll-snap | 69+ | 68+ | 13+ | 79+ | Используется для карточек панели |
| `scrollbar-gutter` | 94+ | 101+ | **16+** | 94+ | Не поддерживается в Safari 15 и более ранних |
| `inset` CSS shorthand | 102+ | 106+ | **16+** | 102+ | Не поддерживается в Safari 15 и более ранних |
| `backdrop-filter` | 76+ | **Не поддерживается** | 9+ | 79+ | Не поддерживается в Firefox |
| `-webkit-backdrop-filter` | ✓ | **Не поддерживается** | 9+ | ✓ | Нет альтернативы для Firefox |

## Известные проблемы

### 🔴 Firefox — `backdrop-filter` не поддерживается

- **Затронутые файлы:** `dock-shell-panel.css`, `search-results-modal-nav.css`
- **Симптом:** Эффект размытия панели (glassmorphism) не отображается, оставляя фон прозрачным
- **Важность:** Снижение визуального качества (функциональность не затронута)
- **План:** Не решено (резервный вариант с непрозрачным фоном для Firefox может быть добавлен в будущем)

### 🟡 Safari 15 и более ранние — `scrollbar-gutter`, `inset` не поддерживаются

- **Затронутые файлы:** `dock-cards.css`, `uxpatch-i18n-paths.css`
- **Симптом:** Дрожание области прокрутки и незначительные смещения вычисления позиции
- **Важность:** Незначительно (макет остаётся функциональным)

---

## Существующие меры совместимости (лучшие практики)

- Объявлены как `-webkit-backdrop-filter`, так и стандартный `backdrop-filter`
- Прокрутка Firefox использует `scrollbar-width` / `scrollbar-color`
- Прокрутка WebKit использует `-webkit-scrollbar`
- Деструктивные API (`crypto.randomUUID`, `structuredClone`, `.at()` и т.д.) не используются
