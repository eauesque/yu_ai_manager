# Горячая клавиша для буфера обмена Bridge

На страницах NAI Bridge / ComfyUI Bridge / SD WebUI Bridge горячая клавиша позволяет
мгновенно отправить текст буфера обмена в поле приглашения. Когда вы скопировали приглашение
из другого окна, вы можете применить его без необходимости сначала щёлкать в текстовую область.

## Горячая клавиша

| ОС | Клавиши |
|---|---|
| Windows / Linux | `Ctrl` + `Alt` + `V` |
| macOS | `⌘` + `⌥` + `V` |

Это добавляется рядом с встроенной функцией вставки браузера (`Ctrl`+`V`) и не
мешает существующему поведению вставки.

## Поведение

1. Откройте одну из страниц Bridge
2. Скопируйте текст из внешнего источника (`Ctrl`+`C`)
3. Нажмите `Ctrl`+`Alt`+`V` пока страница Bridge в фокусе
4. Выбор цели:
   - Если текстовое поле в фокусе → вставлено в позицию каретки в это текстовое поле
   - Если ничего не в фокусе → вставлено в поле позитивного приглашения (NAI: `#nabPrompt` / ComfyUI: `#cfbPrompt` / SD: `#sdwbPrompt`)
5. При успехе отображается уведомление «Текст буфера обмена вставлен»

## Целевые поля

| Bridge | Приоритет целей |
|---|---|
| NAI Bridge | `nabPrompt` → `nabNegative` |
| ComfyUI Bridge | `cfbPrompt` → `cfbNegative` → `cfbWorkflowJson` |
| SD WebUI Bridge | `sdwbPrompt` → `sdwbNegative` |

## Разрешения браузера

Это использует **Clipboard API** браузера (`navigator.clipboard.readText()`),
поэтому браузер может запросить у вас разрешение на чтение из буфера обмена при первом использовании.
Если вы отклоните его, функция не будет работать.

На старых браузерах, где Clipboard API недоступен, отображается уведомление «Clipboard API
недоступен» и ничего не происходит. Обычная вставка `Ctrl`+`V` продолжает работать как раньше.

## Ограничения

- Некоторые браузеры требуют HTTPS или `localhost` чтобы `navigator.clipboard` был
  доступен (Chrome разрешает `localhost`)
- Поддерживается только простой текст — не изображения или форматированный текст
- Элементы, отличные от `<textarea>` (например, области `contenteditable`), не являются целью
  даже если они в фокусе
