# API тегов

API для массовых операций с тегами и предложения/автозаполнения тегов.

## POST /api/tags/batch-set

Добавление или удаление тегов из нескольких файлов в одном запросе.

### Ограничение скорости

WRITE (~120 запросов/мин, всплеск 30)

### Тело запроса

| Поле | Тип | Обязательное | Описание |
|-------|------|----------|-------------|
| `items` | array | Да | Список операций (макс 500 элементов) |
| `items[].file_id` | int | Да | ID файла (положительное целое число) |
| `items[].add` | string[] | Нет | Имена тегов для добавления |
| `items[].remove` | string[] | Нет | Имена тегов для удаления |

- Каждый элемент требует хотя бы один из `add` или `remove`
- Теги, которые не существуют, создаются автоматически (namespace=null)
- Теги, добавленные через API, имеют свой источник установленный на `"user"`
- Сиротские теги (без оставшихся ассоциаций файлов) удаляются автоматически

### Пример запроса

```json
{
  "items": [
    {
      "file_id": 42,
      "add": ["landscape", "sunset"],
      "remove": ["lowres"]
    }
  ]
}
```

### Ответ

```json
{
  "total": 1,
  "succeeded": 1,
  "failed": 0,
  "errors": []
}
```

| Поле | Тип | Описание |
|-------|------|-------------|
| `total` | int | Общее количество обработанных элементов |
| `succeeded` | int | Количество успешных операций |
| `failed` | int | Количество неудачных операций |
| `errors` | array | Список деталей ошибок |

### Ошибки

| Статус | Описание |
|--------|-------------|
| 400 | Неверное тело запроса (пустые элементы, неверный file_id, оба add/remove отсутствуют и т.д.) |
| 429 | Превышен лимит скорости |

## GET /api/tags/suggest

Возвращение кандидатов тегов, соответствующих частичной строке поиска. Предназначено для автозаполнения.

### Параметры

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `q` | string | Да | Поисковая строка |
| `limit` | int | Нет | Максимальное количество результатов (по умолчанию: 20, максимум: 100) |

- Поиск без учета регистра (LIKE %q%)
- Результаты отсортированы по `file_count` в убывающем порядке
- Пустой `q` возвращает пустой массив

### Ответ

```json
{
  "data": [
    { "id": 1, "tag": "landscape", "namespace": null, "file_count": 150 },
    { "id": 2, "tag": "1girl", "namespace": null, "file_count": 3420 }
  ]
}
```

| Поле | Тип | Описание |
|-------|------|-------------|
| `data[].id` | int | ID тега |
| `data[].tag` | string | Имя тега |
| `data[].namespace` | string\|null | Пространство имен (обычно null) |
| `data[].file_count` | int | Количество файлов, связанных с этим тегом |
