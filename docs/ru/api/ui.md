# API управления UI

API для списания, переключения, установки и удаления тем UI.

## GET /api/ui/list

Список всех установленных UI. Возвращает информацию манифеста, статус активности и наличие файлов шаблонов/статических файлов для каждого UI.

### Параметры

Нет

### Ответ

```json
{
  "data": {
    "uis": [
      {
        "name": "default",
        "active": true,
        "manifest": {
          "name": "Default UI",
          "version": "1.0.0",
          "description": "Built-in reference UI"
        },
        "has_templates": true,
        "has_static": true
      },
      {
        "name": "custom-dark",
        "active": false,
        "manifest": {
          "name": "Custom Dark",
          "version": "0.2.0",
          "description": "Dark theme variant"
        },
        "has_templates": true,
        "has_static": true
      }
    ]
  }
}
```

| Поле | Тип | Описание |
|-------|------|-------------|
| `name` | string | Имя каталога UI |
| `active` | boolean | Является ли это текущим активным UI |
| `manifest` | object | Содержимое `manifest.json` |
| `has_templates` | boolean | Существует ли каталог `templates/` |
| `has_static` | boolean | Существует ли каталог `static/` |

## POST /api/ui/switch

Переключение активного UI. Изменение сохраняется в `config.json` и требует перезагрузки сервера для вступления в силу.

### Ограничение скорости

WRITE

### Запрос

```json
{
  "name": "custom-dark"
}
```

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `name` | string | Да | Имя целевого UI. Разрешены только буквенно-цифровые символы, дефисы и подчеркивания |

### Ответ

```json
{
  "name": "custom-dark",
  "restart_required": true
}
```

### Ошибки

| Статус | Условие |
|--------|-----------|
| 400 | Имя UI пусто или содержит недопустимые символы |
| 404 | Указанный UI не существует |
| 400 | `manifest.json` отсутствует или неверен |
| 500 | Ошибка сохранения `config.json` |

## POST /api/ui/install

Установка UI с URL. **Разрешено только с localhost.**

### Ограничение скорости

WRITE

### Аутентификация

Требуется аутентификация PIN или API Key, плюс запрос должен происходить с localhost. Удаленные запросы отклоняются с 403.

### Запрос

```json
{
  "url": "https://github.com/user/my-ui/archive/refs/heads/main.zip"
}
```

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `url` | string | Да | URL пакета UI (архив zip и т.д.) |

### Ответ

```json
{
  "name": "my-ui",
  "installed": true
}
```

### Ошибки

| Статус | Условие |
|--------|-----------|
| 400 | URL пуст |
| 403 | Запрос не с localhost |

## DELETE /api/ui/<name>/uninstall

Удаление UI. **Разрешено только с localhost.** UI по умолчанию (`default`) не может быть удален.

Если удаленный UI в настоящее время активен, параметр UI в `config.json` сбрасывается и восстанавливается UI по умолчанию.

### Ограничение скорости

WRITE

### Аутентификация

Требуется аутентификация PIN или API Key, плюс запрос должен происходить с localhost. Удаленные запросы отклоняются с 403.

### Параметры

| Параметр | Тип | Описание |
|-----------|------|-------------|
| `name` | string | Имя UI (параметр пути). Только буквенно-цифровые символы, дефисы и подчеркивания |

### Ответ

```json
{
  "name": "custom-dark",
  "uninstalled": true
}
```

### Ошибки

| Статус | Условие |
|--------|-----------|
| 400 | Неверное имя UI или попытка удаления `default` |
| 403 | Запрос не с localhost |
| 404 | Указанный UI не существует |
