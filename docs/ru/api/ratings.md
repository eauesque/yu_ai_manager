# API оценок

API для управления оценками файлов (оценки 1–5 звезд): установка, получение и просмотр статистики.

## POST /api/ratings/set

Установка оценки для файла. Указывайте `rating=0` для очистки оценки.

**Ограничение скорости**: WRITE

### Запрос

```json
{
  "file_id": 42,
  "rating": 5
}
```

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `file_id` | int | Да | ID файла (положительное целое число) |
| `rating` | int | Да | Значение оценки (0–5). 0 очищает оценку |

### Ответ

```json
{
  "file_id": 42,
  "rating": 5
}
```

## POST /api/ratings/batch-set

Установка оценок для нескольких файлов одновременно.

**Ограничение скорости**: WRITE

### Запрос

```json
{
  "items": [
    { "file_id": 1, "rating": 5 },
    { "file_id": 2, "rating": 3 }
  ]
}
```

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `items` | array | Да | Список записей оценок (макс 500) |
| `items[].file_id` | int | Да | ID файла (положительное целое число) |
| `items[].rating` | int | Да | Значение оценки (0–5) |

### Ответ

```json
{
  "total": 2,
  "succeeded": 2,
  "failed": 0,
  "errors": []
}
```

## GET /api/ratings/get

Получение оценки для файла. Возвращает `rating: 0`, если файл не оценен.

### Параметры

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `file_id` | int | Да | ID файла (параметр запроса) |

### Ответ

```json
{
  "file_id": 42,
  "rating": 5
}
```

> **Примечание**: Неоцененные файлы возвращают `rating: 0`.

## POST /api/ratings/batch

Получение оценок для нескольких файлов одновременно.

### Запрос

```json
{
  "file_ids": [1, 2, 3]
}
```

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `file_ids` | array | Да | Список ID файлов |

### Ответ

```json
{
  "ratings": {
    "1": 5,
    "3": 4
  }
}
```

> **Примечание**: В карте отображаются только оцененные файлы. Неоцененные файлы опускаются в ответе.

## GET /api/ratings/stats

Получение статистики оценок по всем файлам.

### Параметры

Нет.

### Ответ

```json
{
  "total_rated": 1234,
  "distribution": {
    "1": 50,
    "2": 100,
    "3": 300,
    "4": 500,
    "5": 284
  }
}
```

| Поле | Тип | Описание |
|-------|------|-------------|
| `total_rated` | int | Общее количество оцененных файлов |
| `distribution` | object | Количество файлов на значение оценки (1–5) |
