# API отладки

Внутренние API для отладки и диагностики. Используются для проверки метаданных файлов, проверки информации о моделях и управления сканируемыми корневыми каталогами.

Эти конечные точки не имеют интерфейса веб-сайта и предназначены в основном для разработки и устранения неполадок.

## GET /api/debug/file-meta/<file_id>

Проверить подробные метаданные для файла. Возвращает метаданные, хранящиеся в БД, а для файлов внутри ZIP архивов также возвращает свежие результаты извлечения.

### Аутентификация

Сессия PIN или ключ API

### Параметры

| Параметр | Тип | Описание |
|-----------|------|-------------|
| `file_id` | int | ID файла (параметр пути) |

### Ответ

```json
{
  "id": 123,
  "path": "/images/sample.png",
  "meta_source": "a1111_png",
  "parser_version": 5,
  "format": "a1111",
  "model_name": "sd_xl_base_1.0",
  "raw_prompt_length": 256,
  "raw_prompt_preview": "masterpiece, best quality, ...",
  "raw_negative_preview": "lowres, bad anatomy, ...",
  "raw_meta_json_length": 1024,
  "raw_meta_json_preview": "{\"steps\": 20, ...}",
  "has_v4_prompt": false,
  "has_comment": true
}
```

| Поле | Тип | Описание |
|-------|------|-------------|
| `id` | int | ID файла |
| `path` | string | Путь к файлу |
| `meta_source` | string | Источник метаданных (`a1111_png`, `novelai_v4_png` и т.д.) |
| `parser_version` | int | Версия парсера |
| `format` | string | Формат шаблона |
| `model_name` | string/null | Имя модели |
| `raw_prompt_length` | int | Количество символов в исходной подсказке |
| `raw_prompt_preview` | string | Первые 300 символов исходной подсказки |
| `raw_negative_preview` | string | Первые 300 символов отрицательной подсказки |
| `raw_meta_json_length` | int | Количество символов в исходном JSON метаданных |
| `raw_meta_json_preview` | string | Первые 500 символов исходного JSON метаданных |
| `has_v4_prompt` | bool | Содержит ли NovelAI V4 подсказку |
| `has_comment` | bool | Содержит ли поле Comment |

Для файлов внутри ZIP архивов добавляется поле `fresh_extract` с результатами повторного извлечения:

```json
{
  "fresh_extract": {
    "meta_source": "a1111_png",
    "format": "a1111",
    "raw_meta_json_length": 1024,
    "raw_meta_json_preview": "{...}",
    "has_v4_prompt": false,
    "success": true,
    "raw_prompt_preview": "masterpiece, ..."
  }
}
```

### Ошибки

| Статус | Описание |
|--------|-------------|
| 404 | Файл не найден |

## GET /api/debug/model-check

Проверить статус хранения `model_name` в таблице templates. Возвращает статистику и примеры записей с и без имен моделей.

### Аутентификация

Сессия PIN или ключ API

### Параметры

Нет

### Ответ

```json
{
  "total_templates": 1000,
  "with_model_name": 850,
  "without_model_name": 150,
  "samples_with_model": [
    {
      "file_id": 1,
      "model_name": "sd_xl_base_1.0",
      "model_hash": "abc123",
      "format": "a1111"
    }
  ],
  "samples_without_model": [
    {
      "file_id": 42,
      "model_name": null,
      "format": "comfy",
      "raw_meta_json_preview": "{...}"
    }
  ]
}
```

| Поле | Тип | Описание |
|-------|------|-------------|
| `total_templates` | int | Общее количество шаблонов |
| `with_model_name` | int | Количество записей с установленным именем модели |
| `without_model_name` | int | Количество записей без имени модели |
| `samples_with_model` | array | Примеры с именем модели (до 10) |
| `samples_without_model` | array | Примеры без имени модели (до 5) |

## GET /api/scanned-roots

Извлечь корневые каталоги из файлов, зарегистрированных в БД, и вернуть их с количеством файлов. Объединяет как настроенные корневые каталоги сканирования, так и корневые каталоги файлов, которые не принадлежат ни одному настроенному корневому каталогу.

### Аутентификация

Сессия PIN или ключ API

### Параметры

Нет

### Ответ

```json
{
  "roots": [
    {
      "path": "C:\\Images\\AI",
      "count": 5000
    },
    {
      "path": "D:\\Archives",
      "count": 1200
    }
  ]
}
```

| Поле | Тип | Описание |
|-------|------|-------------|
| `roots` | array | Массив корневых каталогов (сортировка по количеству файлов убывание, максимум 50) |
| `roots[].path` | string | Путь к каталогу |
| `roots[].count` | int | Количество файлов в этом пути |

### Ошибки

| Статус | Описание |
|--------|-------------|
| 500 | Не удалось вычислить сводку корневых каталогов |

## POST /api/debug/query

Выполнить запрос SQL только для чтения. Требует переменную окружения `YU_DEBUG_MODE=1` и разрешает доступ только с localhost.

### Ограничение частоты запросов

WRITE

### Аутентификация

Сессия PIN или ключ API (только localhost + `YU_DEBUG_MODE=1`)

### Запрос

```json
{
  "sql": "SELECT id, path, meta_source FROM files LIMIT 10",
  "limit": 100
}
```

| Параметр | Тип | Требуется | Описание |
|-----------|------|----------|-------------|
| `sql` | string | Да | SELECT инструкция для выполнения |
| `limit` | int | Нет | Максимальное количество строк для возврата (по умолчанию: 100, максимум: 10000) |

### Ограничения

- Разрешены только SELECT инструкции (INSERT, UPDATE, DELETE и т.д. отклоняются)
- Несколько инструкций (разделенные точкой с запятой) не допускаются
- Запросы, содержащие ключевые слова записи (DROP, ALTER, CREATE и т.д.), отклоняются

### Ответ

```json
{
  "columns": ["id", "path", "meta_source"],
  "rows": [
    {"id": 1, "path": "/images/test.png", "meta_source": "a1111_png"}
  ],
  "row_count": 1,
  "truncated": false
}
```

| Поле | Тип | Описание |
|-------|------|-------------|
| `columns` | string[] | Массив имен столбцов |
| `rows` | object[] | Результирующие строки (каждая строка является объектом с ключами по имени столбца) |
| `row_count` | int | Количество возвращенных строк |
| `truncated` | bool | `true` если результаты были усечены лимитом |

### Ошибки

| Статус | Описание |
|--------|-------------|
| 400 | Пустой SQL, несколько инструкций, запрос не-SELECT, операции записи, ошибка синтаксиса SQL |
| 403 | Режим отладки не включен или доступ с нелокального хоста |

## POST /api/scanned-roots/purge

Окончательно удалить все записи файлов под указанным путем из БД. Связанные записи (теги, шаблоны и т.д.) удаляются каскадно. Неиспользуемые теги автоматически удаляются.

### Ограничение частоты запросов

DESTRUCTIVE

### Аутентификация

Сессия PIN или ключ API

### Запрос

```json
{
  "path": "C:\\Images\\OldFolder"
}
```

| Параметр | Тип | Требуется | Описание |
|-----------|------|----------|-------------|
| `path` | string | Да | Корневой путь для удаления. Все файлы под этим путем будут удалены |

### Ответ

```json
{
  "purged": 150,
  "path": "C:\\Images\\OldFolder"
}
```

| Поле | Тип | Описание |
|-------|------|-------------|
| `purged` | int | Количество удаленных записей файлов |
| `path` | string | Указанный путь |

### Ошибки

| Статус | Описание |
|--------|-------------|
| 400 | Путь не указан |
| 500 | Операция удаления не удалась |
