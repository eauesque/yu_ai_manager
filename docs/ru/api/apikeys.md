# API ключей API

API для создания, списания и удаления ключей API. Все конечные точки требуют аутентификацию PIN сеанса.

Ключи API генерируются в формате `sk_` + 32 шестнадцатеричных символа (128-бит). На сервере хранится только хеш; необработанный ключ возвращается только один раз при создании.

## Области

Ключам API можно назначить области для ограничения доступа к конечным точкам. Ключи без областей по умолчанию имеют доступ только для чтения.

| Область | Описание |
|-------|-------------|
| `read` | Поиск, детали файлов, миниатюры, статистика |
| `rate` | Получение/установка оценок, массовая установка |
| `tag.write` | Добавление/удаление тегов |
| `collection.write` | Создание/обновление/удаление коллекции, массовое добавление, избранное |
| `annotate` | Чтение/запись/удаление аннотаций |
| `scan` | Запуск/отмена/возобновление сканирования |
| `admin` | Управление ключами API, параметры, резервное копирование/восстановление |

## POST /api/apikeys

Создание нового ключа API.

### Ограничение скорости

WRITE (область: `admin`)

### Аутентификация

PIN сеанс или ключ API с областью `admin`

### Запрос

```json
{
  "label": "My Integration",
  "scopes": ["read", "rate"]
}
```

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `label` | string | Нет | Идентифицирующее имя для ключа. По умолчанию `Key <timestamp>` если не указано |
| `scopes` | string[] | Нет | Массив областей. Опустить или передать пустой массив для доступа только для чтения |

### Ответ (201)

```json
{
  "id": "ak_1a2b3c4d5e6f7890",
  "key": "sk_abcdef1234567890abcdef1234567890",
  "key_prefix": "sk_abcdef12",
  "label": "My Integration",
  "created_at": 1709500000,
  "scopes": ["read", "rate"]
}
```

> **Примечание**: Поле `key` включено только в ответ при создании. Это значение больше нельзя получить, поэтому сохраните его в безопасном месте.

### Ошибки

| Статус | Описание |
|--------|-------------|
| 400 | Указана неверная область |

## GET /api/apikeys

Список всех ключей API. Хеши не включены; возвращается только префикс.

### Аутентификация

PIN сеанс или ключ API с областью `admin`

### Параметры

Нет

### Ответ

```json
{
  "keys": [
    {
      "id": "ak_1a2b3c4d5e6f7890",
      "key_prefix": "sk_abcdef12",
      "label": "My Integration",
      "created_at": 1709500000,
      "last_used_at": 1709600000,
      "scopes": ["read", "rate"]
    }
  ]
}
```

| Поле | Тип | Описание |
|-------|------|-------------|
| `id` | string | ID ключа (префикс `ak_`) |
| `key_prefix` | string | Первые 10 символов ключа (для идентификации) |
| `label` | string | Определенное пользователем имя |
| `created_at` | int | Время создания (Unix timestamp) |
| `last_used_at` | int/null | Время последнего использования. `null` если никогда не использовался |
| `scopes` | string[] | Назначенные области. Поле опускается, если областей нет |

## DELETE /api/apikeys/<key_id>

Удаление (отзыв) ключа API.

### Ограничение скорости

WRITE (область: `admin`)

### Аутентификация

PIN сеанс или ключ API с областью `admin`

### Параметры

| Параметр | Тип | Описание |
|-----------|------|-------------|
| `key_id` | string | ID ключа API (параметр пути) |

### Ответ

```json
{
  "deleted": "ak_1a2b3c4d5e6f7890"
}
```

### Ошибки

| Статус | Описание |
|--------|-------------|
| 404 | Ключ с указанным ID не найден |

## Использование ключей API

Используйте созданный ключ API через заголовок `Authorization`:

```
Authorization: Bearer sk_abcdef1234567890abcdef1234567890
```

Запросы, аутентифицированные с помощью ключей API, не требуют заголовок CSRF (`X-Requested-With`).
