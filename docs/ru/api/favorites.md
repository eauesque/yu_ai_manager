# API избранного

API для добавления, удаления, проверки и списания избранного.

## POST /api/favorites/toggle

Переключение статуса избранного файла. Добавляет файл, если он еще не в избранном; удаляет его, если он уже присутствует.

- **Ограничение скорости**: WRITE

### Тело запроса

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `file_id` | int | Да | ID целевого файла (положительное целое число) |
| `collection_id` | int | Нет | ID коллекции (по умолчанию: 1) |

```json
{
  "file_id": 42,
  "collection_id": 1
}
```

### Ответ

```json
{
  "file_id": 42,
  "collection_id": 1,
  "favorited": true
}
```

| Поле | Тип | Описание |
|-------|------|-------------|
| `file_id` | int | ID целевого файла |
| `collection_id` | int | ID коллекции |
| `favorited` | bool | Состояние после переключения. `true` = добавлено, `false` = удалено |

## GET /api/favorites/check

Возвращает, какие из указанных ID файлов находятся в избранном.

### Параметры

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `ids` | string | Да | ID файлов, разделенные запятой (например `1,2,3`) |
| `collection_id` | int | Нет | Фильтр по определенной коллекции |

### Ответ

```json
{
  "favorites": [1, 3]
}
```

| Поле | Тип | Описание |
|-------|------|-------------|
| `favorites` | int[] | Массив ID файлов, находящихся в избранном |

## GET /api/favorites/check_collections

Возвращает ID коллекций, которые содержат указанный файл.

### Параметры

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `file_id` | int | Да | ID целевого файла |

### Ответ

```json
{
  "collections": [1, 3]
}
```

| Поле | Тип | Описание |
|-------|------|-------------|
| `collections` | int[] | Массив ID коллекций, содержащих этот файл |

## GET /api/favorites/list

Получение списка ID файлов в избранном. Результаты отсортированы по дате добавления в обратном порядке. Логически удаленные файлы исключены.

### Параметры

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `collection_id` | int | Нет | Фильтр по определенной коллекции |

### Ответ

```json
{
  "ids": [42, 55, 67]
}
```

| Поле | Тип | Описание |
|-------|------|-------------|
| `ids` | int[] | Массив ID файлов в избранном (отсортировано по `added_at` DESC) |
