# API коллекций

API для управления коллекциями (группы избранного).

## GET /api/collections

Список всех коллекций. Отсортировано по `sort_order` ASC, затем `id` ASC.

### Параметры

Нет

### Ответ

```json
{
  "collections": [
    {
      "id": 1,
      "name": "Favorites",
      "sort_order": 0,
      "created_at": 1709500000,
      "count": 42,
      "is_smart": false,
      "query_json": null
    }
  ]
}
```

## POST /api/collections

Создание новой коллекции.

### Ограничение скорости

WRITE

### Запрос

```json
{
  "name": "My Collection",
  "query_json": null
}
```

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `name` | string | Да | Имя коллекции |
| `query_json` | object/null | Нет | Запрос для умных коллекций. Опустить для обычных коллекций |

### Ответ (201)

```json
{
  "id": 2,
  "name": "My Collection",
  "is_smart": false
}
```

## PUT /api/collections/<id>

Переименование коллекции.

### Ограничение скорости

WRITE

### Параметры

| Параметр | Тип | Описание |
|-----------|------|-------------|
| `id` | int | ID коллекции (параметр пути) |

### Запрос

```json
{
  "name": "Renamed Collection"
}
```

### Ответ

```json
{
  "id": 2,
  "name": "Renamed Collection"
}
```

## DELETE /api/collections/<id>

Удаление коллекции. Все записи избранного в коллекции также удаляются.

Коллекция по умолчанию (`id=1`) не может быть удалена.

### Ограничение скорости

WRITE

### Параметры

| Параметр | Тип | Описание |
|-----------|------|-------------|
| `id` | int | ID коллекции (параметр пути) |

### Ответ

```json
{
  "deleted": 2
}
```

## POST /api/collections/reorder

Изменение порядка отображения коллекций.

### Ограничение скорости

WRITE

### Запрос

```json
{
  "ids": [3, 1, 2]
}
```

| Параметр | Тип | Описание |
|-----------|------|-------------|
| `ids` | int[] | Массив ID коллекций. Указанный порядок становится новым порядком сортировки |

### Ответ

```json
{
  "ok": true
}
```

## POST /api/collections/<id>/batch-add

Добавление файлов в коллекцию массово. Идемпотентно: записи, которые уже существуют, пропускаются и считаются успехами.

### Ограничение скорости

WRITE

### Параметры

| Параметр | Тип | Описание |
|-----------|------|-------------|
| `id` | int | ID коллекции (параметр пути) |

### Запрос

```json
{
  "file_ids": [1, 2, 3]
}
```

| Параметр | Тип | Лимит | Описание |
|-----------|------|-------|-------------|
| `file_ids` | int[] | Макс 500 | Массив ID файлов для добавления |

### Ответ

```json
{
  "total": 3,
  "succeeded": 3,
  "failed": 0,
  "errors": []
}
```

## GET /api/collections/<id>/export/csv

Экспорт файлов в коллекции в виде CSV.

### Параметры

| Параметр | Тип | Описание |
|-----------|------|-------------|
| `id` | int | ID коллекции (параметр пути) |

### Ответ

- Content-Type: `text/csv; charset=utf-8`
- Столбцы CSV: `id`, `filename`, `folder`, `path`, `meta_source`, `mtime`, `positive`, `negative`
- Возвращает 404, если коллекция не найдена
