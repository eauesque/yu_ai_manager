# Оформление — CSS пользовательские свойства

Это список CSS пользовательских свойств, используемых в справочном UI (`ui/default/`).
Пользовательский UI может переопределить внешний вид существующих компонентов, переопределив эти переменные.

Источник: `ui/default/static/css/base/base-theme.css`

## Основные переменные (`:root` / `body.dark`)

| Переменная | Светлая | Темная | Назначение |
|----------|-------|------|---------|
| `--bg` | `#f5f6f8` | `#0f1115` | Фон страницы |
| `--card` | `#ffffff` | `#1b1f2a` | Фон карточки/панели |
| `--text` | `#222` | `#e7eaf0` | Основной текст |
| `--muted` | `#666` | `#aab2c0` | Подтекст/подсказки |
| `--border` | `#e6e6e6` | `#2b3240` | Границы/разделители |
| `--shadow` | `0 4px 14px rgba(0,0,0,0.08)` | `0 10px 26px rgba(0,0,0,0.45)` | Тень карточки |
| `--btn-bg` | `#ffffff` | `#1b2030` | Фон кнопки |
| `--btn-text` | `#222` | `#e7eaf0` | Текст кнопки |
| `--btn-hover` | `#f6f9ff` | `#222a3d` | Наведение кнопки |
| `--tooltip-bg` | `rgba(0,0,0,0.85)` | `rgba(0,0,0,0.92)` | Фон всплывающей подсказки |
| `--tooltip-text` | `#fff` | `#fff` | Текст всплывающей подсказки |
| `--accent` | `#2563eb` | `#60a5fa` | Цвет акцента (ссылки, выделение кнопок) |

| `--tag-bg` | `#4a4a4a` | Фон тега |

## Классы темы

| Класс | Описание |
|-------|-------------|
| `body.dark` | Темный режим |
| `body.theme-retro` | Ретро неоновая тема (Konami код) |
| `body.theme-glow` | Пользовательский эффект свечения |

## Применение тем

Для изменения темы в пользовательском UI:

```css
/* Пример пользовательской темы */
body.theme-ocean {
  --bg: #0a1628;
  --card: #132744;
  --text: #c8daf0;
  --accent: #38bdf8;
  color-scheme: dark;
}
```

Тема вступает в силу путем добавления класса к элементу `body`.
Свойство `color-scheme: dark` в темном режиме влияет на цвета элементов управления формы ОС.
