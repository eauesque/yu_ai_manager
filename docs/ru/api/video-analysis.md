# API видео анализа

API для управления конфигурацией видео анализа и проверки статуса. Управляет параметрами для извлечения ключевых кадров из видеофайлов.

## GET /api/video-analysis/config

Получение текущей конфигурации видео анализа. Возвращает сохраненные параметры, объединенные со значениями по умолчанию.

### Параметры

Нет

### Ответ

```json
{
  "config": {
    "enabled": true,
    "keyframe_count": 4,
    "strategy": "uniform",
    "scene_threshold": 0.4,
    "store_per_keyframe": false
  }
}
```

| Поле | Тип | По умолчанию | Описание |
|-------|------|---------|-------------|
| `enabled` | boolean | `true` | Включен ли видео анализ |
| `keyframe_count` | int | `4` | Количество ключевых кадров для извлечения (1-16) |
| `strategy` | string | `"uniform"` | Стратегия извлечения ключевых кадров. `uniform` (равномерно разделены), `scene` (обнаружение изменения сцены), `single` (один кадр только) |
| `scene_threshold` | float | `0.4` | Порог обнаружения изменения сцены (0.0-1.0). Используется когда `strategy` это `scene` |
| `store_per_keyframe` | boolean | `false` | Хранить ли каждый ключевой кадр отдельно |

## POST /api/video-analysis/config

Сохранение конфигурации видео анализа. Обновляются только указанные поля; опущенные поля сохраняют существующие значения.

### Ограничение скорости

WRITE

### Запрос

```json
{
  "enabled": true,
  "keyframe_count": 8,
  "strategy": "scene",
  "scene_threshold": 0.3,
  "store_per_keyframe": false
}
```

Все поля необязательны. Обновляются только указанные поля.

| Параметр | Тип | Обязательный | Ограничения | Описание |
|-----------|------|----------|-------------|-------------|
| `enabled` | boolean | Нет | - | Включен ли видео анализ |
| `keyframe_count` | int | Нет | 1-16 | Количество ключевых кадров для извлечения |
| `strategy` | string | Нет | `uniform`, `scene` или `single` | Стратегия извлечения ключевых кадров |
| `scene_threshold` | float | Нет | 0.0-1.0 | Порог обнаружения изменения сцены |
| `store_per_keyframe` | boolean | Нет | - | Хранить ли каждый ключевой кадр отдельно |

### Ответ

Возвращает объединенную конфигурацию после сохранения (такой же формат, что и GET).

```json
{
  "config": {
    "enabled": true,
    "keyframe_count": 8,
    "strategy": "scene",
    "scene_threshold": 0.3,
    "store_per_keyframe": false
  }
}
```

### Ошибки

| Статус | Код | Условие |
|--------|------|-----------|
| 400 | `invalid_json` | Тело запроса не является объектом JSON |
| 400 | `invalid_value` | Ошибка валидации (неверный тип, значение вне диапазона, неверная стратегия и т.д.) |

## GET /api/video-analysis/status

Получение информации о статусе видео анализа. Возвращает доступность ffmpeg, количество видеофайлов и количество файлов с извлеченными ключевыми кадрами.

### Параметры

Нет

### Ответ

```json
{
  "ffmpeg": true,
  "video_files": 150,
  "files_with_keyframes": 42
}
```

| Поле | Тип | Описание |
|-------|------|-------------|
| `ffmpeg` | boolean | Доступен ли ffmpeg в системе |
| `video_files` | int | Общее количество видеофайлов в базе данных (исключая мягко удаленные). Поддерживаемые расширения: `.mp4`, `.webm`, `.avi`, `.mov`, `.mkv`, `.m4v`, `.ogv` |
| `files_with_keyframes` | int | Количество файлов, которые имеют извлеченные ключевые кадры |
