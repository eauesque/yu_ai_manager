# Матрица распределённого инференса

**Версия**: v4.67.0 и выше

## Обзор

На странице `/mesh-inference` можно включать/отключать типы инференса для каждого пира в меш-инференсе.
Поддерживаются 4 типа: tagger, clip, yolo, whisper.

Это позволяет, например, назначить Hailo NPU на Pi5 только для tagger, а clip обрабатывать на GPU-хосте
— всё без правки конфигурации.

## Использование

1. Нажать «🕸️ Распределённый инференс» в навбаре
2. Кликнуть по ячейке матрицы для переключения включено/отключено
   - ☑ = Включено (использовать этот тип на этом пире)
   - ☐ = Отключено (пропустить этот пир)
   - — = Этот пир не предоставляет данный тип (недоступно для изменения)
3. Кнопка «Только локальный режим» одним кликом отключает все удалённые пиры
4. Состояние автоматически сохраняется в `data/mesh_inference_state.json`

## Поведение

- Настройки сохраняются даже для офлайн-пиров (применяются автоматически при переподключении)
- «Только локальный режим» активен только при наличии хотя бы одного включённого типа локально
- Запуск батча tagger при отключённом tagger на всех пирах немедленно завершится ошибкой `no_enabled_peers`
- При временном отключении и возврате пира после переобнаружения mDNS состояние отключения сохраняется

## Связь с флагом yoloDistributed

Чекбокс «Распределённый инференс» на странице обнаружения YOLO сохранён для обратной совместимости:

| yoloDistributed | Столбец yolo в матрице | Реальное поведение |
|---|---|---|
| ✅ ON | Все пиры включены | Как раньше — распределение по всем |
| ✅ ON | Часть отключена | Пропустить отключённые пиры |
| ❌ OFF | Игнорируется | Только локально (минуя router) |
