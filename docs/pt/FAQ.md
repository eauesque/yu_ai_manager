## Suporte · Bug · Adição de Recursos

**P: Não posso fazer PR.**
R: Não aceitamos PRs. Fim da história.

**P: Adicione uma nova funcionalidade**
R: Há uma Extensions API e documentação disponíveis. Crie você mesmo ou peça a um agente de IA para criar uma extensão referenciando "https://github.com/eauesque/yu_ai_manager". Se você não conseguir fazer isso, este software é muito cedo para você.

**P: Há um bug, corrija-o**
R: Cole o log no GitHub. Se eu tiver vontade, olharei. Se quiser corrigir agora mesmo, passe o log de erro para um agente de IA — será muito mais rápido do que eu. De qualquer forma, seu problema é seu para resolver.

**P: Não entendo a especificação**
R: Não minta. Toda a documentação foi fornecida. Leia. Se não conseguir ler, deixe uma IA ler para você. Se nem isso conseguir fazer, amadureça um pouco e volte depois.

**P: Nem sei o que não entendo.**
R: Mesmo que seja de forma vaga, pense um pouco sobre isso, ou leia o manual — algo pode vir à mente.

**P: Por favor, forneça suporte**
R: We made, you decide. Você não está entendendo algo?

**P: Fico com problemas se não corrigir**
R: Então fica com problemas. Seus problemas e meu trabalho são coisas diferentes. Prepare uma contrapartida e volte depois. É assim que funciona a sociedade.

**P: E se eu preparar uma contrapartida?**
R: Mesmo que prepare, se não corresponder ao meu esforço, não farei. É óbvio.

**P: Corrija-o 💢**
R: Você é um mendigo ou um fora da lei? Ao fazer um pedido, aprenda a dizer algo como "Would it be possible to...". Não aprendeu isso na escola?

## Responsabilidade · Propriedade · Direitos Autorais

**P: Você é irresponsável**
R: We made, you decide. Foi escrito dessa forma desde o início. Se você não leu, é culpa sua.

**P: Sofri perdas usando este software. É culpa do autor extremamente irresponsável e incompetente.**
R: De jeito nenhum. Você foi quem decidiu usar um software feito por um autor como esse em suas horas vagas. We made, you decide.

**P: Você é responsável pelo meu fracasso.**
R: Não culpe os outros pelas suas ações. Se está arrependido, culpe a si mesmo. Se fez algo por sua própria decisão, deve ser capaz de se reconciliar com isso.

**P: A comunidade deve decidir. As políticas de desenvolvimento devem ser discutidas por todos.**
R: Você não aprendeu o conceito de propriedade na escola primária? Estradas são usadas por todos, mas pertencem ao governo. Não lhe pertencem. Mantenho os direitos autorais enquanto forneço direitos de uso. Você está usando um software de forma gratuita e nem mesmo existe uma relação comercial. Um ninguém não tem poder de decisão no design. Traga uma base legal para opinar sobre o design. Se não conseguir, simplesmente use ou não use.

**P: Ouça a voz dos usuários.**
R: Você é meu cliente pagante? Não. Qual é minha obrigação de ouvir os requisitos de alguém com quem não tenho uma relação comercial? Faça um fork e crie seu próprio projeto. Isso é o que a licença MIT significa. Você tem apenas três direitos: "usar", "não usar" ou "fazer um fork".

**P: Você não tem interesse em fazer discussões ou criar uma comunidade?**
R: Não. Não é sustentável. Não tenho tempo para gerenciar comunidades quando meu trabalho principal exige toda minha atenção.

**P: Não gosto da política de desenvolvimento.**
R: Entendo. Faça um fork. Fim da história.

**P: Isso não viola a licença?**
R: Pesquise. Leia THIRD_PARTY_LICENSES.txt. Se ainda assim achar que viola, traga um advogado. Estou pronto.

**P: O OSS não é de todos?**
R: Entenda o significado de propriedade pública. Estradas, parques e bibliotecas — todos podem usar, mas o proprietário é a administração. Não lhe pertencem. "Público" significa "o proprietário gerencia enquanto permite uso amplamente" e não significa "a propriedade pertence a uma multidão indeterminada". OSS é igual. Mantenho os direitos autorais enquanto forneço direitos de uso. Usar é diferente de possuir. Se não conseguir fazer essa distinção, estude um pouco mais de direito antes de voltar.

Não há base alguma de que uma maioria ignorante produz julgamentos corretos. Até Aristóteles considerou permitir que pessoas sem capacidade de julgamento governem como um dos sistemas mais perigosos.

Você acha que sou um filósofo? Não, sou um auto-proclamado tolo. Ainda assim, este projeto chegou até aqui. Se meu julgamento for errado e o projeto desaparecer, assim seja. Que seja. Pelo menos a responsabilidade é clara.

A democracia é apenas uma ferramenta para que pessoas na mesma direção concordem temporariamente. Se você confundiu isso com um princípio permanente de organização comunitária, releia 2.400 anos de filosofia política antes de voltar. Este é meu projeto. Não é sua aldeia. Everyone's business is no one's business — veja a história para ver o que um sistema deliberativo com responsabilidade difusa produziu.

## Questões Técnicas

**P: Escrevi um issue em japonês no GitHub e não recebi resposta.**
R: Relatórios de bugs no GitHub só aceitam inglês. As discussões estão fechadas. Só aceitamos relatórios de bugs. Escreva em inglês ou não espere por uma resposta.

**P: Se eu apelar emocionalmente, você muda a política de desenvolvimento?**
R: O suporte a relatórios de bugs é feito por um agente de IA. Não por um humano. Argumentos emocionais, apelos à culpa e pressão social não funcionam em modelos de linguagem. Declare claramente fatos técnicos em inglês. Caso contrário, não há resposta significativa.

**P: Por que você usa tags Danbooru?**
R: As tags Danbooru são o padrão de fato na marcação de imagens geradas por IA. Stable Diffusion, NovelAI e inúmeras LoRAs — praticamente todos os principais modelos de geração de imagens foram treinados em conjuntos de dados marcados no formato Danbooru. O uso de tags Danbooru neste software é porque é o padrão da indústria, não significa apoio ao projeto Danbooru em si. Se você tem problemas com a taxonomia de tags, reclame com todo o ecossistema de geração de imagens de IA, não com esta ferramenta.

**P: Em macOS, ele diz "desenvolvedor não verificado" e não consegue iniciar.**
R: Correto. Assinatura de código custa dinheiro. Este software é gratuito. Clique com o botão direito no aplicativo, selecione "Abrir" e pressione "Abrir" novamente no diálogo. Só na primeira vez. Se até isso é incômodo, pense em como pagar pelo certificado você mesmo.

**P: O SmartScreen do Windows bloqueia o instalador.**
R: Esperado. A reputação do SmartScreen é construída sobre histórico de distribuição, não capacidade. Clique em "Mais informações" → "Executar mesmo assim" para prosseguir. Se você não consegue fazer esse julgamento por conta própria, seria melhor usar um software mais amigável.
