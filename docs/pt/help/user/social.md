# Social

Recursos sociais e compartilhamento comunitário.

## Gallery Export

Exporte coleção como galeria estática HTML:

1. Selecione coleção
2. Clique "Export as Gallery"
3. Compartilhe arquivo HTML

## LAN Share

Compartilhe coleção com outros usuários na LAN:

1. Clique ícone de compartilhamento
2. Selecione coleção
3. Copie token de compartilhamento
4. Compartilhe com outros usuários

Acesso: `http://<IP>:5000/share/<token>`

## Embed

Incorpore imagem em site externo:

```html
<iframe src="http://localhost:5000/embed/<file_id>"></iframe>
```

Requer compartilhamento público configurado.

## Comentários

Deixe notas em imagens compartilhadas:
- Adições/sugestões
- Créditos
- Contexto

## Coleções Colaborativas

Para equipes:
1. Criar coleção
2. Ativar modo colaborativo
3. Convidar outros usuários

## Perfil

Exiba seu perfil público com:
- Bio
- Imagens favoritas
- Estatísticas

Configurar em Settings > Profile
