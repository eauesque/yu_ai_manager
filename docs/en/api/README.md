# YU AI Manager API Reference

REST API documentation for using all features of YU AI Manager from custom UIs or scripts.

> **Note**: This document covers the main endpoints only.  
> For a complete list of all endpoints, refer to **[all-endpoints.md](all-endpoints.md)** (auto-generated by `scripts/gen_api_docs.py`, 629 endpoints).

## Common Conventions

### Base URL

```
http://<host>:<port>
```

Default: `http://127.0.0.1:5000`
Test environment: `http://127.0.0.1:5100` (when using `config_test.json`)

### Authentication

Supports 4 authentication methods:

| Method | Use Case | Header Example |
|--------|----------|----------|
| PIN Authentication | Browser session | Cookie: `session=...` |
| API Key | Machine-to-machine communication | `Authorization: Bearer sk_...` |
| Trusted Proxy | Behind reverse proxy | `X-Remote-User: username` |
| LAN Share Token | Guest access | URL path `/s/<token>/...` |

You can skip authentication by launching with `config_test.json` (no PIN).

### CSRF Protection

All `POST` / `PUT` / `DELETE` endpoints under `/api/` require the `X-Requested-With` header:

```
X-Requested-With: XMLHttpRequest
```

**Exception**: API Key requests with `Authorization: Bearer` header do not require CSRF.

### Rate Limiting

| Tier | Target | Rate | Burst |
|--------|--------|--------|----------|
| READ | All GET | Unlimited | - |
| WRITE | POST/PUT/DELETE (normal) | ~120 req/min | 30 |
| HEAVY | Similarity search, hash calculation, AI analysis, scan | ~20 req/min | 5 |
| DESTRUCTIVE | purge, hard-delete, cache clear, config write | ~12 req/min | 3 |

429 responses include a `Retry-After` header.

### Response Format

**Success** (new API):
```json
{
  "ok": true,
  "error": null,
  "data": { ... }
}
```

**Error**:
```json
{
  "ok": false,
  "error": "Error message",
  "code": "ERROR_CODE",
  "detail": "Additional information (optional)"
}
```

Some legacy APIs return `{ "success": true, "message": "..." }` format.

### Pagination

**Offset-based** (default):
```
GET /api/search?offset=0&limit=50
```

**Cursor-based** (for large datasets):
```
GET /api/search?cursor=<opaque_token>&limit=50
```

Response includes a `next_cursor` field.

### Batch Operations

Batch APIs support up to 500 operations with partial success:

```json
POST /api/ratings/batch-set
{
  "items": [
    { "file_id": 1, "rating": 5 },
    { "file_id": 999, "rating": 3 }
  ]
}
```

## Quick Start (curl)

```bash
# Search (no PIN environment)
curl "http://localhost:5100/api/search?q=landscape&limit=10"

# Get thumbnail
curl "http://localhost:5100/api/thumbnail/42" -o thumb.webp

# Search with API Key
curl -H "Authorization: Bearer sk_your_key_here" \
     "http://localhost:5100/api/search?q=portrait"

# Set rating
curl -X POST "http://localhost:5100/api/ratings/set" \
     -H "X-Requested-With: XMLHttpRequest" \
     -H "Content-Type: application/json" \
     -d '{"file_id": 42, "rating": 5}'
```
