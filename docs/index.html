03CAPABILITIES

Nine modules,
one local runtime.

Every capability runs on your hardware. No data leaves your machine unless you explicitly route it to a configured endpoint.

01

Multi‑backend inference

Hailo‑10H, ONNX Runtime, ROCm, CoreML. Automatic fallback and LAN‑distributed inference via mDNS discovery.

HailoONNXROCmCoreML
02

Image library management

SQLite‑backed library with VirtualGrid UI. Tag management, collections, ratings, favorites, duplicate detection.

SQLiteVirtualGriddedupe
03

WD‑Tagger / AI analysis

Batch image tagging with WD‑Tagger. Configurable thresholds, tag normalization, Danbooru autocomplete.

batchthresholdsautocomplete
04

LLM router

Multi‑backend LLM routing with SLO state reporting. Supports Ollama, OpenAI‑compatible APIs, and local models.

OllamaOpenAI‑APISLO
05

OCR + translation

Multi‑engine OCR with bounding‑box detection. LLM‑powered translation, overlay rendering, and batch export.

bboxoverlaybatch export
06

YOLO object detection

Hailo‑accelerated YOLO with stream sources (USB, RTSP, HTTP). Rule‑based detection triggers and action hooks.

USBRTSPHTTPtriggers
07

LoRA dataset manager

Build and export LoRA training datasets. WD‑Tagger integration, caption preview, kohya_ss export.

WD‑Taggerkohya_sscaption
08

Extension system

Multi‑stage sandboxed extensions. MCP server integration, inbound/outbound webhooks, Agent Safety Gateway.

MCPwebhookssandboxed
09

SD / NAI / ComfyUI bridge

Direct integration with Stable Diffusion WebUI, NovelAI, and ComfyUI for generation and prompt management.

SD‑WebUINAIComfyUI
