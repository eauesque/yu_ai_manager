# 模态工具栏

位于详细模态下方的统一工具栏，提供图像/视频查看期间所有主要控制的访问权限。

## 结构

### 主要栏（始终可见）

**静止图像模式：**
- ☆ 收藏
- ⓘ 切换信息面板
- ‹ › 上一个 / 下一个
- 缩放（－ / 100% / ＋）
- 适配模式（fit / fit-w / fit-h / fit-custom + 高度 / original）
- 跨页 2P / 方向 ↔（如适用）
- ⛶ 沉浸式 / ⤢ 全屏
- 📁 集合
- Bridge Send（发送提示词 ▾ / 发送图像 ▾）

**视频 / 音频模式（2 层布局）：**
- 上层：时间显示 + 进度条（max-width 720px 限制）
- 下层：☆ 收藏 / ⓘ 信息 / ‹ › / ▶ 播放 ⏪ ⏩ / ♪ 静音 + 音量 / ⛶ ⤢ / 📁

### 溢出菜单（… 按钮）

将低频率操作集中在竖向列表中：
- 自动播放 + 间隔
- 重复 / 速度 / 继续（用于视频）
- FPB / 角色网格（用于静止图像）
- ZIP / 容器视图

## 键盘快捷键

| 按键 | 操作 |
|---|---|
| `T` | 切换工具栏可见性 |
| `V` | 沉浸式模式 |
| `F` | 全屏 |
| `I` | 信息面板 |
| `H` | 键盘指南 |
| `P` | 自动播放 |
| `Space` / `K` | 播放 / 暂停（视频） |
| `J` / `0` | 快退（视频） |
| `L` | 快进（视频） |
| `M` | 静音（视频） |
| `R` | 重复（视频） |
| `←` / `→` | 上一个 / 下一个图像 |
| `ESC` | 依次关闭溢出菜单 → 模态 |

## 折叠和恢复

折叠工具栏的方法：
- 从溢出菜单（…）选择「折叠工具栏」
- 按下 `T` 键

恢复的方法：
- 点击屏幕底部中央的边缘把手
- 再按一次 `T` 键

折叠状态下，边缘把手位置会根据 filmstrip 的存在情况自动调整。

## 无障碍设计

- 整个工具栏具有 `role="toolbar"`
- 溢出按钮使用 `aria-haspopup="menu"` / `aria-expanded` 动态更新
- 溢出菜单项具有 `role="menuitem"`
- 边缘把手是标准 `<button>`，可使用 Enter / Space 操作
- 为满足 WCAG 2.5.5（目标大小），视觉上 8px 的把手通过 `::before` 扩展了 24px 高度的不可见点击区域
