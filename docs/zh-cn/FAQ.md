## 责任・所有权・知识产权

**Q: 这很不负责任**
A: We made, you decide. 从一开始就是这样写的。没有读的是你。

**Q: 我使用这个软件造成了损失。这是愚蠢和无责任的作者的错。**
A: 才不是。片手间开发的软件是你自己决定使用的。We made, you decide.

**Q: 由于你，我失败了。**
A: 别把你做的事归咎于别人。如果你后悔了，那就责备你自己。如果是你自己决定做的事，你就一定能接受它。

**Q: 应该由社区决定。开发方针应该由大家讨论。**
A: 你没有在小学学过知识产权的概念吗？道路任何人都可以使用，但它属于国家。它不属于你。著作权由我保有，只是给了你使用权。首先，你是免费使用软件的立场，甚至不存在交易关系。虫子没有设计决策权。如果你想对设计发表意见，请带上法律依据。如果你拿不出来，那就沉默地使用或不使用。

**Q: 听听用户的声音。**
A: 你是我的付费客户吗？当然不是。我对没有交易关系的人的要求没有义务听。自己 fork 创建你的项目。这就是 MIT 许可证的含义。你所获得的权力只有三种选择："使用""不使用""fork"。

**Q: 你不想进行讨论或建立社区吗？**
A: 没有。这在可持续性方面是有问题的。对于有本职工作的人来说，没有时间来经营社区。

**Q: 我不喜欢开发方针。**
A: 很好。自己 fork。就这样。

**Q: 这不是许可证违反吗？**
A: 先研究一下。读一下 THIRD_PARTY_LICENSES.txt。如果你还有话说，就带个律师来。我已经准备好了。

**Q: OSS 不是属于每个人的吗？**
A: 查一下公共财产的定义。道路、公园、图书馆——任何人都可以使用，但所有者是政府。它不属于你。public 是指"所有者管理但广泛允许使用的状态"，而不是"所有权属于不特定多数人的状态"。OSS 也是一样的。著作权由作者保有，只是给了你使用权。能够使用和拥有是两回事。如果你分不清楚，那就更多地学习法律，然后再来。

## 哲学・人生咨询・其他

**Q: 应该以更民主的方式运营。**

我是哲学家吗？不，我自称是愚者。尽管如此，这个项目还是走到这里了。如果我的判断是错误的，项目烟消云散，那就是这样。一切都会顺其自然。至少责任明确。

民主主义只是让方向一致的人暂时达成一致的工具。如果你把它误认为是永久性共同体的运营原理，那就去重新读一遍 2400 年的政治哲学。这是我的项目。不是你的村子。Everyone's business is no one's business — 看历史就能看出，责任所有权分散的合议制会造成什么。

## 技术问题

**Q: 我用日语写了 issue，但没有得到回复。**
A: GitHub 上的 bug 报告仅以英文处理。讨论已关闭。我们只接受 bug 报告。要么用英文写，要么不期望回复。

**Q: 如果我从情感上呼吁，我能改变开发方针吗？**
A: bug 报告的响应由 AI agent 处理。不是人。情感论证、内疚感呼吁、社会压力对语言模型无效。用英文清楚地陈述技术事实。否则，你将不会得到有意义的回答。

**Q: 为什么你使用 Danbooru 标签？**
A: Danbooru 标签是 AI 生成图像标签的事实标准。Stable Diffusion、NovelAI、众多 LoRA——主要的图像生成模型几乎都在用 Danbooru 格式标记的数据集上进行训练。该软件使用 Danbooru 标签，因为它是行业标准，这并不意味着对 Danbooru 项目本身的参与或支持。如果你对标签系统有意见，请向整个 AI 图像生成生态系统提出，而不是向这个工具。

**Q: 在 macOS 上，显示"开发者无法验证"，无法启动。**
A: 没错。代码签名需要钱。这个软件是免费的。右键单击应用程序，选择"打开"，然后在对话框中再次按"打开"。第一次就足够了。如果连这都嫌麻烦，那就自己想办法支付证书费用。

**Q: Windows SmartScreen 阻止了安装程序。**
A: 在预期之内。SmartScreen 的声誉是通过配布性能来建立的。点击"详细信息"→"运行"来继续。如果你自己无法做出这个判断，你最好使用更友善的软件。
