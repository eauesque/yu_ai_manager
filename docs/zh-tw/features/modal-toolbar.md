# 模態工具列

位於詳細模態下方的統一工具列，提供影像/影片檢視期間所有主要控制項的存取權。

## 結構

### 主要列（始終可見）

**靜止影像模式：**
- ☆ 我的最愛
- ⓘ 切換資訊面板
- ‹ › 上一個 / 下一個
- 縮放（－ / 100% / ＋）
- 適應模式（fit / fit-w / fit-h / fit-custom + 高度 / original）
- 跨頁 2P / 方向 ↔（如適用）
- ⛶ 沈浸式 / ⤢ 全螢幕
- 📁 集合
- Bridge Send（傳送提示詞 ▾ / 傳送影像 ▾）

**影片 / 音訊模式（2 層式配置）：**
- 上層：時間顯示 + 尋軸列（max-width 720px 上限）
- 下層：☆ 我的最愛 / ⓘ 資訊 / ‹ › / ▶ 播放 ⏪ ⏩ / ♪ 靜音 + 音量 / ⛶ ⤢ / 📁

### Overflow 選單（… 按鈕）

將低頻率操作集中在垂直清單中：
- 自動播放 + 間隔
- 重複 / 速度 / 繼續（針對影片）
- FPB / 角色網格（針對靜止影像）
- ZIP / 容器檢視
- 鍵盤指南 ?
- 摺疊工具列 «

## 鍵盤快速鍵

| 按鍵 | 操作 |
|---|---|
| `T` | 切換工具列可見度 |
| `V` | 沈浸式模式 |
| `F` | 全螢幕 |
| `I` | 資訊面板 |
| `H` | 鍵盤指南 |
| `P` | 自動播放 |
| `Space` / `K` | 播放 / 暫停（影片） |
| `J` / `0` | 倒轉（影片） |
| `L` | 快進（影片） |
| `M` | 靜音（影片） |
| `R` | 重複（影片） |
| `←` / `→` | 上一個 / 下一個影像 |
| `ESC` | 依序關閉 overflow 選單 → 模態 |

## 摺疊和復原

摺疊工具列的方式：
- 從 overflow 選單（…）選擇「摺疊工具列」
- 按下 `T` 鍵

復原的方式：
- 按一下螢幕底部中央的邊緣把手
- 再按一次 `T` 鍵

摺疊狀態期間，邊緣把手位置會根據 filmstrip 存在情況自動調整。

## 無障礙設計

- 整個工具列具有 `role="toolbar"`
- Overflow 按鈕使用 `aria-haspopup="menu"` / `aria-expanded` 動態更新
- Overflow 選單項目具有 `role="menuitem"`
- 邊緣把手是標準 `<button>`，可使用 Enter / Space 操作
- 為滿足 WCAG 2.5.5（目標大小），視覺上 8px 的把手透過 `::before` 擴展了 24px 高度的不可見點擊區域
