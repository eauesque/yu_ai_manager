# 遇到問題時的自我診斷與回報

當 YU AI Manager 無法運行或行為異常時，可以按照以下步驟自行收集原因線索，然後向開發者回報。您不需要了解命令行或 Git 的相關知識。

## 1. 首先按下「回報問題」

1. 在瀏覽器中打開應用程式，從螢幕右上角的選單中選擇 **診斷 (Diagnostics)**。
2. 點擊 **「回報問題」** 按鈕。
3. 稍等片刻後，會建立一個名為 `repair/2026XXXX-HHMMSS/` 的資料夾。資料夾內容包括以下自動回報集：
   - 環境資訊、最近的日誌、設定（個人資訊和令牌已遮罩）
   - AI 修復用的提示詞範本

按下 **「開啟資料夾」** 可在檔案總管中開啟該資料夾。按下 **「建立 ZIP」** 可將所有內容打包成一個 zip 檔案。

> 遮罩處理說明：使用者名稱、電子郵件、API 金鑰相關字符、IP 位址等會自動替換為 `<REDACTED>`。由於遮罩不完全，在分享之前請查看一下檔案內容。

## 2. 分享回報

將 ZIP 檔案附加到開發者、支援窗口或 Discord 等地方。點擊 **「複製 Discord 訊息」** 按鈕可為您準備一份簡短的貼上即用的文本。

## 3. 您可以自己嘗試的臨時解決方案

### 3-A. 環境檢查 (doctor)

在診斷螢幕上點擊 **「環境診斷」** 按鈕，Python、GPU、資料庫等的狀態會以 markdown 格式顯示。請按順序嘗試紅色（ERROR）或黃色（WARN）項目中列出的 `fix_hint`（修復提示）。

### 3-B. 以安全模式重新啟動

當無法正常啟動、應用程式崩潰或載入無限進行時，可以使用 **安全模式** 啟動。

- Windows：雙擊 `start.bat --safe-mode`（或在捷徑末尾新增 ` --safe-mode`）
- macOS / Linux：從終端機執行 `./start.sh --safe-mode`

在安全模式中，您可以執行以下操作：

- 檢查設定
- 「回報問題」和「環境診斷」
- 應用開發者提供的 **安全更新套件 (update.zip)**（僅檔案替換，自動修復指令碼無效）

安全模式將持續到下次正常啟動為止。透過正常重新啟動可回到正常模式。

### 3-C. 應用更新套件 (update.zip)

如果您收到來自開發者的 `update.zip`：

1. 進入診斷螢幕 → **「套用更新」** 區段
2. 選擇檔案，確認 **驗證 (Verify)** 變成綠色
3. 在確認對話框中點擊 **套用**
4. 按照顯示的指示重新啟動

> 驗證為紅色的 zip 千萬不要套用。可能存在被篡改或是其他應用程式套件的風險。

如果出現任何問題，可透過 **「復原上次更新」** 回到前一個狀態。

## 4. 不應該做的事情

- 將遮罩前的原始日誌貼到社交媒體 / 公開論壇
- 應用來源不明的 `update.zip`
- 手動編輯 `data/` 資料夾或 `tags.db`

## 如果仍然無法解決

如果還是無法解決問題，請連同 ZIP 檔案提交「您執行了什麼操作以及發生了什麼」的詳細說明。AI 側會讀取 `prompt_for_codex.md` / `prompt_for_claude.md`，並提供修復補丁建議。
