# Social Sharing

Condivisione risultati su comunità social.

## Piattaforme supportate

- Bluesky (@bsky.social)
- Mastodon (istanze federate)
- X (Twitter API)

## Flusso condivisione

1. Apri immagine in detail modal
2. Clicca bottone "Share"
3. Seleziona piattaforma
4. Componi caption
5. Allega media
6. Pubblica

## Caption template

Template automatici:
- Prompt principale
- Model name
- Generation params
- Link back ai dettagli

## Privacy considerate

- No share senza consenso
- Token crittografati in store
- Option per anonimo
- Disattivabile per piattaforma

## Automazione

Scheduler per post automatici:
- Daily best-of
- Weekly trending
- Monthly recap
