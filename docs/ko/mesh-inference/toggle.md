# 분산 추론 매트릭스

**버전**: v4.67.0 이후

## 개요

`/mesh-inference` 페이지에서는 mesh inference에 참여하는 각 피어에 대해 추론 타입 단위로 활성화/비활성화를 전환할 수 있습니다. 대상은 tagger, clip, yolo, whisper의 4종류입니다.

이를 통해 Pi5의 Hailo NPU를 tagger 전용으로 할당하거나, GPU 호스트에서 clip을 처리하는 등 config를 수정하지 않고 역할 분담이 가능합니다.

## 사용 방법

1. 내비게이션 바에서 "🕸️ 분산 추론"을 클릭
2. 매트릭스 표의 각 셀을 클릭하여 활성화/비활성화를 전환
   - ☑ = 활성화 (해당 피어에서 해당 추론 타입을 사용)
   - ☐ = 비활성화 (해당 피어를 건너뜀)
   - — = 해당 피어가 해당 타입을 제공하지 않음 (조작 불가)
3. "로컬 전용 모드" 버튼으로 모든 리모트 피어를 일괄 비활성화 가능
4. 상태는 자동으로 `data/mesh_inference_state.json`에 영구 저장됨

## 동작

- 오프라인 피어에도 설정은 유지됨 (재접속 시 자동 적용)
- "로컬 전용 모드"는 로컬에 1개 이상의 활성화된 타입이 있을 때만 누를 수 있음
- 모든 피어에서 tagger가 비활성화된 상태로 tagger 배치를 시작하면 `no_enabled_peers` 에러로 즉시 실패
- mDNS 재검출로 피어가 일시 이탈 후 복귀해도 비활성화 상태는 유지됨

## 기존 YOLO 분산 추론 체크와의 관계

YOLO 검출 페이지의 "분산 추론" 체크박스는 하위 호환을 위해 유지되며, 다음과 같이 조합됩니다:

| yoloDistributed | 매트릭스 yolo 열 | 실제 동작 |
|---|---|---|
| ✅ ON | 전체 피어 활성화 | 기존대로 전체 피어에서 분산 |
| ✅ ON | 일부 비활성화 | 비활성화된 피어를 건너뜀 |
| ❌ OFF | 무시 | 로컬만 (router 바이패스) |
