# 문제가 생겼을 때의 자가 진단과 보고

YU AI Manager가 작동하지 않거나 동작이 이상할 때, 자신이 직접 원인의 단서를 모아서 개발자에게 보고하는 절차를 정리했습니다. 명령어나 Git에 대한 지식은 필요하지 않습니다.

## 1. 먼저 "문제를 보고합니다"를 누르기

1. 브라우저에서 앱을 열고, 화면 우측 상단의 메뉴에서 **진단 (Diagnostics)**를 선택합니다.
2. **"문제를 보고합니다"** 버튼을 누릅니다.
3. 잠깐 기다리면 `repair/2026XXXX-HHMMSS/`라는 폴더가 생성됩니다. 안에는 다음과 같은 자동 보고 세트가 있습니다.
   - 환경 정보·최근 로그·설정(개인 정보와 토큰은 마스크됨)
   - AI 수리용 프롬프트 템플릿

**"폴더 열기"**를 누르면 그 폴더가 파일 탐색기에서 열립니다. **"ZIP으로 만들기"**로 1개의 ZIP 파일로 묶을 수 있습니다.

> 마스크 처리에 대하여: 사용자명·이메일·API 키로 보이는 문자열·IP 주소 등은 자동으로 `<REDACTED>`로 치환됩니다. 완전하지 않을 수 있으니 공유 전에 한 번 내용을 확인해 주세요.

## 2. 공유하기

ZIP 파일을 개발자·지원 창구·Discord 등에 첨부해 주세요. **"Discord용 메시지 복사"** 버튼으로 붙여넣기만 하면 되는 짧은 문구도 준비할 수 있습니다.

## 3. 자신이 시도해 볼 수 있는 임시 대처

### 3-A. 환경 확인 (doctor)

진단 화면의 **"환경 진단"** 버튼을 누르면, Python·GPU·DB 등의 상태가 마크다운 형식으로 표시됩니다. 빨간색(ERROR) 또는 노란색(WARN)의 항목에 쓰인 `fix_hint`(수리 힌트)를 순서대로 시도해 보세요.

### 3-B. Safe Mode로 다시 시작

정상 시작이 안 되거나 충돌하거나 계속해서 로딩이 멈출 때는 **Safe Mode**로 시작할 수 있습니다.

- Windows: `start.bat --safe-mode`를 더블 클릭합니다 (또는 바로가기 끝에 ` --safe-mode` 추가)
- macOS / Linux: 터미널에서 `./start.sh --safe-mode`를 실행합니다

Safe Mode에서는 다음을 수행할 수 있습니다.

- 설정 확인
- "문제를 보고합니다" "환경 진단"
- 개발자가 제공한 **안전한 업데이트 패키지(update.zip)** 적용(파일 교체만 가능·자동 수리 스크립트는 비활성화)

Safe Mode는 다음 번 정상 시작할 때까지 계속됩니다. 정상적으로 다시 시작하면 정상 모드로 돌아옵니다.

### 3-C. 업데이트 패키지(update.zip) 적용

개발자로부터 `update.zip`을 받았을 때:

1. 진단 화면 → **"업데이트 적용"** 섹션
2. 파일을 선택하고 **검증(Verify)**이 녹색이 되는지 확인
3. 확인 대화상자에서 **적용**을 누릅니다
4. 표시되는 지시에 따라 다시 시작

> 검증이 빨간색으로 나온 ZIP은 절대로 적용하지 마세요. 변조되었거나 다른 앱용 패키지일 가능성이 있습니다.

문제가 있으면 **"마지막 업데이트 취소(Rollback)"**로 이전 상태로 돌아갈 수 있습니다.

## 4. 해서는 안 되는 것들

- 마스크 전의 생 로그를 SNS / 공개 포럼에 붙여 넣기
- 출처 불명의 `update.zip` 적용
- `data/` 폴더나 `tags.db`를 손으로 수정

## 그래도 해결되지 않으면

그래도 해결되지 않으면 ZIP과 함께 "어떤 작업을 했을 때 무엇이 일어났는지"를 덧붙여서 보고해 주세요. AI 쪽에서 `prompt_for_codex.md` / `prompt_for_claude.md`를 읽어서 수리 패치 안을 냅니다.
