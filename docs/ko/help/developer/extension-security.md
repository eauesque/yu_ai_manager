# Extension 보안 모델

이 소프트웨어는 「누구나 AI를 사용해 Extension을 만들 수 있다」는 것을 특징으로 한다.
동시에, 악의적인 Extension으로부터 당신의 시스템을 보호하는 구조가 내장되어 있다.

이 페이지에서는 그 구조를 설명한다.
기술자가 아니어도 이해할 수 있도록 작성했다.

---

## 기본 원칙

Extension은 **보호된 세계** 안에서 동작한다.

이 보호된 세계 안에서 Extension은 비교적 자유롭게 행동할 수 있다.
페이지를 추가하거나, 데이터를 표시하거나, 이미지를 처리하거나——그것이 Extension의 역할이다.

다만, 보호된 세계 **바깥**에 있는 것——시스템 핵심(core), 다른 Extension, 당신의 PC에 있는 모든 파일——에는 손이 닿지 않는다.
이것은 「규칙으로 금지한 것」이 아니라, **구조적으로 손이 닿을 수 없게** 되어 있다.

---

## 권한 구조

Extension이 무언가를 하려면 **권한**이 필요하다.

권한은 스마트폰의 앱 권한과 동일한 모델로 설계되어 있다.

- 카메라 앱이 카메라 접근을 요청하는 것은 당연하다
- 카메라 앱이 연락처 접근을 요청하는 것은 부자연스럽다

Extension도 마찬가지다. 워터마크를 추가하는 Extension이 네트워크 접근을 요청하고 있다면, 의심해야 한다.

### 승인 절차

1. Extension을 설치한다(또는 AI에게 만들어 달라고 한다)
2. YU AI Manager가 자동으로 코드를 스캔하여 무엇을 하려는지 검사한다
3. Extension이 요청하는 권한 목록이 표시된다
4. **당신이 승인할 때까지 Extension은 동작하지 않는다**

승인 화면에 표시되는 정보를 제대로 읽어라.
특히 빨간색으로 표시된 권한에는 주의를 기울일 것.

### 권한을 승인한 후

승인한 권한 범위 내에서 Extension이 동작한다.
승인하지 않은 권한은, Extension이 아무리 노력해도 사용할 수 없다.
「사용하려다 거부당하는」 것이 아니라, 「애초에 보이지 않는다」.

---

## 3중 독립 감시

당신의 Extension은 세 가지 독립적인 구조로 감시되고 있다.
이 셋은 서로 독립되어 있어, 하나가 속더라도 나머지 둘이 기능한다.

### 1. 코드 스캔

Extension의 코드를 자동으로 분석하여 위험한 패턴을 탐지한다.
외부 프로그램 실행, 직접적인 데이터베이스 조작, 동적 코드 실행——이런 것들은 즉시 탐지된다.

### 2. 권한 제어

Extension이 API를 호출할 때, 유효한 「허가증」(Capability Token)을 가지고 있는지 확인한다.
허가증은 당신이 권한을 승인했을 때만 발급된다.
Extension 스스로 허가증을 위조하는 것은 불가능하다.

### 3. 감사 기록

Extension의 모든 조작이 기록된다.
이 기록은 Extension 자체에서 수정할 수 없는 독립된 장소에 저장된다.

이상이 감지된 경우——예를 들어, 선언하지 않은 동작을 시도한 경우——자동으로 알림이 전송되고, 필요에 따라 Extension의 허가증이 무효화된다.

---

## AI로 Extension을 만드는 경우

Claude Desktop에서 Extension을 만드는 경우, 생성된 Extension은 자동으로 **가장 제한이 엄격한 레벨**로 등록된다.

이것은 새로 고용한 직원에게 처음부터 금고 열쇠를 건네지 않는 것과 같다.
먼저 제한된 권한으로 동작시키고, 문제가 없음을 확인한 후에 필요에 따라 권한을 추가한다.

### AI가 만든 Extension으로 무엇을 할 수 있는가

**승인 없이 사용 가능:**
- 데이터 읽기 및 표시
- UI에 페이지 추가
- 설정 화면 추가

**승인이 필요:**
- 외부 서비스와의 통신
- 데이터베이스 쓰기
- 파일 읽기

**무엇을 해도 불가능:**
- 시스템 핵심(core)의 읽기 또는 수정
- 다른 Extension의 읽기 또는 수정
- 외부 프로그램 실행
- 허가증 위조

---

## 정기 검사

Extension은 한 번 승인했다고 끝이 아니다.

코드가 변경된 경우, 변경량이 일정 임계값을 초과하면 **재승인**이 요구된다.
이것은 조금씩 변경을 쌓아가다가 어느새 완전히 다른 것이 되어 있는, 그런 수법을 방지하기 위해서다.

또한, 정기적으로 코드 재검사가 자동 실행된다.
승인 시에는 문제가 없었더라도, 새로운 검사 규칙에서 문제가 발견될 수 있다.

---

## 당신이 해야 할 것

1. **권한 승인 화면을 제대로 읽어라** — 무엇을 요청하는지 이해한 후에 승인해라
2. **부자연스러운 권한 요청은 거부해라** — 이미지 처리에 네트워크가 필요한 건 이상하다
3. **알림을 무시하지 마라** — 이상이 감지되면 확인해라
4. **신뢰할 수 없는 출처의 Extension은 설치하지 마라** — 당연한 일이다

반대로 말하면, 그것만 하면 안전하다.
나머지는 시스템이 지켜준다.
