# 모달 도구 모음

세부 모달 하단에 위치한 통합 도구 모음으로, 이미지/비디오 보기 중에 모든 주요 컨트롤에 액세스할 수 있습니다.

## 구조

### 기본 모음(항상 표시)

**정지 이미지 모드:**
- ☆ 즐겨찾기
- ⓘ 정보 패널 토글
- ‹ › 이전 / 다음
- 확대(－ / 100% / ＋)
- 맞춤 모드(fit / fit-w / fit-h / fit-custom + 높이 / original)
- 페이지 펼침 2P / 방향 ↔(해당하는 경우)
- ⛶ 몰입식 / ⤢ 전체 화면
- 📁 컬렉션
- Bridge Send(프롬프트 전송 ▾ / 이미지 전송 ▾)

**비디오 / 오디오 모드(2계층 레이아웃):**
- 상단: 시간 표시 + 시크 바(max-width 720px 제한)
- 하단: ☆ 즐겨찾기 / ⓘ 정보 / ‹ › / ▶ 재생 ⏪ ⏩ / ♪ 음소거 + 볼륨 / ⛶ ⤢ / 📁

### 오버플로우 메뉴(… 버튼)

저빈도 작업을 세로 목록으로 통합:
- 자동 재생 + 간격
- 반복 / 속도 / 계속(비디오용)
- FPB / 캐릭터 그리드(정지 이미지용)
- ZIP / 컨테이너 뷰
- 키보드 가이드 ?
- 도구 모음 축소 «

## 키보드 단축키

| 키 | 작업 |
|---|---|
| `T` | 도구 모음 표시 여부 토글 |
| `V` | 몰입식 모드 |
| `F` | 전체 화면 |
| `I` | 정보 패널 |
| `H` | 키보드 가이드 |
| `P` | 자동 재생 |
| `Space` / `K` | 재생 / 일시 정지(비디오) |
| `J` / `0` | 빨리 감기(비디오) |
| `L` | 빨리 감기(비디오) |
| `M` | 음소거(비디오) |
| `R` | 반복(비디오) |
| `←` / `→` | 이전 / 다음 이미지 |
| `ESC` | 오버플로우 메뉴 → 모달 순서대로 닫기 |

## 축소 및 복원

도구 모음을 축소하는 방법:
- 오버플로우 메뉴(…)에서 "도구 모음 축소" 선택
- `T` 키 누르기

복원하는 방법:
- 화면 하단 중앙의 가장자리 핸들 클릭
- `T` 키를 다시 누르기

축소된 상태에서 가장자리 핸들 위치는 filmstrip 존재 여부에 따라 자동으로 조정됩니다.

## 접근성

- 전체 도구 모음에 `role="toolbar"` 설정
- 오버플로우 버튼은 `aria-haspopup="menu"` / `aria-expanded` 동적 업데이트
- 오버플로우 메뉴 항목은 `role="menuitem"`
- 가장자리 핸들은 표준 `<button>`으로 Enter / Space로 작동 가능
- WCAG 2.5.5(목표 크기)를 충족하기 위해 시각적으로 8px인 핸들에 `::before`를 통해 24px 높이의 보이지 않는 클릭 영역 확장
