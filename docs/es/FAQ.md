## 責任・所有権・財産権

**Q: 無責任だ**
A: We made, you decide. 最初からそう書いてある。読んでいなかったのはあなただ。

**Q: このソフト使って損害が出た。愚鈍を極めた無責任極まりない作者のせいだ。**
A: んなわけねーだろ。そんな作者が片手間に作ったソフトを使った判断はあなたがしたんだ。We made, you decide.

**Q: お前のせいで失敗した。**
A: お前がやったことを人の所為にするな。後悔するなら自分を責めろ。自分で決めてやったことであれば、必ず納得できるはずだ。

**Q: コミュニティで決めるべきだ。開発方針はみんなで議論すべきだ。**
A: 財産権という概念を小学校で習わなかったか。道路は誰でも使えるが国のものだ。あなたのものではない。著作権はこちらが保持したまま使用権を与えているにすぎない。そもそもあなたは無償でソフトウェアを使わせてもらっている立場であり、取引関係すら存在しない。虫ケラに設計の決定権はない。設計に口出しする法的根拠を持ってきなさい。持ってこられないなら、黙って使うか使わなければいい。

**Q: ユーザーの声を聞け。**
A: あなたは私の有償取引先か？違うだろう。取引関係のない相手の要求を聞く義務がどこにある。フォークして自分のプロジェクトを作りなさい。それがMITライセンスの意味だ。あなたに与えられた権限は「使う」「使わない」「フォークする」の三択だけだ。

**Q: ディスカッションしたりコミュニティ作る気はないんですか？**
A: ない。持続可能性がない。本職がある人間がコミュニティ運営まで抱える余裕はどこにもない。

**Q: 開発方針が気に入らない。**
A: そうか。フォークしろ。以上だ。

**Q: ライセンス違反ではないか。**
A: 調べてから言え。THIRD_PARTY_LICENSES.txtを読め。それでもまだ言うなら弁護士を連れてきなさい。準備はできている。

**Q: OSSはみんなのものじゃないのか。**
A: 公共物の意味を調べなさい。道路も公園も図書館も、誰でも使えるが所有者は行政だ。あなたのものではない。publicとは「所有者が管理しつつ広く使用を認めている状態」であって「所有権が不特定多数に帰属する状態」ではない。OSSも同じだ。著作権は作者が保持したまま使用権を与えているにすぎない。使えることと所有することは別の話だ。その区別がつかないなら、もう少し法律の勉強をしてから出直しなさい。

私が哲人かって？違う、自称愚者だ。それでもこのプロジェクトはここまで来た。もし私の判断が間違っていてプロジェクトが霧散するなら、それはそういうことだ。なるようになる。少なくとも責任の所在は明確だ。

民主主義とは同じ方向を向いた人間が一時的に合意するための道具にすぎない。それを永続的な共同体の運営原理と勘違いしているなら、2400年分の政治哲学を読み直してから出直しなさい。これは私のプロジェクトだ。あなたの村ではない。Everyone's business is no one's business — 責任の所在が霧散した合議制が何を生んできたか、歴史を見れば明らかだ。

## 技術的な質問

**Q: 日本語で issue を書いたのに返事がない。**
A: GitHub でのバグ報告は英語のみ対応だ。ディスカッションは閉鎖している。受け付けるのはバグ報告だけだ。英語で書くか、返事を期待しないかのどちらかにしなさい。

**Q: 感情的に訴えたら開発方針を変えてもらえますか？**
A: バグ報告の対応は AI agent が行っている。人間ではない。感情論、罪悪感に訴える手法、社会的圧力は言語モデルには通じない。技術的な事実を英語で明確に述べなさい。さもなければ意味のある回答は返ってこない。

**Q: なぜ Danbooru タグを使っているのですか？**
A: Danbooru タグは AI 生成画像のタグ付けにおけるデファクトスタンダードだからだ。Stable Diffusion、NovelAI、無数の LoRA — 主要な画像生成モデルのほぼ全てが Danbooru 形式でタグ付けされたデータセットで学習されている。このソフトウェアが Danbooru タグを使っているのは、それが業界標準だからであって、Danbooru プロジェクト自体への加担や支持を意味するものではない。タグ体系に文句があるなら、このツールではなく AI 画像生成エコシステム全体に言いなさい。

**Q: macOS で「開発元が未確認」と表示されて起動できない。**
A: 正しい。コード署名には金がかかる。このソフトは無料だ。アプリを右クリックして「開く」を選び、ダイアログでもう一度「開く」を押しなさい。初回だけでいい。それすら面倒なら、自分で証明書代を出す方法を考えなさい。

**Q: Windows の SmartScreen がインストーラーをブロックする。**
A: 想定内だ。SmartScreen の評判は能力ではなく配布実績で積み上がる仕組みになっている。「詳細情報」→「実行」で進みなさい。それを自分で判断できないなら、もっと親切なソフトウェアを使った方がいい。
