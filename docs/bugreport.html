GitHub accountSign up at github.com/join — free, 2 min. Username can be anything; a throwaway is fine.
02
Review diagnosticsInspect what will be sent. This page only includes what you see on-screen.

Submit to GitHub IssuesOpens a new tab with a pre-filled issue. Click "Submit new issue" there. Alternatively, copy the bundle JSON and paste it into an AI coding assistant — git clone + AI is often the fastest path to a fix.
04
Attach screenshotIf reached via QR, upload a photo of it, or a screenshot of the error screen. No camera? Save the error screen as an image file and upload that instead.

What gets sent: only what appears on this page. No additional data is collected.

Submission goes directly to GitHub Issues via your browser. GitHub's privacy policy applies once submitted.
