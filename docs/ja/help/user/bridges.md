# Bridge 連携

Bridge 機能を使うと、YU AI Manager から各種 AI 画像生成ツールへプロンプトを直接送信できます。

## 対応 Bridge

### SD WebUI Bridge
Stable Diffusion WebUI (Automatic1111 / Forge) と連携します。
- プロンプトの送受信
- 生成パラメータの転送

### NAI Bridge
NovelAI と連携します。
- プロンプト構文の自動変換（SD ↔ NAI）
- 品質タグの自動挿入

#### Vibe Transfer (NovelAIポーション) と encode-vibe キャッシュ

NAI V4 以降のモデルでは、参照画像を生成リクエストに添付する前に `/ai/encode-vibe` API
でエンコードする必要があります（1 回あたり **2 Anlas** を消費）。

同じ画像で繰り返し生成する Anlas 浪費を防ぐため、エンコード結果を以下にローカルキャッシュします:

```
data/nai_vibe_cache/<sha256>__<model>__<info_extracted>.bin
```

- **キー**: 生画像の SHA256 + モデル名 + 情報抽出度（0.01 刻み）
- **上限**: 既定 500 MB。Settings > NAI Bridge > "Vibe encode cache (MB)" で変更可（0 で無効化）
- **LRU**: 上限を超えると古い順に自動削除（バックグラウンドスレッドで非同期実行）

### ComfyUI Bridge
_v4.121.0 から img2img 対応（画像をドロップ／選択、変化強度 denoise 0.0〜1.0、デフォルト 0.75。出力は元画像と同寸法）_
ComfyUI と連携します。
- ワークフローへのプロンプト挿入
- 出力フォーマットのカスタマイズ

## バッチ生成

3 つの Bridge とも、メイン生成パスでバッチ生成 (A1111 互換セマンティクス) に対応しています。

### Batch count / Batch size

- **Batch count** — 連続して生成する回数 (時間方向)。クライアント側で 1 回ずつ API を呼び続けます
- **Batch size** — 1 回の API 呼び出しで並列生成する枚数 (VRAM 方向)。NAI Bridge では非表示
- 合計枚数 = Batch count × Batch size

固定 Seed のとき、loop 内で seed を `base + i` で連番にずらします (A1111 と同じ挙動)。`-1` (ランダム) のときは各回でランダム seed が振られます。

### 中断ボタン

| Bridge | 単発 (count=1) | loop (count>1) |
|---|---|---|
| NAI | 中断ボタンなし | 「画像生成後中断」のみ |
| SD WebUI | 「中断」(サーバー cancel API) | 「画像生成後中断」+「中断」両方 |
| ComfyUI | 「中断」(サーバー cancel API) | 「画像生成後中断」+「中断」両方 |

- **中断 (即時)** — 進行中の API 呼び出しを切断し、loop も停止。SD WebUI / ComfyUI ではサーバー cancel API も呼び出します
- **画像生成後中断** — 現在生成中の画像は完成させ、次の iteration を投げない

NAI Bridge の単発生成に中断ボタンがないのは、NAI API が fetch を受理した時点で Anlas (クレジット) を消費するためです。HTTP 接続を切断してもサーバー側の生成も課金も止まらないため、中断ボタンは UX の誤解を招くだけになるので意図的に出していません。

### VRAM 注意

Batch size を上げるとサーバー側 GPU の VRAM 消費が枚数分増えます。SDXL × Batch size 4 以上で OOM することがあるので、初回は 1 から試してください。

## 品質プリセット

各 Bridge のツールバーにある「QP」ボタンで、品質向上タグをワンクリックで挿入できます。

ビルトインプリセット:
- SD High Quality
- SD Realistic
- NAI Quality
- NAI Artistic
- Minimal

カスタムプリセットも作成可能です。

## 解像度プリセット

SD WebUI Bridge と ComfyUI Bridge の Width/Height 入力の上に「Resolution Preset」ドロップダウンと ⇄ Swap ボタンがあります。代表的な解像度をワンクリックで入力できます。

- **SD 1.5** — SD1.5 系モデル向け 512 基準 5 種
- **SDXL Trained** — SDXL 公式学習バケット 9 種（品質最優先）
- **SDXL Cheat Sheet** — 映画・写真のアスペクト比を 8 の倍数で近似した 12 種（構図優先、出典 [Civitai](https://civitai.com/articles/2246/sdxl-image-size-cheat-sheet)）

`Custom` 選択時は既存の W/H 値を保持します。プリセット適用後に W/H を手動編集すると自動で `Custom` に戻ります。⇄ ボタンで Width と Height を交換できます。

Cheat Sheet の解像度は公式バケットから外れるため、モデルによっては若干の構図崩れが起こる可能性があります。

> ComfyUI Bridge では Simple モードにのみ適用されます。Raw JSON Workflow モードのノード値には影響しません。


## 複数サーバー対応（マルチ Bridge）

SD WebUI Bridge と ComfyUI Bridge は複数のサーバーに同時接続できます。異なるモデルを比較したり、複数 GPU でスループットを上げたり、リモートマシンとローカルを並列使用することができます。

### サーバーを登録する

Bridge ページ下部の **Servers** セクション（折りたたみ可）からサーバーを追加します。

1. **Servers** をクリックして展開
2. **+ Add Backend** をクリック
3. **Type**（`comfyui` または `sd_webui`）、**URL**（`http://HOST:PORT` 形式）、**Name**（任意）を入力して Save

登録済みサーバーは名前・URL・ステータスドット（🟢 起動中 / 🔴 停止中 / 🟡 不明）で一覧表示されます。削除ボタンで削除できます。

#### URL の形式

| 形式 | 例 |
|------|-----|
| ローカル | `http://127.0.0.1:8188` |
| LAN 内リモート | `http://192.168.1.10:7860` |
| HTTPS | `https://gpu.example.com` |

path / query / fragment は含められません（`http://host:port` のみ）。

### グループを作る

グループはサーバーをまとめた単位です。グループを選ぶと、グループ内の全サーバーへ**同時**にプロンプトを送信します（ファンアウト）。

1. **Servers** セクション内の **Groups** エリアで **+ Add Group** をクリック
2. グループ名と含めるサーバーにチェックを入れて Save

> グループ内のサーバー数は最大 16 台です。8 台超の場合は送信前に確認ダイアログが表示されます。

### 送信先を選ぶ

画像詳細モーダルの「→ ComfyUI」「→ SD」ボタンをクリックすると **送信先セレクター** が表示されます。

| 選択肢 | 動作 |
|--------|------|
| **Default** | デフォルト設定のサーバー（未設定時はフォールバック URL）へ送信 |
| **グループ名** (⚡) | グループ内の全サーバーへ並列ファンアウト |
| **サーバー名** (🟢/🟡) | 指定した 1 台のサーバーへ送信 |

停止中（🔴）のサーバーはグレーアウトして選択できません。

#### デフォルトサーバーを設定する

**Servers** セクション内の **Default Backends** で、type ごとにデフォルトサーバーを指定できます。設定後は「Default」選択で毎回そのサーバーへ送信されます。

### 並列生成の結果を見る

複数サーバーへの送信後、結果パネルが**スイムレーン**形式で表示されます。

- 各サーバーの生成が独立した行（レーン）に表示されます
- グループ選択時はグループヘッダーが表示され、クリックで折りたたみができます
- レーン上部のプログレスバーが生成の進行を示します
- 右上の **「Unified View」** ボタンで全サーバーの結果を受信時刻順の統合フィルムストリップに切り替えられます

一部のサーバーでエラーが発生しても、他のサーバーの生成は継続します。エラーはそのレーンに表示されます。

## Bridge 間転送

Bridge 間でプロンプトを直接転送できます。SD ↔ NAI 間は構文が自動変換されます。

## Bridge への送信

画像詳細モーダルのツールバーから、表示中の画像のプロンプトまたは画像本体を生成 Bridge に直接送れます。

- **プロンプトを送る ▾** — 表示画像のプロンプトを NAI Bridge / SD WebUI / ComfyUI のいずれかに送信。NAI 文法で書かれたプロンプトは送信先が SD/ComfyUI なら自動で SD 文法に変換、逆も同様。NAI v4 のキャラクタープロンプト（positive/negative）は送信先が NAI Bridge なら構造化のまま、それ以外ならメインプロンプトに結合されて送られます。
- **画像を送る (img2img) ▾** — 表示画像のフル解像度を NAI Bridge / SD WebUI / ComfyUI の img2img スロットに直接セット。ComfyUI は v4.121.0 から対応。
- **リミックス ▾**（v4.121.3〜） — プロンプトと画像を**まとめて**送信。同じ画像に対してプロンプトを微修正して再生成したい場合に 1 クリックで完結。NAI / SD WebUI / ComfyUI が選択可能。

ボタンが表示される条件:
- プロンプト送信: 画像にプロンプトメタデータ（positive/negative またはキャラクター情報）が含まれる場合
- 画像送信: 表示中のメディアが画像（静止画 / アニメーション画像 / 動画）の場合。動画では現在の再生位置のフレームをキャプチャして送信します（v4.121.20〜）
- リミックス: 上記両方を満たす場合のみ

注意点:
- PDF・音声では「画像を送る」は表示されません
- 動画フレーム送信時は元動画ではなく、再生中の現在位置の 1 枚を PNG として送信します
- プロンプト変換が失敗した場合、元の文法のまま送信され、送信先 Bridge 画面で警告トーストが表示されます
- 送信されるのはプロンプト/画像のみ。サンプラー・ステップ数・CFG・Seed 等のパラメータは送信先で復元されません（Bridge 側のデフォルトまたは前回値が使われます）
