# 困ったときの自己診断と報告

YU AI Manager が動かない・挙動がおかしいときに、自分で原因の手がかりを集めて開発者へ報告する手順をまとめます。コマンドや Git の知識は不要です。

## 1. まず「問題を報告する」を押す

1. ブラウザでアプリを開き、画面右上のメニューから **診断 (Diagnostics)** を選びます。
2. **「問題を報告する」** ボタンを押します。
3. しばらく待つと、`repair/2026XXXX-HHMMSS/` というフォルダが作られます。中身は次の自動報告セットです。
   - 環境情報・最近のログ・設定（個人情報やトークンはマスク済み）
   - AI 修復用のプロンプト雛形

「**フォルダを開く**」を押すとそのフォルダがエクスプローラで開きます。「**ZIP にする**」で 1 つの zip にまとめられます。

> マスク処理について: ユーザー名・メール・API キーらしき文字列・IP アドレスなどは自動で `<REDACTED>` に置換されます。完全ではないので、共有前に中身を一度見てください。

## 2. 共有する

ZIP ファイルを開発者・サポート窓口・Discord などに添付してください。「**Discord 用メッセージをコピー**」ボタンで、貼り付けるだけの短文も用意できます。

## 3. 自分で試せる暫定対処

### 3-A. 環境チェック (doctor)

診断画面の **「環境診断」** ボタンを押すと、Python・GPU・DB などの状態が markdown で表示されます。赤色 (ERROR) や黄色 (WARN) の項目に書かれている `fix_hint` (修正のヒント) を順に試してください。

### 3-B. Safe Mode で立ち上げ直す

通常起動ができない・落ちる・延々と読み込みが止まらないときは、**Safe Mode** で起動できます。

- Windows: `start.bat --safe-mode` をダブルクリック (またはショートカット末尾に ` --safe-mode` を追加)
- macOS / Linux: ターミナルから `./start.sh --safe-mode`

Safe Mode 中は次のことができます。

- 設定の確認
- 「問題を報告する」「環境診断」
- 開発者から渡された **安全な更新パッケージ (update.zip)** の適用（ファイル差し替えのみ・自動修復スクリプトは無効）

Safe Mode は次回通常起動するまで続きます。普通に再起動すれば通常モードに戻ります。

### 3-C. 更新パッケージ (update.zip) を当てる

開発者から `update.zip` を受け取ったら:

1. 診断画面 → **「アップデートを適用」** セクション
2. ファイルを選び、**検証 (Verify)** が緑になることを確認
3. 確認ダイアログで **適用** を押す
4. 表示される指示に従って再起動

> 検証が赤になった zip は絶対に適用しないでください。改竄や別アプリ用パッケージの可能性があります。

何かあったら **「直前の更新を取り消す (Rollback)」** で 1 つ前の状態に戻せます。

## 4. やってはいけないこと

- マスク前の生ログを SNS / 公開フォーラムへ貼ること
- 出所不明の `update.zip` を適用すること
- `data/` フォルダや `tags.db` を手で書き換えること

## 困ったら

それでも解決しない場合は、ZIP と一緒に「どんな操作で何が起きたか」を添えて報告してください。AI 側で `prompt_for_codex.md` / `prompt_for_claude.md` を読み込み、修正パッチ案を出します。
