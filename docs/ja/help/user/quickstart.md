# 5分で始める YU AI Manager

## YU AI Manager とは

YU AI Manager は、AI 生成画像（Stable Diffusion / NovelAI / ComfyUI など）のメタデータを一元管理できる WebUI アプリケーションです。画像に埋め込まれたプロンプトやモデル情報を自動抽出し、タグ検索・閲覧・整理を効率化します。

---

## 動作環境

| 項目 | 要件 |
|------|------|
| Python | 3.11 以上（`start.sh` / `start.bat` が自動インストール） |
| Node.js | 22 LTS（任意 — 初回起動時に自動ダウンロードを提案） |
| OS | Windows 10/11, macOS, Linux |
| ブラウザ | Chrome / Firefox / Edge（最新版推奨） |

> **手動インストール不要。** `start.sh` / `start.bat` が必要なツールをすべてプロジェクト配下に自動セットアップします（システムへの書き込み・管理者権限なし）。

## インストール＆起動

### 1. リポジトリをクローン

```bash
git clone https://github.com/eauesque/yu_ai_manager.git
cd yu_ai_manager
```

### 2. 起動スクリプトを実行

**macOS / Linux:**

```bash
./start.sh
```

**Windows:**

```bat
start.bat
```

### 初回起動時の自動セットアップ

初回実行時、以下のツールが必要に応じてインストールされます:

| ツール | 入手方法 |
|--------|----------|
| `uv` | `./bin/uv` に自動ダウンロード |
| Python 3.11+ | `uv` が自動インストール |
| Node.js 22 LTS | 任意 — `./bin/node/` への DL を確認（約 30 MB） |
| pnpm | Node.js が入った時点で `corepack` 経由で有効化 |
| ffmpeg | 任意 — `./bin/ffmpeg/` への DL を確認（約 80 MB） |

> **ffmpeg** は動画分析・音声テキスト変換・OCR 等の拡張機能専用です。本体起動には不要です。  
> CI 等の非対話環境では `YU_AUTO_INSTALL=1` を設定するとプロンプトをスキップして全自動インストールします。

2 回目以降は依存関係や TypeScript ソースが更新されたときのみ再ビルドします。

### 3. ブラウザでアクセス

起動後、ブラウザで以下の URL を開きます:

```
http://localhost:5000
```

## 最初にやること

### Step 1: 画像フォルダをスキャン登録する

AI 生成画像が保存されているフォルダを登録して、メタデータを読み取ります。

1. 画面右上のハンバーガーメニューから **Settings** を開く
2. **Scan** タブを選択
3. スキャン対象フォルダのパスを追加
4. フォルダ追加後、自動的にスキャンが開始される

スキャン中は画面上部にプログレスバーが表示されます。画像数が多い場合は数分かかることがありますが、スキャン中でも検索・閲覧は可能です。

### Step 2: サムネイルグリッドで画像を見る

スキャンが完了すると、メインページにサムネイルグリッドが表示されます。

- **スクロール**: 仮想スクロールにより大量の画像をスムーズに表示
- **並び替え**: 画面上部のソートメニューで日付順・評価順などに切り替え
- **右クリック**: コンテキストメニューからお気に入り登録やコレクション追加が可能

### Step 3: タグ検索で画像を絞り込む

検索バーにタグをカンマ区切りで入力すると、該当する画像だけが表示されます。

```
1girl, blue_eyes, school_uniform
```

- **オートコンプリート**: 入力中に候補タグが表示される
- **フィルタ**: 日付範囲、ファイル形式、星評価などで絞り込み可能
- **プロンプト内検索**: プロンプトのテキスト全文を検索することも可能

### Step 4: 詳細モーダルで画像情報を確認する

サムネイルをクリックすると、詳細モーダルが開きます。

- **Info タブ**: プロンプト、ネガティブプロンプト、モデル名、生成パラメータなどを確認
- **AI Analysis タブ**: WD-Tagger による自動タグ付け結果を表示（設定済みの場合）
- **星評価**: 画像に 1〜5 の星評価を付けられる
- **お気に入り**: ハートアイコンでお気に入りに登録
- **タグ編集**: ユーザータグの追加・削除が可能
- **キーボード操作**: 左右矢印キーで前後の画像に移動

## よく使う操作のまとめ

| やりたいこと | 操作 |
|-------------|------|
| 画像を探す | 検索バーにタグを入力 |
| 画像の詳細を見る | サムネイルをクリック |
| お気に入りに追加 | 詳細モーダルのハートアイコン、または右クリックメニュー |
| 星評価を付ける | 詳細モーダルの星アイコン |
| 画像をコレクションに追加 | 右クリックメニュー > コレクションに追加 |
| 複数画像を選択 | Ctrl+クリック（または Shift+クリック）で範囲選択 |
| 新しいフォルダをスキャン | Settings > Scan タブ |

## 起動オプション

`launch-args.txt`（プロジェクトルートに作成）に以下のオプションを記載すると永続設定できます:

```
--db /path/to/tags.db
--port 5001
--lan
--pin 1234
```

| オプション | 説明 |
|-----------|------|
| `--db` | データベースファイルのパスを指定 |
| `--port` | ポート番号を変更（デフォルト: 5000） |
| `--lan` | LAN 公開モードを有効化（他のデバイスからアクセス可能） |
| `--pin` | LAN 公開時の PIN コード認証を設定 |

## 次のステップ

基本操作に慣れたら、以下の機能も試してみてください。

### Settings（設定）

Settings ページでは外観のカスタマイズ、タイムゾーン設定、LAN 公開設定などが行えます。

### Bridge（画像生成ツール連携）

SD WebUI / ComfyUI / NovelAI API と連携して、プロンプトの送受信ができます。  
詳しくは [Bridge ガイド](bridges.md) を参照してください。

### Extensions（拡張機能）

WD-Tagger（自動タグ付け）、プロンプトライブラリ、チャットログビューアなど、多数の拡張機能が利用できます。Settings > Extensions タブで管理できます。

### セマンティック検索

CLIP モデルを設定すると、「海辺で夕日を見ている女の子」のような自然言語で画像検索ができます。  
詳しくは [検索ガイド](search.md) を参照してください。

### MCP サーバー

Claude Desktop などの AI エージェントから YU AI Manager を操作できます。

## トラブルシューティング

問題が発生した場合は [トラブルシューティングガイド](troubleshooting.md) を参照してください。

よくある問題:

- **`start.sh` が実行できない（Linux/macOS）**: `chmod +x start.sh` で実行権限を付与してください
- **ポート 5000 が使用中**: `launch-args.txt` に `--port 5001` を追記して再起動
- **画像が表示されない**: スキャンフォルダのパスが正しいか、画像ファイルの実体が存在するか確認
- **Node.js のダウンロードをスキップしたい**: `n` を入力するか `YU_AUTO_INSTALL=1` でスキップ後、ビルド済み `dist/` がある場合はそのまま動作します
