# SNS Share & Bluesky Monitor

## 概要

SNS Share は、YU AI Manager から AI 生成画像を Bluesky や X (Twitter) に直接共有できる拡張機能です。投稿テキストはカスタマイズ可能なテンプレートから自動生成され、画像メタデータの変数が自動展開されます。Bluesky Monitor は通知の監視機能を追加し、AI によるトリアージと自動応答が可能です。

## セットアップ

### Bluesky App Password の取得

1. [bsky.app](https://bsky.app) にログインし、**設定 > App Passwords** を開く
2. **App Password を追加** をクリック
3. 名前を入力（例: 「YU AI Manager」）し、**App Password を作成** をクリック
4. 表示されたパスワードをコピーする

> **注意**: App Password はこの画面でしか表示されません。ダイアログを閉じる前に必ずコピーしてください。Bluesky のメインパスワードは絶対に使用しないでください。

### YU AI Manager での設定

1. ナビゲーションメニューから **Settings** を開く
2. **SNS** タブに切り替える
3. 以下の情報を入力する:
   - **Bluesky ハンドル**: ハンドル名（例: `yourname.bsky.social`）
   - **App Password**: 上記で取得した App Password
   - **投稿テンプレート**: 投稿テキストのテンプレート（[テンプレート変数](#テンプレート変数)を参照）
4. **保存** をクリック

### 接続テスト

認証情報を保存後、**接続テスト** をクリックして Bluesky との認証を確認します。成功するとハンドル名と表示名が表示されます。

## 機能

### Bluesky への共有

画像詳細ビューから Bluesky に直接画像を共有できます。

1. 画像の詳細モーダルを開く
2. **SNS** ボタンをクリック
3. 生成された投稿テキストを確認・編集する
4. **Bluesky に投稿** をクリック

- 投稿テキストは設定済みのテンプレートから、メタデータ変数を展開して生成されます
- 画像は Bluesky の 1 MB アップロード制限に合わせて自動的に圧縮・リサイズされます
- 投稿は **300 grapheme** に制限されます（超過分は自動的に切り詰められます）
- 画像の添付あり/なしを選択できます

### X (Twitter) への共有

Web Intent（ブラウザで X の投稿画面を開く）を使って画像情報を X に共有します。

1. 画像の詳細モーダルを開く
2. **SNS** ボタンをクリック
3. **X にシェア** をクリック

新しいブラウザタブで X の投稿画面が開き、テンプレートから生成されたテキストが自動入力されます。投稿前にテキストを編集できます。X では画像の自動添付はされないため、手動で画像を添付する必要があります。

### Bluesky Monitor

Bluesky Monitor は Bluesky の通知をポーリングし、ローカルにキューイングしてトリアージと応答を行います。

#### 通知タイプ

- **メンション**: 投稿であなたがメンションされた
- **リプライ**: あなたの投稿に返信があった
- **引用**: あなたの投稿が引用された
- **フォロー**: 誰かがあなたをフォローした
- **いいね**: あなたの投稿がいいねされた
- **リポスト**: あなたの投稿がリポストされた

#### ポーリング

通知は設定可能な間隔で自動取得されます（デフォルト: 30 分、最小: 5 分）。Settings または MCP ツールから即座にポーリングをトリガーすることもできます。

#### キューシステム

各通知は **pending**（未処理）ステータスでキューに入ります。その後、以下のステータスに遷移できます:

- **notified** -- MCP クライアント（Claude Desktop）に通知済み
- **dismissed** -- 対応不要として却下

#### トリアージ

AI による分類で、各通知に対応が必要かどうかを判定します:

- **valid** -- 対応が必要（質問、バグ報告、コラボレーション依頼など）
- **invalid** -- 無視可能（汎用的な称賛、スパム、ボットコンテンツなど）

通知タイプ（メンション、リプライ、引用）ごとにカスタマイズ可能なトリアージプロンプトがあります。デフォルトプロンプトが用意されており、いつでも復元可能です。

#### 自動応答

valid と判定されたメンション・リプライ・引用に対して、テンプレートベースの自動返信を送信できます:

- Monitor 設定で自動応答を有効化
- 通知タイプごとに応答テンプレートをカスタマイズ
- 応答は 300 grapheme に制限されます

#### 自動却下

フォロー・いいね・リポストは自動的に却下してキューのノイズを減らすことができます。各タイプは Settings で個別に切り替え可能です。

#### MCP 接続時の通知

MCP クライアント（Claude Desktop）が接続すると、未処理の通知がまとめて報告されるため、開発セッション中に確認できます。

### Settings

SNS 設定は Settings ページの **SNS** タブで行います:

- **Bluesky 認証情報**: ハンドルと App Password（パスワードは暗号化保存、マスク表示）
- **投稿テンプレート**: 変数プレースホルダー付きのテンプレートテキスト
- **Monitor 設定**:
  - ポーリング間隔（分）
  - フォロー・いいね・リポストの自動却下
  - 自動応答の有効/無効
  - メンション・リプライ・引用のトリアージプロンプト
  - メンション・リプライ・引用の自動応答テンプレート

## MCP 連携

SNS Share & Bluesky Monitor には 15 の MCP ツールが用意されています:

**共有（6 ツール）**:
- `share_to_bluesky` -- 画像を Bluesky に投稿
- `get_x_share_url` -- X Web Intent URL を取得
- `get_sns_preview` -- テンプレート展開のプレビュー
- `test_bluesky_connection` -- API 接続テスト
- `get_sns_config` / `save_sns_config` -- SNS 設定の取得・保存

**通知キュー（5 ツール）**:
- `bsky_get_pending_notifications` -- 未処理の通知を取得
- `bsky_get_notification_queue` -- フィルター付きキューアイテムの取得
- `bsky_triage_notification` -- トリアージ結果の設定（valid/invalid）
- `bsky_send_auto_response` -- 通知への返信を送信
- `bsky_poll_notifications` -- 即座にポーリングをトリガー

**Monitor 設定（4 ツール）**:
- `bsky_get_monitor_config` / `bsky_save_monitor_config` -- Monitor 設定の取得・保存
- `bsky_get_triage_prompts` / `bsky_save_triage_prompts` -- トリアージプロンプトと応答テンプレートの取得・保存

## テンプレート変数

投稿テンプレートで使用できる変数:

| 変数 | 説明 |
|---|---|
| `{positive_short}` | ポジティブプロンプト（先頭 100 文字） |
| `{positive}` | ポジティブプロンプト全文 |
| `{negative_short}` | ネガティブプロンプト（先頭 50 文字） |
| `{model}` | モデル名 |
| `{seed}` | シード値 |
| `{steps}` | サンプリングステップ数 |
| `{cfg}` | CFG スケール |
| `{sampler}` | サンプラー名 |
| `{size}` | 画像サイズ |
| `{tags}` | 上位 5 タグ |
| `{filename}` | ファイル名 |

デフォルトテンプレート: `{positive_short}`

## ヒント

- **App Password のセキュリティ**: Bluesky のメインパスワードではなく、必ず App Password を使用してください。App Password は bsky.app の設定からいつでも無効化できます
- **レート制限**: Bluesky API にはレート制限があります。連続した投稿は避けてください。画像アップロードもレート制限にカウントされます
- **Grapheme カウント**: Bluesky は 300 文字制限に文字数ではなく grapheme cluster を使用します。CJK 文字は 1 grapheme としてカウントされます
- **画像圧縮**: 1 MB を超える画像は自動的にリサイズされます。画像の準備に失敗した場合はテキストのみで投稿されます
- **Monitor のポーリング間隔**: 通知量に応じてポーリング間隔を設定してください。通知が多いアカウントは短い間隔が有効です
- **自動却下**: フォロー・いいね・リポストの自動却下を有効にすると、対応が必要な通知に集中できます
- **トリアージプロンプト**: コミュニケーションスタイルや受信するインタラクションの種類に合わせてトリアージプロンプトをカスタマイズしてください
