# Extension のセキュリティモデル

このソフトウェアは「誰でも AI を使って Extension を作れる」ことを特徴としている。
同時に、悪意のある Extension からあなたのシステムを守る仕組みが組み込まれている。

このページでは、その仕組みを説明する。
技術者でなくても理解できるように書いてある。

---

## 基本的な考え方

Extension は **守られた世界** の中で動く。

この守られた世界の中では、Extension は比較的自由に振る舞える。
ページを追加したり、データを表示したり、画像を処理したり——それは Extension の仕事だ。

ただし、守られた世界の **外** にあるもの——システムの中枢（core）、他の Extension、あなたの PC の全てのファイル——には手が届かない。
これは「ルールで禁止している」のではなく、**物理的に手が届かない** 構造になっている。

---

## 権限の仕組み

Extension が何かをするには **権限** が必要だ。

権限はスマートフォンのアプリ権限と同じモデルで設計されている。

- カメラアプリがカメラへのアクセスを求めるのは当然だ
- カメラアプリが連絡先へのアクセスを求めるのは不自然だ

Extension も同じ。画像にウォーターマークを付ける Extension がネットワークアクセスを求めていたら、それは疑うべきだ。

### 承認の流れ

1. Extension をインストールする（または AI に作ってもらう）
2. YU AI Manager が自動でコードをスキャンし、何をしようとしているか検査する
3. Extension が求めている権限の一覧が表示される
4. **あなたが承認するまで、Extension は動かない**

承認画面に表示される情報をよく読みなさい。
特に赤く表示されている権限には注意を払うこと。

### 権限を承認した後

承認した権限の範囲内で Extension は動作する。
承認していない権限は、Extension がどれだけ頑張っても使えない。
「使おうとして拒否される」のではなく、「そもそも見えない」。

---

## 3つの独立した監視

あなたの Extension は3つの独立した仕組みで監視されている。
この3つは互いに独立していて、1つが騙されても残り2つが機能する。

### 1. コードスキャン

Extension のコードを自動的に解析し、危険なパターンを検出する。
外部プログラムの実行、直接的なデータベース操作、動的なコード実行——これらは即座に検出される。

### 2. 権限制御

Extension が API を呼ぶとき、有効な「許可証」を持っているか確認する。
許可証はあなたが権限を承認したときだけ発行される。
Extension 自身が許可証を偽造することはできない。

### 3. 監査記録

Extension の全ての操作は記録されている。
この記録は Extension 自身からは書き換えられない独立した場所に保存される。

異常が検出された場合——たとえば、宣言していない動作をしようとした場合——自動的に通知が届き、必要に応じて Extension の許可証が無効化される。

---

## AI で Extension を作る場合

Claude Desktop から Extension を作る場合、作成された Extension は自動的に **最も制限の厳しいレベル** で登録される。

これは新しく雇った社員に最初から金庫の鍵を渡さないのと同じだ。
まず限られた権限で動かし、問題がないことを確認してから、必要に応じて権限を追加する。

### AI が作った Extension で何ができるか

**承認なしで使えるもの:**
- データの読み取り表示
- UI へのページ追加
- 設定画面の追加

**承認が必要なもの:**
- 外部サービスへの通信
- データベースへの書き込み
- ファイルの読み取り

**何をしても不可能なもの:**
- システムの中枢（core）の読み取りや変更
- 他の Extension の読み取りや変更
- 外部プログラムの実行
- 許可証の偽造

---

## 定期的な検査

Extension は一度承認されたら終わりではない。

コードが変更された場合、その変更量が一定の閾値を超えると **再承認** が求められる。
これは、少しずつ変更を重ねて気づいたら全く別物になっている、という手口を防ぐためだ。

また、定期的にコードの再検査が自動実行される。
承認時には問題がなくても、新しい検査ルールで問題が見つかることがある。

---

## あなたがすべきこと

1. **権限の承認画面をちゃんと読め** — 何を求めているか理解してから承認しなさい
2. **不自然な権限要求は拒否しろ** — 画像処理にネットワークが要るのはおかしい
3. **通知を無視するな** — 異常が検出されたら確認しなさい
4. **信頼できない出所の Extension は入れるな** — 当然のことだ

逆に言えば、それだけやっていれば安全だ。
あとは仕組みが守ってくれる。
