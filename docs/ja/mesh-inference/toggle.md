# 分散推論マトリクス

**バージョン**: v4.67.0 以降

## 概要

`/mesh-inference` ページでは、mesh inference に参加している各ピアに対して推論タイプ単位で有効/無効を切り替えられます。対象は tagger・clip・yolo・whisper の 4 種類。

これにより、Pi5 の Hailo NPU を tagger 専用に寄せる、GPU ホストで clip を処理する、といった役割分担が config を触らずに行えます。

## 使い方

1. ナビバーから「🕸️ 分散推論」をクリック
2. マトリクス表の各セルをクリックして有効/無効を切替
   - ☑ = 有効（そのピアでその推論タイプを使う）
   - ☐ = 無効（そのピアをスキップ）
   - — = そのピアは該当タイプを提供していない（操作不可）
3. 「ローカルのみモード」ボタンで全リモートピアを一括無効化できる
4. 状態は自動的に `data/mesh_inference_state.json` に永続化される

## 挙動

- オフラインのピアにも設定は保持される（再接続時に自動適用）
- 「ローカルのみモード」はローカルに 1 つでも有効なタイプがあるときだけ押せる
- すべてのピアで tagger が無効な状態で tagger バッチを起動すると `no_enabled_peers` エラーで即座に失敗する
- mDNS 再検出でピアが一時離脱・復帰しても無効化状態は保持される

## 既存 YOLO 分散推論チェックとの関係

YOLO 検出ページの「分散推論」チェックボックスは後方互換のため温存されており、以下のように組み合わさります:

| yoloDistributed | マトリクス yolo 列 | 実挙動 |
|---|---|---|
| ✅ ON | 全ピア有効 | 従来どおり全ピアで分散 |
| ✅ ON | 一部無効 | 無効ピアをスキップ |
| ❌ OFF | 無視 | ローカルのみ（router バイパス） |
