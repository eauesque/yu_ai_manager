# Favorites API

お気に入り（ファボ）の追加・削除・チェック・一覧取得に関する API。

## POST /api/favorites/toggle

ファイルのお気に入り状態をトグルする。お気に入りに含まれていなければ追加、含まれていれば削除する。

- **レート制限**: WRITE

### リクエストボディ

| パラメータ | 型 | 必須 | 説明 |
|-----------|------|------|------|
| `file_id` | int | はい | 対象ファイルの ID（正の整数） |
| `collection_id` | int | いいえ | コレクション ID（デフォルト: 1） |

```json
{
  "file_id": 42,
  "collection_id": 1
}
```

### レスポンス

```json
{
  "file_id": 42,
  "collection_id": 1,
  "favorited": true
}
```

| フィールド | 型 | 説明 |
|-----------|------|------|
| `file_id` | int | 対象ファイルの ID |
| `collection_id` | int | コレクション ID |
| `favorited` | bool | トグル後の状態。`true` = 追加された、`false` = 削除された |

## GET /api/favorites/check

指定したファイル ID のうち、お気に入りに含まれているものを返す。

### パラメータ

| パラメータ | 型 | 必須 | 説明 |
|-----------|------|------|------|
| `ids` | string | はい | カンマ区切りのファイル ID（例: `1,2,3`） |
| `collection_id` | int | いいえ | 特定のコレクションに絞り込む |

### レスポンス

```json
{
  "favorites": [1, 3]
}
```

| フィールド | 型 | 説明 |
|-----------|------|------|
| `favorites` | int[] | お気に入りに含まれているファイル ID の配列 |

## GET /api/favorites/check_collections

指定したファイルが含まれているコレクション ID の一覧を返す。

### パラメータ

| パラメータ | 型 | 必須 | 説明 |
|-----------|------|------|------|
| `file_id` | int | はい | 対象ファイルの ID |

### レスポンス

```json
{
  "collections": [1, 3]
}
```

| フィールド | 型 | 説明 |
|-----------|------|------|
| `collections` | int[] | このファイルを含むコレクション ID の配列 |

## GET /api/favorites/list

お気に入りファイル ID の一覧を取得する。追加日時の降順でソートされ、論理削除されたファイルは除外される。

### パラメータ

| パラメータ | 型 | 必須 | 説明 |
|-----------|------|------|------|
| `collection_id` | int | いいえ | 特定のコレクションに絞り込む |

### レスポンス

```json
{
  "ids": [42, 55, 67]
}
```

| フィールド | 型 | 説明 |
|-----------|------|------|
| `ids` | int[] | お気に入りファイル ID の配列（`added_at` 降順） |
