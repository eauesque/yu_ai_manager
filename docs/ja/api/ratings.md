# Ratings API

ファイルのレーティング (1〜5 の星評価) の設定・取得・統計に関する API。

## POST /api/ratings/set

ファイルにレーティングを設定する。`rating=0` を指定するとレーティングをクリアする。

**レート制限**: WRITE

### リクエスト

```json
{
  "file_id": 42,
  "rating": 5
}
```

| パラメータ | 型 | 必須 | 説明 |
|-----------|------|------|------|
| `file_id` | int | はい | ファイル ID (正の整数) |
| `rating` | int | はい | レーティング値 (0〜5)。0 でクリア |

### レスポンス

```json
{
  "file_id": 42,
  "rating": 5
}
```

## POST /api/ratings/batch-set

複数ファイルのレーティングを一括設定する。

**レート制限**: WRITE

### リクエスト

```json
{
  "items": [
    { "file_id": 1, "rating": 5 },
    { "file_id": 2, "rating": 3 }
  ]
}
```

| パラメータ | 型 | 必須 | 説明 |
|-----------|------|------|------|
| `items` | array | はい | レーティング設定のリスト (最大 500 件) |
| `items[].file_id` | int | はい | ファイル ID (正の整数) |
| `items[].rating` | int | はい | レーティング値 (0〜5) |

### レスポンス

```json
{
  "total": 2,
  "succeeded": 2,
  "failed": 0,
  "errors": []
}
```

## GET /api/ratings/get

ファイルのレーティングを取得する。未評価の場合は `rating: 0` を返す。

### パラメータ

| パラメータ | 型 | 必須 | 説明 |
|-----------|------|------|------|
| `file_id` | int | はい | ファイル ID (クエリパラメータ) |

### レスポンス

```json
{
  "file_id": 42,
  "rating": 5
}
```

> **注意**: 未評価のファイルは `rating: 0` を返す。

## POST /api/ratings/batch

複数ファイルのレーティングを一括取得する。

### リクエスト

```json
{
  "file_ids": [1, 2, 3]
}
```

| パラメータ | 型 | 必須 | 説明 |
|-----------|------|------|------|
| `file_ids` | array | はい | ファイル ID のリスト |

### レスポンス

```json
{
  "ratings": {
    "1": 5,
    "3": 4
  }
}
```

> **注意**: レーティングが設定されているファイルのみがマップに含まれる。未評価のファイルはキーとして出現しない。

## GET /api/ratings/stats

レーティングの統計情報を取得する。

### パラメータ

なし。

### レスポンス

```json
{
  "total_rated": 1234,
  "distribution": {
    "1": 50,
    "2": 100,
    "3": 300,
    "4": 500,
    "5": 284
  }
}
```

| フィールド | 型 | 説明 |
|-----------|------|------|
| `total_rated` | int | レーティング済みファイルの総数 |
| `distribution` | object | 各レーティング値 (1〜5) ごとのファイル数 |
