# モーダルツールバー

詳細モーダルの下部に配置された統合ツールバーで、画像 / 動画表示中の主要操作にアクセスできます。

## 構造

### 主要バー（常時表示）

**静止画モード:**
- ☆ お気に入り
- ⓘ Info パネル開閉
- ‹ › 前/次の画像
- ズーム（－ / 100% / ＋）
- フィットモード（fit / fit-w / fit-h / fit-custom + 高さ入力 / original）
- 見開き 2P / 方向 ↔（適用可能な場合のみ）
- ⛶ イマーシブ / ⤢ フルスクリーン
- 📁 コレクション
- Bridge Send（プロンプトを送る ▾ / 画像を送る ▾）

**動画 / 音声モード（2 段構造）:**
- 上段: 時間表示 + シークバー（max-width 720px キャップ）
- 下段: ☆ Fav / ⓘ Info / ‹ › / ▶ 再生 ⏪ ⏩ / ♪ ミュート + 音量 / ⛶ ⤢ / 📁

### overflow メニュー（… ボタン）

低頻度操作を縦リストで集約：
- オートプレイ + 間隔
- リピート / 速度 / レジューム（動画時）
- FPB / キャラクターグリッド（静止画時）
- ZIP / コンテナビュー
- キーボードガイド ?
- ツールバー折りたたみ «

## キーボードショートカット

| キー | 動作 |
|---|---|
| `T` | ツールバーの表示/非表示トグル |
| `V` | イマーシブモード |
| `F` | フルスクリーン |
| `I` | Info パネル |
| `H` | キーボードガイド |
| `P` | オートプレイ |
| `Space` / `K` | 再生/一時停止（動画） |
| `J` / `0` | 早戻し（動画） |
| `L` | 早送り（動画） |
| `M` | ミュート（動画） |
| `R` | リピート（動画） |
| `←` / `→` | 前/次の画像 |
| `ESC` | overflow メニュー → モーダルの順に閉じる |

## 折りたたみと復帰

ツールバーを折りたたむ方法：
- overflow メニュー（…）から「ツールバーを隠す」
- `T` キー

復帰方法：
- 画面下端中央のエッジハンドルをクリック
- `T` キーをもう一度押す

折りたたみ状態は filmstrip の有無に応じてエッジハンドル位置が自動調整されます。

## アクセシビリティ

- ツールバー全体に `role="toolbar"` を設定
- overflow ボタンは `aria-haspopup="menu"` / `aria-expanded` を動的に更新
- overflow メニュー項目は `role="menuitem"`
- エッジハンドルは標準の `<button>` で Enter/Space で操作可能
- WCAG 2.5.5 (Target Size) を満たすため、視認上 8px のハンドルに 24px 高さの不可視ヒットエリアを `::before` で拡張
