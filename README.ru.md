# YU AI Manager

WebUI для управления метаданными AI-генерированных изображений.

## Обзор

WebUI инструмент для извлечения, поиска и управления метаданными, встроенными в AI-генерированные изображения (промпты, модели, сиды и т.д.).

**Что вы можете делать:**

- Сканировать папки и ZIP архивы целиком и автоматически регистрировать изображения
- Поиск и фильтрация по промптам, тегам, названиям моделей, значениям сида и многому другому
- Отправлять понравившиеся изображения в SD / ComfyUI / NovelAI для переиспользования
- Автоматическое добавление тегов с помощью WD-Tagger, анализ содержимого с помощью Ollama/OpenAI
- Доступ с других устройств в локальной сети (смартфоны и т.д.) через QR-код

**Поддерживаемые источники**: Stable Diffusion (A1111/Forge), NovelAI V3/V4, ComfyUI

## Требования к системе

- Windows / Linux / macOS

> **Ручная установка не требуется.** `start.sh` / `start.bat` автоматически загружает все необходимые инструменты в проект (без прав администратора и записи в систему).

## Установка и запуск

```bash
git clone https://github.com/eauesque/yu_ai_manager.git
cd yu_ai_manager

# Windows
start.bat

# macOS / Linux
./start.sh
```

Автоматическая настройка при первом запуске:

| Инструмент | Получение |
| --- | --- |
| `uv` | Автоматическая загрузка в `./bin/uv` |
| Python 3.11+ | Автоматическая установка через `uv` |
| Node.js 22 LTS | Опционально — проверка загрузки в `./bin/node/` (около 30 МБ) |
| pnpm | Активация через `corepack` когда установлен Node.js |
| ffmpeg | Опционально — Windows/macOS: проверка загрузки в `./bin/ffmpeg/` (около 80 МБ), Linux: указание команды `apt`/`dnf`/`pacman` дистро |

Установка `YU_AUTO_INSTALL=1` пропускает подсказки и запускает полностью автоматическую установку даже в неинтерактивной среде (например, CI). ffmpeg специализирован на расширенных функциях, таких как анализ видео, S2T и OCR, поэтому не требуется для основного запуска.

При следующих запусках переустановка и перестроение происходят только если обновлены зависимости или исходники TypeScript.

Вы можете создать постоянные параметры, указав `--db`, `--port`, `--lan`, `--pin` и другие флаги в файле `launch-args.txt`.

## Основные функции

### Сканирование и регистрация
- Автоматическое извлечение метаданных из PNG / WebP / JPEG
- Прозрачное сканирование архивов ZIP / 7z без распаковки
- Добавление файлов через перетаскивание

### Поиск и просмотр
- Полнотекстовый поиск по промптам, тегам, названиям моделей, значениям сида
- Поиск по регулярным выражениям, сложные фильтры условий
- Поиск похожих изображений по pHash, семантический поиск CLIP

### Организация и управление
- Избранное, рейтинг звезд (1-5), заметки (аннотации)
- Коллекции (группировка)
- Статистическая панель, месячные отчеты, система трофеев

### Интеграция с инструментами генерации (Bridge)
- Быстрая отправка промптов в SD WebUI / Forge / ComfyUI / NovelAI
- Поддержка отправки через буфер обмена

### AI помощь
- Автоматическое добавление тегов с помощью WD-Tagger
- Анализ содержимого изображения с использованием Ollama / OpenAI
- Преобразование речи в текст (S2T)

### Сетевые возможности и общий доступ
- Режим общего доступа в локальной сети (доступ со смартфонов через QR-код)
- MCP сервер (управление от AI агентов)
- Fleet управление (единое управление несколькими экземплярами)

### Настройка
- Система пользовательского UI и расширений
- Поддержка тем (светлая / темная)
- Приложение Tauri (запуск без браузера)

## Не знаете, как что-то сделать? Спросите у AI

### Если приложение не запускается

Откройте этот проект в AI агенте, таком как Claude Code Desktop, и скажите:

> `start.bat` (или `start.sh`) запускается но затем зависает. Пожалуйста, посмотрите в чем дело.

> **Примечание**: В Claude Code Desktop нужно указать папку проекта перед началом разговора.

### Проблемы, настройка и использование после запуска

**Шаг 1 — Получить контекст**

Откройте страницу справки (`/help`) и нажмите кнопку **"Копировать AI контекст"**.
Она использует вошедший в систему сеанс браузера для fetch запроса `GET /api/ai-context` и копирует JSON в буфер обмена (работает даже в http:// LAN среде).

> **Примечание (если у вас есть API ключ)**: Если у вас есть API ключ с областью администратора, вы можете напрямую вызвать `GET /api/ai-context` с заголовком `Authorization: Bearer <key>`.

**Шаг 2 — Передать AI**

Вставьте скопированный JSON в чат AI и напишите свой вопрос:

> [Вставленный JSON]
> Учитывая это, пожалуйста, решите [описание проблемы].

`/api/ai-context` содержит текущую версию, включенные функции, подсказки по настройке, список API и правила CSRF, необходимые для точной поддержки со стороны AI.
