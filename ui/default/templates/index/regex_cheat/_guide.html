How Search Works
The main bar searches tags. Comma-separated = AND (all must match). 1girl, winter → 1girl AND winter
Prefix with - to exclude: 1girl, -nsfw

All condition chips are AND-combined. The more you add, the narrower the results:
Main: 1girl, winter + Folder + NovelAI + 1024+

OR (match any) → use the "OR tags" chip: blonde, silver → blonde OR silver
