OR (match either)
cat|dog
Matches "cat" or "dog"
Word boundary
\b1girl\b
Excludes "12girls" etc.
Group
(masterpiece|best quality)
Matches any of the alternatives
Common error
( / [ unclosed bracket
If in trouble, turn off "Regex"
AND (both match)
(?=.*cat)(?=.*dog)
Contains both "cat" and "dog" (any order)
Exclude (NOT)
^(?!.*nsfw).*
Excludes lines containing "nsfw"
Match as comma-separated tag
(?:^|,\s*)cat(?:,|$)
Matches "cat" as a standalone tag (avoids "category" etc.)
Any char (greedy)
1girl.*smile
"smile" appears anywhere after "1girl"
Any char (lazy)
\(.*?\)
Shortest match inside parentheses
Whitespace tolerance
cat\s*\|\s*dog
Allows spaces around "cat|dog"
Start/End anchor
^masterpiece|quality$
Starts with "masterpiece" or ends with "quality"
Escape (literal symbols)
\.|\(|\)|\[|\]
Treat . ( ) [ ] as literal characters
Exclude (negative lookahead)
^(?!.*\bnsfw\b).*
Excludes lines containing "nsfw" (as tag or text)
AND + NOT
^(?=.*\b1girl\b)(?!.*\bnsfw\b).*
Contains "1girl" but not "nsfw"
Exclude as comma-separated tag
^(?=.*(?:^|,\s*)1girl(?:\s*,|$))(?!.*(?:^|,\s*)nsfw(?:\s*,|$)).*
Excludes "nsfw" only as a standalone tag (keeps "nsfw123")
Lookbehind
(?<=artist:\s*)[^,\n]+
Captures text right after "artist:" (some browsers only)
