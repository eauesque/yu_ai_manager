What is Regex? (Basics)

Regular expressions (RegExp) are a pattern notation for finding parts of strings that match conditions.
Check "Regex" in the prompt search to interpret input as a regular expression. (Click examples below to copy)

1) OR (match any)
cat|dog
Matches "cat" or "dog"
2) Word boundary (avoid partial match)
\b1girl\b
Excludes "12girls" etc.
3) Exclude (negative lookahead)
^(?!.*\bnsfw\b).*$
Excludes lines containing "nsfw"
For more examples (tag exclusion, lookbehind, etc.), see the Regex Cheatsheet (Ctrl+/). Start with the 3 patterns above, then refer to the cheatsheet.
